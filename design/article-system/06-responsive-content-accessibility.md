# 响应式、内容与可访问性规范

## 断点

设计验收视口：

| 名称    |   宽度 | 目标               |
| ------- | -----: | ------------------ |
| Compact |  360px | 最小手机           |
| Mobile  |  390px | 常见手机           |
| Tablet  |  768px | 单列到双列过渡     |
| Desktop | 1024px | 正文与目录开始并列 |
| Wide    | 1440px | 完整 12 列体验     |

不能只检查 1440px 和一个手机宽度。

## 响应规则

### 文章列表

- 1024px 以上使用四区网格。
- 768–1023px 使用日期列与内容列，标签进入内容列底部。
- 767px 以下单列；日期、更新时间同一行，标题紧随其后。
- 不在手机上重复列表页标题。

### 面包屑

- 所有断点保持同一语义。
- 手机端单行横向滚动，不允许因换行造成页面顶部高度随机变化。
- 当前项设置 `aria-current="page"`。

### 正文与目录

- 1024px 以上显示右侧 sticky 目录。
- 1023px 以下显示折叠式“本文目录”。
- 没有 H2/H3 时不渲染目录控件。
- 当前章节同时反映到桌面目录和移动目录。

### 版本工具

- 桌面使用单行紧凑工具条。
- 移动端主选择器和比较入口保持清晰，展开表单后使用单列。
- 十二个版本只影响下拉面板内部，不增加工具条高度。
- 比较表单禁止选择两个相同版本，反向选择时按版本号自动规范化。

## 内容层级

### 导航标签

简短、稳定、面向站点结构：

```text
项目 / 文章 / 关于
```

### 页面标题

文章索引不额外渲染标题或说明，直接进入工具与列表。其他页面仅在标题承担真实页面身份时渲染 H1：

```text
文章导航：文章
文章索引：无可见 H1
标签页：#标签名
文章页：文章标题
```

### Demo 说明

“这里用于……”仅用于确有需要的：

- 空状态；
- 原型注释；
- 组件说明。

禁止为填补版面而设置可见说明区，也禁止作为 H1 或文章真实标题的替代品。

## 可访问性

- 需要可见页面标题的页面只有一个 H1；文章索引不为满足形式而添加空洞 H1。
- 面包屑使用 `<nav aria-label="面包屑">` 和有序列表。
- 当前面包屑项使用 `aria-current="page"`。
- 版本选择器使用原生 `details/summary` 或符合 ARIA 的菜单模式。
- 所有图标操作具有可见文字或 `aria-label`。
- 焦点顺序与视觉顺序一致。
- 焦点环不可被 `overflow: hidden` 截断。
- 点击目标至少 40×40px；正文内普通链接除外。
- 历史状态不仅用琥珀色表达，必须包含“历史版本”文字。
- Diff 的新增和删除同时使用符号、文字和颜色。
- 深浅主题正文、辅助文字、边框和焦点态分别检查对比度。
- 尊重减少动态效果偏好。

## SEO 与索引

- 当前文章是唯一 canonical 和可搜索版本。
- 历史版本和 Diff 设置 `noindex`。
- 标签页可进入 sitemap，但不进入全文搜索索引，避免重复文章摘要。
- 分页拥有独立 canonical，并使用前后页关系。
- 可见页面标题与 SEO title 相互独立；SEO title 不要求页面重复渲染 H1。
