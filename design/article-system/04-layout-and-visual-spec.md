# 布局与视觉规范

## 设计原则

1. 视觉丰富不等于信息层级混乱。
2. 背景网格、光效和品牌色属于全站氛围层；文章结构由网格、基线和文字层级控制。
3. 同一对象在不同页面必须保持相同位置与语义。
4. Demo 说明可以存在，但不能冒充页面身份。
5. 条件功能出现时只占用自己的区域，不改变上方导航和标题位置。

## 页面网格

桌面基准宽度：`1216px`  
页面左右安全边距：`32px`  
列数：12  
列间距：`24px`

### 文章列表

```text
日期：2 列
标题与摘要：6 列
标签与版本：3 列
阅读入口：1 列
```

这不是“收窄内容轨道”，而是让整条横向空间承担明确职责。

### 文章正文

```text
正文主列：9 列
目录：3 列
```

标题、摘要、元数据、版本工具和正文全部从正文主列左边界开始。目录从右侧三列开始。历史页与 Diff 也复用同一 12 列外框。

### 移动端

- 单列布局。
- 页面安全边距 `16px`。
- 面包屑、标题、元数据、条件工具、目录、正文顺序固定。
- 版本工具允许换行，但不能生成多个同权重大胶囊按钮。

## 垂直节奏

基础单位：`4px`，常用节奏为 `8px` 的倍数。

| 关系               | 桌面 | 移动 |
| ------------------ | ---: | ---: |
| 站点导航到页面内容 | 48px | 32px |
| 面包屑到标题       | 32px | 24px |
| 标题到摘要         | 16px | 16px |
| 摘要到元数据       | 24px | 24px |
| 元数据到标签       | 16px | 16px |
| 标签到版本工具     | 16px | 16px |
| 文章头到正文       | 48px | 40px |
| 正文段落间距       | 24px | 20px |
| H2 前间距          | 56px | 44px |

条件区块缺失时只移除自身高度，不能改变面包屑和标题的基准位置。

## 字体层级

| Token             | 桌面       | 移动       | 用途                   |
| ----------------- | ---------- | ---------- | ---------------------- |
| `display-page`    | 48/56, 800 | 36/44, 800 | 文章索引的编辑型标题   |
| `display-article` | 48/56, 800 | 36/44, 800 | 文章标题               |
| `display-utility` | 40/48, 800 | 32/40, 800 | 历史和 Diff            |
| `heading-2`       | 30/40, 800 | 27/36, 800 | 正文章节               |
| `heading-3`       | 23/32, 750 | 21/30, 750 | 正文小节               |
| `body`            | 18/32, 400 | 17/30, 400 | 正文                   |
| `summary`         | 18/30, 400 | 17/28, 400 | 摘要                   |
| `meta`            | 13/20, 500 | 12/20, 500 | 日期、阅读时间         |
| `label`           | 11/16, 700 | 11/16, 700 | 英文 eyebrow、版本状态 |

标题测试必须覆盖 10、20、30、45 个汉字。长标题允许换行，但不能遮挡目录或把工具栏挤出视口。

## 颜色

原型颜色不是最终品牌锁定值，但定义了角色：

```text
page-dark        #070A12
surface-dark     #0E1422
surface-strong   #121A2A
ink-dark         #EDF2F9
muted-dark       #98A4B7
line-dark        rgba(148, 163, 184, .16)
cyan             #22D3EE
violet           #A78BFA
amber            #FBBF24
green            #34D399
```

- Cyan：链接、当前位置、普通交互。
- Violet：版本相关操作。
- Amber：历史版本警告。
- Green：当前版本状态。
- 颜色不能单独承担含义，必须配合文本或图标。

## 表面和动效

- 页面背景保留网格与两处柔和径向光。
- 普通文章行不使用独立大卡片。
- 标签索引、历史版本项和 Diff 端点可以使用表面容器。
- 圆角层级：小控件 `10px`，工具条 `16px`，主要卡片 `20px`。
- Hover 位移最大 `2px`，文章阅读区域不使用持续动画。
- 遵守 `prefers-reduced-motion`。

## 内容宽度说明

本设计不把“页面太宽”作为问题。问题是现有横向空间没有结构。

- 列表使用全部 12 列。
- 正文使用 9 列，目录使用 3 列。
- 代码、表格和大图允许在正文主列内占满。
- 必要时为图表设计 breakout，但不通过任意 `max-width` 修补对齐。
