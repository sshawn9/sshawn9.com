# 导航与版本语义

## 统一面包屑

所有文章子页面使用同一个 `ArticleBreadcrumb`，共享相同容器、顶部间距、字号和截断规则。

| 页面     | 面包屑                            |
| -------- | --------------------------------- |
| 当前文章 | `文章 / 文章标题`                 |
| 历史版本 | `文章 / 文章标题 / v1`            |
| 版本比较 | `文章 / 文章标题 / 比较 v1 与 v3` |
| 标签索引 | `文章 / 标签`                     |
| 标签文章 | `文章 / 标签 / #Markdown`         |

规则：

- “文章”始终链接 `/blog/`。
- 面包屑中的文章标题始终链接当前文章 `/blog/:slug/`。
- 最后一级表示当前页面，不可点击并设置 `aria-current="page"`。
- 文章标题超过可用空间时单行省略，不能把整个头部推高。
- 移动端允许横向滚动，但隐藏滚动条；不换成含义不同的“返回”按钮。

## 禁止的导航模式

以下文字不再作为文章页面顶部导航：

- 返回文章列表
- 返回当前文章
- 返回版本

它们的问题不是措辞，而是由各页面临时定义父级，位置和语义都会漂移。

## 当前版本

默认 URL：

```text
/blog/:slug/
```

版本工具：

```text
[v3 / 当前 ▾]  [比较版本]
```

- 版本选择器列出所有已发布版本。
- “比较版本”展开版本 A 和版本 B 两个选择器。
- 两个版本相同时禁用提交，并给出文字提示。
- 这些操作属于文章元数据区，不是页面主导航。

## 历史版本

URL：

```text
/blog/:slug/v/1/
```

历史版本状态块：

```text
历史版本 v1 · 发布于 2024-06-18
这是发布时的不可变快照；当前最新版为 v3。
[阅读当前版本] [比较 v1 与 v3]
```

“阅读当前版本”是状态修复操作，不是面包屑或返回链接。

## 版本比较

Diff 页面始终表达两个明确端点：

```text
比较 v1 与 v3
版本 A：v1 / 2024-06-18
版本 B：v3 / 2026-07-31
```

页面操作：

- 阅读 v1
- 阅读 v3
- 重新选择任意两个不同版本

不出现第三套“返回”按钮。

## 页面底部

彻底删除：

- KEEP EXPLORING
- 连接相邻文章
- 上一篇
- 下一篇
- 项目入口
- 更多文章卡片

正文完成后只允许：

- 文章自身的脚注或引用；
- 极简“回到顶部”辅助动作；
- 全站 Footer。

版本入口只存在于版本工具和历史状态块，不在底部重复。
