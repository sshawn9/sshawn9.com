# 组件与状态矩阵

## 核心组件

| 组件                      | 职责                             | 不负责                 |
| ------------------------- | -------------------------------- | ---------------------- |
| `ArticleIndexHeader`      | 编辑型标题、说明、数量、标签入口 | 搜索；全局导航已有搜索 |
| `ArticleList`             | 文章行、分页                     | 年份归档               |
| `ArticleListItem`         | 日期、标题、摘要、标签、版本摘要 | 展示完整版本工具       |
| `ArticleBreadcrumb`       | 表达页面层级                     | 页面状态提示           |
| `ArticleHeader`           | 标题、摘要、时间、标签           | 相邻文章               |
| `VersionToolbar`          | 选择阅读版本、打开双版本比较     | 在单版本文章出现       |
| `HistoricalVersionNotice` | 说明旧快照并提供当前版本操作     | 代替面包屑             |
| `ArticleToc`              | 当前章节和锚点导航               | 文章版本导航           |
| `VersionCompareForm`      | 自由选择两个不同版本             | 展示 Diff 正文         |
| `VersionDiff`             | 展示两个版本的真实正文差异       | 人工变更摘要           |
| `Pagination`              | 全部文章和标签文章翻页           | 年份筛选               |
| `TagIndex`                | 标签与计数                       | 充当文章分类说明       |

## 页面状态矩阵

| 状态           | 面包屑 | 版本工具   | 历史提示   | 目录         | 标签 | 底部相邻文章 |
| -------------- | ------ | ---------- | ---------- | ------------ | ---- | ------------ |
| 普通文章       | 是     | 否         | 否         | 按标题生成   | 可选 | 否           |
| 多版本当前文章 | 是     | 是         | 否         | 按标题生成   | 可选 | 否           |
| 多版本历史文章 | 是     | 是         | 是         | 按该版本生成 | 可选 | 否           |
| 版本比较       | 是     | 不使用     | 不使用     | 否           | 否   | 否           |
| 无目录文章     | 是     | 按版本状态 | 按版本状态 | 完全不渲染   | 可选 | 否           |

## 版本工具状态

| 条件               | 显示                                         |
| ------------------ | -------------------------------------------- |
| 只有一个已发布版本 | 不渲染整个组件                               |
| 只有两个公开版本   | 版本选择、比较版本                           |
| 当前为 v3+         | 比较表单默认选择上一版与当前版               |
| 查看历史版本       | 选择器显示当前历史版本；状态块提供当前最新版 |
| 版本较多           | 选择器内部滚动，页面工具条尺寸不增长         |

## 空状态

### 无文章

```text
当前没有公开文章。
```

不显示分页、标签或伪造 Demo 卡片。

### 无标签

标签索引显示说明性空状态；文章页面不保留空标签容器。

### 标签无文章

正常构建流程不应产生。若数据变化导致出现，返回 404，而不是空标签页。

## 错误状态

- 同一标签生成相同 slug：构建失败并指出冲突。
- 版本缺号：构建失败。
- 单文件和版本目录并存：构建失败。
- 历史版本缺少日期或摘要：构建失败。
- 非法 Diff 端点：不生成静态路由。
- 两个相同 Diff 端点：阻止提交并显示文字错误。

## 删除清单

以下组件或逻辑在实施时删除：

- `KEEP EXPLORING` 文章尾部；
- 相邻文章计算；
- 上一篇和下一篇组件；
- 三种页面各自的顶部“返回”链接；
- 以说明句作为 H1 的列表配置；
- Diff 页自行定义的外层宽度和顶部间距。
