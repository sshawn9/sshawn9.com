# 信息架构与用户流

## 页面地图

```text
全局站点
└── 文章导航 /blog/
    ├── 文章索引 /blog/
    │   └── 分页 /blog/page/:page/
    ├── 标签索引 /blog/tags/
    │   └── 标签文章 /blog/tags/:tag/
    │       └── 标签分页 /blog/tags/:tag/page/:page/
    └── 文章 /blog/:slug/
        ├── 历史版本 /blog/:slug/v/:version/
        └── 版本比较 /blog/:slug/compare/:from...:to/
```

对应图形文件：[information-architecture.svg](./diagrams/information-architecture.svg)

## 页面身份

| 页面     | 页面任务               | 主标题内容                       | 父级     |
| -------- | ---------------------- | -------------------------------- | -------- |
| 文章索引 | 浏览全部文章           | 不设独立标题，直接进入工具与列表 | 全局站点 |
| 标签索引 | 浏览全部标签           | 主题索引                         | 文章索引 |
| 标签文章 | 浏览一个标签的文章     | `#标签名`                        | 标签索引 |
| 当前文章 | 阅读当前有效内容       | 文章标题                         | 文章索引 |
| 历史版本 | 阅读不可变快照         | 文章标题                         | 当前文章 |
| 版本比较 | 核对两个版本的实际差异 | `比较 vA 与 vB`                  | 当前文章 |

## 主流程

### 发现内容

```text
全局导航“文章”
→ 文章索引
→ 文章或标签
→ 当前文章
```

### 查看修订

```text
当前文章
→ 版本工具
→ 自由选择版本 A 和版本 B
→ Diff
```

### 阅读历史快照

```text
当前文章
→ 版本选择器
→ 固定历史版本
→ 历史状态提示
→ 阅读当前版本 或 与当前版本比较
```

## 文章索引入口

全局导航已经明确标识“文章”。文章索引不再重复设置编辑型 H1，也不添加解释列表作用的占位文案；进入页面后只显示文章数量、标签、文章列表和必要的分页。

SEO title 与 description 仍作为文档元数据存在，不进入可见内容层级。

## 排序和时间语义

- 文章索引以首次发布时间排序。
- 修订不会把旧文章伪装成新文章。
- 已修订文章同时展示首次发布时间和最近更新时间。

## 分页

- 默认每页 8 篇。
- 第一页使用 `/blog/`，不生成 `/blog/page/1/`。
- 第二页开始使用 `/blog/page/2/`。
- 标签列表使用相同规则。
- 分页只在总页数大于 1 时出现。
- 不增加按年份归档。
