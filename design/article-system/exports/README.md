# 设计评审导出

本目录保存由线框图和高保真原型导出的 PNG，用于无需运行项目的静态评审。

## 总览

- `wireframes-desktop.png`：桌面端全部低保真页面
- `wireframes-mobile.png`：移动端全部低保真页面
- `information-architecture.png`：信息架构图
- `version-navigation-flow.png`：多版本文章阅读流

## 高保真页面

每个核心页面同时导出桌面端和移动端：

- `prototype-articles-*`：文章索引
- `prototype-tags-*`：标签索引
- `prototype-tag-*`：标签文章列表
- `prototype-single-*`：普通文章
- `prototype-current-*`：多版本文章的当前版本
- `prototype-old-*`：固定历史版本
- `prototype-compare-*`：版本差异

静态截图仅用于快速检查；导航、主题切换及页面状态应在
[高保真原型](../prototype/index.html) 中评审。
