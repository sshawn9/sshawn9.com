# 响应式几何边界

- 目的：防止代表页面在四个宽度产生横向溢出或关键容器越界。
- 触发：依次访问八条代表路由，并在 320/768/1024/1440px 采样。
- 预期：根、body、关键容器和可见元素不产生横向溢出。
- 自动化覆盖：覆盖首页、博客、搜索、项目、研究文章与版本比较；固定研究图等待实际 SVG 可见并采样其根容器，交互 Frenet 仍等待绘图就绪；中英文平板尺寸触摸上下文实际点按导航、横竖屏切换并操作主题和菜单。
- 盲区：这是 Chromium 的固定路由、尺寸和触摸样本，不等同于真实 iPad/Safari 验收；忽略 KaTeX MathML，也不覆盖所有动态弹层或高度溢出。
