# 生产部署清单增减

验证生产部署前的两份清单校验，以及部署成功后从保存的旧清单和本次产物清单生成离线报告。

- 页面 HTML 不在资源增减中重复计数，保留入口页、404 页面和未引用资源。
- URL 查询参数、哈希文件名、外部资源分别比较；URL 不变时忽略标题、大小、构建标识和顺序变化。
- 缺失字段、重复 URL、无效 URL、预览清单、页面缺少 HTML 资源和站点不一致均拒绝比较。
- CLI 的 `--check` 模式只校验；缺文件或无效 JSON 返回失败，不生成报告；报告模式保留输入，生成完整 JSON/Markdown 并追加摘要。
- 摘要转义 Markdown/HTML，过大时限制展示列表但保留数量和完整报告。

在项目 devenv 中运行 `npm exec -- vitest run tests/development/inventory-diff/unit.test.ts`。测试使用隔离样例，不访问生产网站、不运行部署。
