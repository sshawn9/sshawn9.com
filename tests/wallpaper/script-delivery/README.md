# 壁纸启动脚本的内容寻址

- 开发态在隔离 Vite 实例中验证：请求脚本时才编译，重复请求复用结果，依赖变化后只重新编译一次；不启动独立监听进程。
- 浏览器测试验证构建页面引用真实存在、可按经典脚本解析的哈希脚本，且不带模块、异步或延迟执行属性；不依赖 `.cache` 中间文件。
- 进入关于页后，脚本地址不变、不重复请求，当前壁纸继续保留；逐帧首屏由相邻的 `warm-reload` 和 `appearance/theme-first-frame` 案例覆盖。
- 依赖已构建产物；不验证 Cloudflare 线上缓存头或旧部署文件保留。发布交界旧脚本不可用、需要刷新恢复是已接受的边界。
