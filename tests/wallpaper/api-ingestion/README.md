# 候选照片入池时过滤不支持的数据

模拟 Unsplash 搜索返回，检查尺寸、比例和公共照片字段符合现有规则，保存摄影署名与服务端下载上报地址，并且只发起一次搜索请求，不上报未使用的照片。

预置四张真正可读的旧照片，把同 ID 的坏候选与一张合格新照片一起返回。覆盖 HTTP 图片/页面地址、冒充 Unsplash 的域名、错误下载地址和缺失嵌套字段：坏候选不能覆盖旧照片，好候选正常加入；刷新前后均通过 Worker 的公开请求入口确认 API 返回 200，且响应不泄露下载上报地址。原实现在五类图片/页面 URL 异常下，更新后的 API 返回 503。

所有候选都不合格时，旧名单和更新时间不变，不写 KV。没有旧池时，过滤、去重后不足四张不能写入；正常去重、排序和 250 张上限另由 `api-pool-merge` 覆盖。

使用内存 KV 和模拟 fetch，不验证 Cloudflare 平台规则或真实 Unsplash 服务。
