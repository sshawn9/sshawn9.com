# 壁纸请求超时后取消连接并允许重试

浏览器回归覆盖照片名单和主动下载两种请求，各测试服务器不返回响应头、返回半份内容后不再发送两种情况。请求地址在测试中重定向到临时本地 HTTP 服务，保留浏览器原生 fetch、AbortSignal 和响应体读取；检查服务端连接关闭，不以按钮恢复代替网络取消。

另对两种请求验证 HTTP 503 已返回、错误响应体仍挂起的情况：立即取消不需要的响应体，不继续等到超时。

名单超时后，当前壁纸与队列不变，等待它的 Next 恢复可用；保留原有 30 秒退避，之后获取新名单、准备备用图并成功 Next。已有名单刷新失败后的保留与 5 小时节奏由 `manifest-refresh` 单元测试覆盖。

下载使用独立的 120 秒期限，不在名单的 60 秒期限到达时提前停止；暂停浏览器时钟后，检查到期前 1 毫秒仍等待、推进最后 1 毫秒后取消。超时不保存半份文件、不上报下载，不自动重试；再次点击能保存一次完整文件并仅上报一次，当前壁纸、主题和队列均不改变。

使用 Playwright 时钟推进等待，不实际等待两分钟。模拟图片和上报接口均在本地，不访问真实 Unsplash。验证 Chromium，不代表旧 Safari／iPad 实机验收；测试结束关闭本地服务与连接。
