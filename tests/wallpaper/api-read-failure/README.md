# 名单读取异常只在访客接口转换为 503

模拟 KV 读取拒绝，以及内存 KV 中真实无法解析的 JSON。通过 Worker 的实际请求入口验证 GET、HEAD 和合法下载上报 POST：返回不缓存的 503 与现有 Retry-After，HEAD 无响应体；每次读取失败记录一次原异常，不访问上游、不安排后台任务、不写入或修复 KV。

修复测试数据后再次请求，名单恢复读取、下载上报恢复执行，证明 Worker 没有缓存失败状态。无效方法、来源、内容类型及请求体仍先返回各自的错误，不因 KV 故障变成 503。

同样的读取异常进入定时更新时，等待任务必须继续拒绝、记录原始刷新错误并保留存储，不能把读取失败当成空池继续抓取和写入。

仅使用内存 KV 和模拟 fetch，不验证真实 Cloudflare 故障、线上日志保存或 Unsplash 服务。
