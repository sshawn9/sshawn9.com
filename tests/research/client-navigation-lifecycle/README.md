# 研究图表客户端导航生命周期

- 目的：避免静态研究图在离开并再次进入文章时残留旧节点或聚焦状态，也不重新引入绘图库运行时。
- 触发：从标签页进入文章、打开聚焦模式、离开，再次客户端进入。
- 预期：旧图移除，聚焦状态关闭；重进时两幅静态图的五个 SVG 子图可见，无 hydration island、加载提示、Plotly 容器/全局样式/运行时请求。
- 自动化覆盖：覆盖一次真实客户端离开/重进周期及代表性重复痕迹；真正交互 Frenet 的启动、失败、相机和控件测试另行保留。
- 盲区：运行时请求匹配依赖当前 Plotly 资源命名；四类图的内容、主题和响应式表现由 static-research-figures 覆盖。
