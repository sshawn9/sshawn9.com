# 研究图表聚焦模式

- 目的：保证聚焦模式移动而非复制现有图表实例，并在关闭时提交聚焦中的最新状态、恢复焦点与页面几何。
- 触发：修改 Frenet 参数，打开聚焦对话框，在其中再次修改后关闭；另以中英文入口核对按钮文案。
- 预期：同一 identity 节点往返，最终参数不回退，原生模态语义成立，触发按钮恢复焦点，页头几何和滚动不变。
- 自动化覆盖：覆盖按钮、Escape 与真实 dialog 外围点击关闭，并确认图注点击不误关；另覆盖节点身份、最新参数、分栏比例、中英文按钮文案及代表几何。相机通过共享 `plotly-camera.ts` 只读探针读取实际 renderer；Plotly 4 在 react 后可能留下过期的 layout 声明，不能用它证明画面。探针依赖内部接口，升级 Plotly 时需复核。
- 盲区：未证明所有浏览器的完整焦点圈定或屏幕阅读器实际朗读。
