# 拖动车辆改变位置并遵守模型边界

单元测试检查拖动改变位置、投影和转向但不改变航向，并将越界坐标限制在交互范围内。浏览器测试连续发送两个横纵位移，验证第二个位置成为释放后的稳定状态且旧事件不会随后回放；不将模型断言当作整幅图的视觉比较。

交互提示检查小车的抓取／拖动光标；从轮胎描边起手也应能拖动，不被上方绘制的车轮挡住。拖动后仍停留在项目列表，点击项目标题才进入详情。

鼠标按住拖动时用键盘切到 About，在松手前确认旧窗口监听与文字选择保护已经释放，再返回项目页确认可以重新拖动。另验证准备中的导航被同页锚点导航取消后，原图仍能继续拖动。

浏览器用例在内存中打包已安装的 d3-selection，通过公开接口读取窗口上的拖动监听，不读取或改写 D3 私有监听表。

触屏测试在有滚动空间的短屏视口，用 Chromium 的触摸输入验证移动、正常松手和取消；拖车时页面不滚动，从参考线或图中空白处划动时页面滚动、小车不动。这里检查实际滚动位置，不只读取 CSS 属性，不代表 Safari 或旧 iPad 实机验收。所有浏览器操作使用本地站点，壁纸 API 被固定响应替代；测试不生成额外网站产物。
