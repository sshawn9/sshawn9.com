# 构建期固定研究图

- 目的：四类固定图由真实 SVG 直接显示，保留图注、主题、响应式与聚焦，不再等待 Solid hydration 或 Plotly。
- 单元测试：验证坐标投影、曲率正负与固定左法向、正交标架和圆弧切向、车辆偏移与航向、双向距离箭头及两种速度分解的一致性。
- 导数标记：三个时间导数在构建期用 KaTeX `\dot` 排版，不使用普通带点字符。浏览器验证 MathML 重音语义、实际点/字母的相对位置、原有 18px 字号及窄宽/聚焦状态，不加载 KaTeX 或 Plotly 客户端脚本；几何检查使用当前 KaTeX 的重音标记结构，升级时需复核。
- 自动化覆盖：从中英文两篇真实构建页面的 HTTP 响应提取四类 SSR figure（含图注）、stylesheet links 和内联样式，以原构建 CSS 在禁用 JavaScript 的隔离组件文档中验证 3/2/1/2 个子图及代表标签。隔离文档保留 article-prose 样式上下文，但不包含站点全局字体门控包装，且剔除 script。有 JavaScript 的真实页面仍采样 390/1440px，检查子图正尺寸、真实绘制几何、标签包围框与横向边界，并确认不请求/初始化 Plotly；实际打开和 Escape 关闭四类聚焦图，验证同一个节点、图注、关闭后尺寸与焦点保留。
- 断言边界：不限定标签用 SVG text 或 HTML，也不要求窄屏重新排列子图。只找研究图契约，不把聚焦按钮的图标 SVG 算作图本体。
- 窄宽样本额外检查曲率公式说明背景透明、`T(s)` 向量标签保留衬底，防止新增衬底遮字；不要求本次消除旧版已有的文字重叠。
- 保留测试：Frenet 控件/3D 相机/WebGL/加载失败、ClosedLoop/Vega、MotionControl/D3 及其模型测试仍针对真正交互图，不因本次静态化删除。
- 盲区：隔离验收只证明图组件本体无需脚本绘制，不等于整站禁用 JavaScript 可读；现有 B06 字体策略仍会隐藏处于 loading 的页面字体表面，本次不改此策略，也不以删除真实页面 loading 属性绕过它。正尺寸和代表标签不能证明所有箭头方向、数学关系及全部标签无重叠；主题和窄屏可读性仍需与归档图形基线逐图视觉对照。禁用 JavaScript 不要求聚焦按钮可用；不等同于旧 iPad 浏览器验收。
