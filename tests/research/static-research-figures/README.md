# 构建期固定研究图

- 目的：四类固定图由真实 SVG 直接显示，保留图注、主题、响应式与聚焦，不再等待 Solid hydration 或 Plotly。
- 布局检查按文章独立运行，主题切换另按文章验证明暗两个方向；每条测试保留 60 秒上限，不让多篇文章和不同交互共用一份超时预算。布局保留原有平面图浅色、车辆图深色场景，显式设置主题，不依赖前一篇文章的操作。
- 单元测试：验证坐标投影、正交标架及左法向、两种速度分解的一致性。
- 导数标记：三个时间导数在构建期用 KaTeX `\dot` 排版，不使用普通带点字符。浏览器验证 MathML 重音语义、实际点/字母的相对位置、原有 18px 字号及窄宽/聚焦状态，不加载 KaTeX 或 Plotly 客户端脚本；几何检查使用当前 KaTeX 的重音标记结构，升级时需复核。
- 自动化覆盖：从中英文两篇真实构建页面的 HTTP 响应提取四类 SSR figure（含图注）、stylesheet links 和内联样式，以原构建 CSS 在禁用 JavaScript 的隔离组件文档中验证 3/2/1/2 个子图及代表标签。隔离文档保留 article-prose 样式上下文，但不包含站点全局字体门控包装，且剔除 script。有 JavaScript 的真实页面采样 320/390/768/1024/1440px，并在宽屏将实际正文限宽 360px 及当前三组换行临界宽度前后各 1px，验证多子图按可用宽度换行、图形等比例及零 Plotly 加载；真实操作文章侧栏调宽和折叠后再次检查完整标签；保留宽屏四图聚焦的节点、图注、尺寸和焦点检查。
- 完整标签边界：遍历每张子图卡片内的外层 `.research-label`、标题和说明，不重复计算 KaTeX 内部盒子或隐藏 MathML；独立固定各子图预期数量为 curvature `[4,4,4]`、heading `[3,4]`、state `[5]`、velocity `[4,4]`，不从同一渲染模型生成期待，防止删除难排标签后假通过。检查标签框及可见文本 Range 不越所属卡片、不横向裁切。两标签重叠宽高均超过 2px，且相交面积超过较小标签 10% 即失败，不设标签忽略名单。
- 窄屏聚焦：以 320px 平面图和 390px 车辆图覆盖四类，要求打开时处于顶部、关闭按钮完整进入视口、首张卡片开头可见；滚至图注后再次检查 sticky 关闭按钮完整可见且可直接命中，并实际点击关闭，恢复正文原位置、尺寸和焦点。原宽屏用例继续覆盖 Escape。
- 窄宽样本仍检查曲率公式说明背景透明、`T(s)` 向量标签保留衬底；本次已将完整可读与明显重叠纳入要求，不再豁免旧版已有的遮字。
- 保留测试：Frenet 控件/3D 相机/WebGL/加载失败、ClosedLoop/Vega、MotionControl/D3 及其模型测试仍针对真正交互图，不因本次静态化删除。
- 盲区：隔离验收只证明图组件本体无需脚本绘制，不等于整站禁用 JavaScript 可读；现有 B06 字体策略仍会隐藏处于 loading 的页面字体表面，本次不改此策略，也不以删除真实页面 loading 属性绕过它。矩形边界及显著相交阈值不能替代逐图视觉验收，也不证明箭头方向和数学关系；数学不变量与导数标记测试继续保留。禁用 JavaScript 不要求聚焦按钮可用；不等同于旧 iPad 浏览器验收。
