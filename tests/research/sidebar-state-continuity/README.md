# 文章 Sidebar 变化不重置研究图表

- 目的：验证文章 Sidebar 的折叠、展开和调宽只改变图表可用空间，不重建研究图表或恢复默认交互状态。
- 触发：调整双变量 Frenet 曲面的固定参数和三维相机后，依次折叠、展开并调宽右侧 Sidebar。
- 预期：图表节点身份、参数状态和相机保持不变，图表宽度响应新的正文空间。
- 自动化覆盖：覆盖桌面端键盘 Sidebar 操作及代表性参数、相机和容器几何。共享 `plotly-camera.ts` 只读探针读取实际 renderer，避免 react 后过期 layout 造成假绿；这是集中的 Plotly 4 内部接口耦合，升级时需复核。
- 盲区：未覆盖 Sidebar 指针拖拽、所有研究图和连续动画进度。
