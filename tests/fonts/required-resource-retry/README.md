# 必需字体失败与重试

字体是新内容提交的必要条件，实际文件不可用时持续重试原资源，不以备用字体或超时放行。字体保持为独立文件，不包装成携带字体数据的 JS。

- 首次直达首页、中文列表、代码文章、公式文章和 404：分别中止字体文件、返回 503 或无效字体字节。至少两轮重试期间，正文保持未挂载，字体状态不就绪，首帧就绪标记不存在；恢复后才提交正确字体的内容。
- 站内导航：目标字体失败时旧 main 和正文保持可见；恢复后提交。新导航取消旧任务后，不再发出旧任务的后续重试。
- Manrope：只中止标题字体文件，其他字体可以成功；等待期不能显示标题，恢复后的首批标题宽度必须与原页面一致。
- 必需样式：正文样式失败时也不得提前提交。目标页面样式失败时保留旧页，恢复后提交；取消则停止后续重试。

- 样式与中文字体同时失败后恢复，再往返博客和 About：保留恢复后的样式节点，实际中文字体持续可用；文件路径或其他查询参数不同的目标样式必须正常替换。

本组验证资源与提交条件；原生刷新画面连续性仍由 `tests/navigation/refresh-continuity` 和真实窗口像素另行核对，不能用本组通过替代。
