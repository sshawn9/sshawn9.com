# 导航字体事务

- 目的：保证客户端导航在目标字体准备前保留旧页，并让最新导航独占提交、busy、ready、进度阶段与滚动状态。
- 触发：阻塞数学文章字体超过两个进度周期；连续发起分别等待 KaTeX 与中文字体的 A→B 导航。
- 预期：目标字体未 ready 时，新一段等待在 120ms 显示计时器触发后进入 `active`；进入后，旧页、pending、反馈阶段、透明度和动画 CSS 声明不能中断。旧版轨迹允许条段阶段性离开视口；A→B 同步接管不能丢失 active 所有权，A 的字体晚到不能结束 B。后退取消立即清理。
- 自动化覆盖：等待、提交、后退取消、active 阶段的连续导航接管；精确延迟和 active 阶段最短时长由单元测试覆盖，不将其解释为连续屏内可见时长。
- 盲区：网络请求可能在事务取消后继续完成；用例验证的是这些过期结果不能取得 UI 和文档状态所有权。

首次文档的正文先保留在未挂载的 HTML 模板中，字体就绪后提交；已显示页面的站内导航仍由当前 Document 准备目标。迟到回调的 body 身份隔离由 `tests/navigation/initial-document-failure/` 核对，真实刷新另行验收。
