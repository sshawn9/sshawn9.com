# 文档字体加载门

- 目的：避免冷启动、404 和字体失败时暴露回退字体正文，同时保持等待反馈状态。
- 触发：分别延迟或中止真实 woff2 请求；延迟分支覆盖正常和减少动态效果偏好。
- 预期：所有采样 loading 帧都隐藏字体表面，且进度元素保持不透明、动画 CSS 声明保持启用；这不等于条段持续位于屏内。旧版轨迹保留离屏阶段，减少动态效果遵循全局 0.01ms、单次动画规则，结束后不显示静态条段。释放后才 ready、显示并保持几何稳定；失败超过两个完整进度周期后仍不超时、不 fallback、不假 ready。
- 自动化覆盖：慢字体、失败、减少动态效果、首次 404 响应，以及成功后的中文字体和逐帧几何。逐帧检查所有已登记字体表面，同时独立采样普通页面的 Header、“跳过正文”入口和正文容器，避免丢失登记标记后漏检；成功后这三个区域都须解除字体隐藏。
- 盲区：失败用例证明的是超过两个周期的观察窗，而不是数学意义上的无限期；像素截图由独立的 progress-visibility 用例负责。
