# 目录导航与阅读高亮

手动阅读时优先选中可阅读区域内第一个可见标题，排除顶部导航栏的遮挡。没有可见标题时，选择当前正文所属章节，不能盲目保留上一次结果；向上滚动或跳过标题也应正确。只有结果变化才更新高亮。点击目录或打开章节链接会明确选中目标，实际手动滚动正文后再进入自动跟随。

真实文章用闭环控制时序的中文锚点复现页尾问题，覆盖首次打开章节链接、同位置目录切换、前进后退和刷新。手动滚离再回到页尾并刷新，URL 中旧锚点不能重新覆盖当前阅读状态。明确目标或自动跟随状态与滚动位置一起保存在现有历史记录中，不根据坐标猜测用户意图。

固定正文几何的浏览器场景验证第一可见标题优先于正文占比；长节没有可见标题时向下继续跟随，向上回到上一节时正确切换。内容高度变化和窗口变化都重新计算；该场景不依赖发布文章的内容长度。

同位置目录点击也须保存实际坐标和选择状态。正文平滑跳转时滚动侧栏不能取消所选章节，随后手动滚动正文才交回自动跟随。跨页面历史导航尚在加载时，旧文章不得读取目标页面的历史状态。普通章节、嵌套目录滚动位置恢复，以及点击的取消和新标签语义由相邻 toc-scroll-history、toc-click-intent 场景覆盖。不专项支持在已打开页面手动修改地址栏锚点或通过 `location.hash` 绕过站内导航。
