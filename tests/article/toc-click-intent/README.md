# 目录只响应作用于当前文章的点击

Ctrl 点击、中键和 `target="_blank"` 用真实浏览器操作打开目标页面，确认目标章节可见，同时原页面的 URL、正文位置、目录位置和高亮保持不变。测试只关闭自己打开的窗口。

已经在链接处取消的点击不能改变目录。Meta/Shift/Alt、非主键、下载链接、其他页面或查询、错误或不匹配的锚点另用合成点击覆盖目录判断；这些用例在目录处理之后阻止实际导航，不把其他操作系统的快捷键行为当成已验证。

键盘 Enter 验证百分号编码的中文锚点：先确认目标未高亮，再在目录点击处理之后、Astro 跳转之前同步记录高亮，最后检查 URL 和标题位置。这样不能靠后续滚动补上高亮来掩盖点击处理被错误跳过。触屏点击验证取消时手机目录保持打开、随后有效点击仍能跳转并关闭目录。正常滚动、刷新与历史恢复及宽屏 Popover 边界继续由相邻案例覆盖。

取消状态在目录处理入口判断。这里验证提前取消，不承诺撤销任何后置处理器造成的导航变化；Astro 在后面的 document 监听中阻止默认动作并执行正常导航，不应被误判为取消。
