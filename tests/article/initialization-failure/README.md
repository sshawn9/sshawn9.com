# 文章增强初始化回滚

单元测试验证文章组合逆序回收、销毁异常不阻断其他子项、幂等销毁，以及侧栏／目录在返回控制器之前失败时撤下已安装监听。媒体覆盖同步样式安装失败、Lightbox 已绑定点击后初始化失败的局部回退，以及开场期间销毁后仍由原 viewer 完成延迟关闭。

使用 linkedom DOM、显式窗口事件夹具和模拟 PhotoSwipe；linkedom 不支持的监听 signal 选项由夹具连接到真实 AbortSignal。异常是定向注入，不代表已观察到浏览器自然故障。保留正文、普通图片链接、共享样式与持久偏好，不验证真实图库动画、布局、焦点或原生新标签行为；这些仍由现有浏览器测试负责。
