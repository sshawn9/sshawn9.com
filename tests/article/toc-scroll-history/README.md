# 目录、片段与滚动历史

- 目的：验证滚轮输入属于其命中的正文或侧栏，目录点击同步 URL/活动项，并恢复页面与目录位置。
- 触发：在目录及其末端滚轮滚动、在正文滚动、点击中后部目录项，再刷新并离开文章后返回。
- 预期：目录滚动和边界不移动页面，正文仍可滚动；选中切换不改变目录行与邻项几何；页面落在目标标题，刷新和 back 的首批样本恢复目录位置与活动项。
- 自动化覆盖：覆盖 wheel 所有权、边界滚动链、片段定位、目录选中几何、页面与目录 scroll、active TOC、reload 和 back。
- 盲区：FCP 回调采样不代表预绘制；正文滚动可以为保持活动章节可见而自动调整目录位置。
