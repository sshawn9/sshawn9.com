# 旧版进度条视觉回归

本用例把 `ee23e94` 中字体修复前的 Header 进度条 CSS 固定为测试内参考，并在同一 Header 内创建 `visibility: hidden` 的参考条段。参考类、动画名和 `@keyframes` 均已重命名，不会覆盖生产动画；状态选择器仍读取真实的 `data-font-state` 与 `data-navigation-progress`。

正常动态效果下，测试在旧动画的多个确定相位逐项比较实际条段与参考条段的真实包围盒、26% 宽度、2px 厚度、颜色和透明度。旧轨迹按条段自身宽度从 `translateX(-110%)` 移至 `390%`，因此起点完全位于 Header 左侧、末尾完全位于右侧；这些离屏阶段属于被确认保留的旧视觉，不再要求每帧可见。完成阶段还验证条段先移到右侧再进行 120ms 淡出，而不是停在原处淡出；idle 恢复旧起点与透明状态。

减少动态效果时不另造组件特例，而是对照旧版所受的全局 `0.01ms`、单次动画规则及其最终离屏位置。截图固定在正常动画中点，避免把旧版有意存在的离屏帧误作视觉证据。低高度视口滚动则确认进度条仍属于 Header，而不是独立固定在视口上。

确定性推进 Web Animation 用于精确比较历史轨迹，不能替代连续播放的主观观感检查；缓存与字体提交行为由 `tests/fonts/` 覆盖。
