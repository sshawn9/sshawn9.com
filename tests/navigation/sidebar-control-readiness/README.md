# 侧栏控件只在初始化完成后启用

博客和文章桌面侧栏折叠按钮、博客窄屏标签折叠按钮依赖 JS；静态 HTML 默认禁用。两种桌面调宽柄默认 `tabindex="-1"`、`aria-disabled="true"`，控制器完成监听与初始状态设置后才启用。

浏览器测试延迟真正的 SiteRuntime 模块，检查静态控件状态和 Tab 无法进入按钮／调宽柄，但正文与普通标签／目录链接可用。放行模块后检查按钮、键盘调宽或窄屏折叠实际工作，并逐像素比较启用前后的按钮截图，防止增加灰态闪变；模块加载失败时仍保持禁用且普通链接可导航。

覆盖 1440px 博客、1440px 文章和 390px 博客。初始化中途失败及重新进入的回归复用既有 sidebar-rollback 与 initialization-failure 案例。不修改字体等待、原生弹层或其他按钮，只用本地预览，不请求线上壁纸 API。
