# 主题与文章首批帧

- 目的：确认保存的深色主题、字体等待门和文章标题几何在 FCP 后的每一采样帧保持一致。
- 触发：预置深色主题，从 FCP 后连续采样，直至取得八个 ready 帧；期间保留并检查所有 loading 帧。
- 预期：主题始终为深色；合法状态序列为同步 ready 或 `loading → ready`，不得倒退。loading 帧正文隐藏，进度元素保持不透明并启用动画；旧版轨迹允许条段阶段性离开视口。ready 帧正文可见、标题使用 Manrope 且几何稳定。
- 自动化覆盖：使用 PerformanceObserver 加 rAF 读取文章标题、字体表面与进度反馈状态，并验证 ready 后的标题 CSS 几何。
- 盲区：采样从 FCP 通知后开始，不证明预绘制状态或每个真实合成帧。
