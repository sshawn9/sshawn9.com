# 博客筛选、分页与历史使用一致状态

单元测试以多值、大小写混合标签和越界页码验证并集筛选、标签排序与规范 URL。浏览器测试增减标签、同帧连续点击、离开后返回和历史遍历，检查选中标签及结果对应，并确认标签目录的顺序、行几何和滚动位置不因选中态变化；保留减少动态效果和缺少 View Transition 时的变体。

浏览器测试通过 `../browser-fixtures.ts` 注入固定文章和标签，使用真实页面的脚本与样式。数据包含单标签文章、交集和无关文章，Beta 在目录中排在 Alpha 前面，另有足够标签产生侧栏滚动；断言具体筛选结果及目录顺序规范化后的 URL，不依赖发布内容或草稿状态。离开列表时进入固定的 About 路由。
