# 集中分页

分页只有一组原生链接，放在博客根节点内；宽裕的右侧留白使用竖排，其余使用底部横排。位置以当前可见视口和内容边界决定，分页状态继续由 URL 推导。底部预留空间在历史滚动恢复前准备，离开页面时清理。

横向边界复用竖排测量阶段的原生固定定位参考框，遵从根元素已有的 `scrollbar-gutter: stable`。`clientWidth` 与 `VisualViewport.width` 在滚动条消失时会重新包含预留区，不能单独作为定位边界；根元素自身还可能受最小宽度影响。浏览器回归显式移除 Playwright 的 `--hide-scrollbars` 参数，检查 1920、1280、390、320px 下滚动条显隐及翻页过程中的逐帧位置。

桌面使用两枚独立的 52px 圆形按钮，距右侧安全边缘 32px，上下箭头对应上一页、下一页；页码放在下方，显示 `1 / 4`，保留分隔符两侧间距。窄屏改为 48px 圆形按钮横排，页码居中、操作名称常驻；触屏的侧边布局同样显示操作名称。读屏仍保留完整的本地化页码描述。

底部模式以页面底色渐隐遮住控件后方经过的正文，防止标题与页码、操作名称重叠；背景不截获点击，也不参与控件尺寸与滚动预留的计算。

照片署名与底部分页横向相交时，分页置于署名上方，并随署名出现、消失和换行重新测量；渐隐背景及滚动预留包含这部分实际间距。

侧边提示包含操作名称和目标页，在悬停及键盘聚焦时显示；鼠标可移到提示上，Esc 关闭后保持关闭，直到鼠标与键盘焦点都离开当前链接。提示文案随分页状态更新，禁用链接不显示提示。可见性及位置由 CSS 负责，Esc 监听归属页面现有的 AbortSignal，不引入分页业务状态。

桌面页脚链接位于左侧，不与居中的底部控件重叠，文章已有页脚及页面间距作为余量；不额外拉长页脚之后的空白，以保留侧栏的底部边界。窄屏额外预留底部空间，保证页脚链接可见。篇数菜单的向上翻转用例将触发区域放在分页条上方；内部滚动用例使用 preventScroll 聚焦，区分浏览器揭示焦点与菜单自身滚动。

滚动安全距离只作用于文章区控件和窄屏页脚。整页设置 scroll-padding-bottom 会把未被分页遮挡的左侧标签面板也视为需要避让，导致聚焦或滚入视口时牵动整页滚动。

捏合放大可能只改变 VisualViewport，桌面媒体查询仍然成立；此时同样预留底部空间，防止放大后的分页覆盖页脚链接。

回归覆盖固定位置、连续操作、首末页、窗口切换时的焦点和文章集合、触屏目标、菜单取消、控件隐藏后的焦点及资源清理。提示用例检查中英文名称与目标页文案，并在英文页面验证翻页后的目标页更新，以及键盘 Esc 关闭后焦点保留。几何单元用例覆盖可见边界、向上和向下定位、极短视口。Chromium 的 VisualViewport 缩放通过 CDP 验证，不能代替浏览器工具栏缩放或真实 Safari/iOS 的操作验收。

分页使用局部视图导航队列和历史提交。内容提交失败时重新加载当前记录；布局与滚动定位失败只报告错误，不回滚内容或触发整页重载。
