# 博客每页篇数

详细模式默认 5 篇，预设 5、10、20、50；紧凑模式默认 15 篇，预设 15、50、100。两种模式的篇数独立保存，共用分页计算；各标签页保持自己的设置，缺少标签页记录时才读取最近确认的长期记录作为初值。URL 只表达标签与页码；每页篇数由独立的阅读偏好提供。纯状态函数显式接收偏好，不读取浏览器存储。

改变篇数保留当前页码，越界时静默限制到末页；后续操作基于限制后的页码。筛选回到第一页并保留偏好。设置变更不新增历史记录，越界仅替换当前 URL；前进、后退恢复路由并使用当前偏好，不恢复历史篇数。

切换篇数不主动滚动，当前位置在更新后的页面范围内时保持。回归用例在桌面与手机宽度下，从页面顶部及略微下滚的位置连续切换各预设，并逐帧检查没有平滑滚动造成的偏移。上一页、下一页沿用分页控件的列表定位规则。

纯状态测试用完整中间页和不足整页的末页检查文章范围，覆盖空结果、非法参数、筛选与页码归一，并逐页验证各预设无遗漏无重复、URL 规范化幂等。浏览器测试覆盖实际范围、焦点、原 DOM 保留、无 HTML 请求、连续操作及历史顺序、刷新、独立新标签页，以及离开页面时取消旧视图工作但保留已经确认的偏好。真实分页导航提交后渲染异常的恢复由故障注入验证；带 hash 的越界、继续翻页和滚动位置保持均有浏览器回归。URL 不变时直接刷新；越界时通过 Astro replace 同步路由和历史，不新增记录。滚动或布局失败只报告错误，不重载已正确渲染的内容，相关异常处理由导航协调器单元测试覆盖。

阅读偏好的存储边界由相邻 page-size-preference 测试覆盖，模式和篇数的跨标签页隔离由 compact-mode 浏览器测试覆盖。浏览器基于当前至少三页的博客语料，纯状态测试提供较大数据集。
