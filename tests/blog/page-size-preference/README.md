# 博客阅读偏好

每页篇数在当前 Window 中只有一个所有者，由首帧脚本与主运行时共享；确认选择后立即保存到 localStorage。页面控制器订阅变更，离开页面后撤销订阅。确认值不属于 URL 或历史记录，取消菜单定位不提交设置。

导航栏返回博客时回到第一页并保留偏好；文章、其他页面、语言切换和下次访问使用同一偏好。存储写入失败时保留当前 Window 的内存值，客户端导航继续可用，完整重载不承诺保留。非法存储值使用默认 5。

其他标签页通过 storage 事件重新读取偏好，当前标签页直接通知订阅者，不等待自身不会收到的 storage 事件。pageshow 重新核对存储；订阅全部释放后移除全局监听，后续挂载重新读取。偏好变更与分页命令按输入顺序处理，离开旧页面只取消渲染任务，不取消已保存的选择。如果同页锚点取消导航、仍保留原页面，则在确认没有替代导航后重新应用当前偏好。

单元测试覆盖所有者复用、写入与订阅释放、存储事件与清空、读写异常和内存值保持。浏览器测试覆盖桌面和手机导航栏返回、跨页面和保存存储状态后的新访问、两个真实标签页同步、禁用存储后的客户端导航、历史页越界、可见首帧、目标文档已准备后的跨标签页更新、原生锚点取消分页、导航栏及文档导航（包括取消后继续翻页和改篇数），以及 pageshow 重新核对。手机导航返回博客还检查菜单关闭。pageshow 用例人工发送持久化事件，不把它等同于所有浏览器 BFCache 驱逐和恢复策略的实机验收。
