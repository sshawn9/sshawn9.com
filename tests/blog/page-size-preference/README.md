# 博客阅读偏好

显示模式、详细模式篇数和紧凑模式篇数分别属于当前标签页。首次取得设置时，各项优先使用 sessionStorage 中本标签页的记录；缺失的项目读取 localStorage 中最近一次主动确认的值，仍无记录才使用默认值。三项解析后的初值全部写入 sessionStorage，保证未修改过的项目在刷新后也不会被其他标签页覆盖。初始化与恢复不写入 localStorage。

用户确认某项设置时，只把这一项写入当前标签页的 sessionStorage 和供以后访问使用的 localStorage。其他标签页保持自己的模式和两套篇数，已经打开的菜单及聚焦的文章也不受影响。读取设置、刷新、pageshow、站内导航及语言切换均不重新套用其他标签页的值，不回写本标签页的旧值。取消菜单定位不提交设置，偏好不进入 URL 或历史记录。

首帧脚本与主运行时共享当前 Window 的同一所有者，向当前页面报告本地操作或本标签页缓存恢复带来的设置变化，离开页面时释放页面监听。不监听跨标签页 storage 事件，也不在挂载页面时重新读取长期记录。完整文档重新载入后，从 sessionStorage 恢复本标签页；浏览器从后退缓存恢复旧文档时，也重新读取 sessionStorage 中本标签页的最新设置，不读取或回写 localStorage，记录不可读取或缺失时保留内存值。这项恢复不依赖博客页面是否已经挂载。浏览器已有的会话副本同样按本标签页记录处理，之后各自独立。

两种存储分别尝试写入：长期存储失败时，标签页记录仍可保留本页选择；标签页存储不可用时，本次文档内仍保留内存值，但不能保证完整重载后维持独立设置。全部存储不可用时仍能切换模式和篇数。非法记录使用对应默认值：详细模式 5 篇、紧凑模式 15 篇、显示方式为详细模式。

导航栏返回博客时回到第一页并保留本标签页设置。偏好变更与分页命令继续按输入顺序处理；离开旧页面只取消渲染任务，不取消已确认的选择。同页锚点取消导航、仍保留原页面时，重新应用本标签页当前设置。

单元验证覆盖初始化保存三项本地值、未挂载和重新挂载页面、外部修改、pageshow、刷新、按项更新未来默认值、存储异常和监听释放。浏览器验证覆盖真实标签页独立、普通新标签页与下次访问继承记录、刷新与导航保留、两套篇数分别保持、首帧显示、文档准备期间其他标签页修改，以及本地确认后的导航取消。普通 pageshow 用例人工发送持久化事件；独立的后退缓存回归仅为该用例解除 Playwright 的禁用参数，实际执行整页导航后的后退，检查保留的文档标记、persisted 状态、两套篇数及另一标签页的隔离；再前进时检查最新设置仍保留，不要求浏览器一定保留前进缓存。Chromium 验证不等同于所有浏览器缓存策略的实机验收。
