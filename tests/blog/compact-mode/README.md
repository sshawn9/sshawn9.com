# 博客详细 / 紧凑模式

两种模式共用筛选、页码及分页计算。详细模式默认 5 篇，可选 5 / 10 / 20 / 50；紧凑模式只显示完整标题，默认 15 篇，可选 15 / 50 / 100。显示模式与两种篇数按标签页独立保存；新标签页缺少自己的记录时，以最近主动确认的长期记录作为初值，不写入 URL。模式切换按有效篇数重新计算，保留有效页码，越界时静默 replace 到末页，不新增历史记录。

工具栏左侧是“紧凑模式”（英文 Compact）滑动开关，文字和轨道整组可点击，文案始终不变；通过圆点位置、轨道颜色和 aria-checked 表达状态，无勾号，右侧是篇数，中间靠右显示范围；窄栏将统计移至下一行。标题可换行，紧凑模式整行可点击。首帧准备与站内导航准备读取同一偏好所有者；菜单的键盘操作仅遍历当前模式的选项，当前标签页切换模式时关闭旧菜单，其他标签页的修改不影响本页；若聚焦的文章标签被隐藏，则将焦点移到同篇标题，聚焦的文章不在当前页时移到结果统计，可见标题保持原焦点。

浏览器回归覆盖快速连续切换、Enter / Space 操作、按钮宽度稳定、独立偏好、站内返回、刷新、语言切换和下次访问；固定文章数量的响应夹具验证连续切换、紧凑分页、越界和焦点恢复；覆盖原生 Popover 与回退、动态选项的键盘选择、真实标签页独立与按项继承、可见首帧，以及中英文宽窄布局。单元测试在相邻 page-size 和 page-size-preference 中验证计算与存储边界。
