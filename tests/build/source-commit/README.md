# About 页脚显示构建来源提交

- 中英文 About 在原有页脚标识的位置显示 `SHAWN@<前 7 位 SHA>`，保留原有样式；构建 HTML 已包含当前检出提交的 GitHub 链接，悬停可查看完整 SHA，不依赖客户端取值。
- 点击后在新标签页打开对应提交，原页面保持不变，新页面不能访问 opener；测试拦截 GitHub 导航，不访问外网。
- 从博客进入 About、刷新、离开及后退时，SHA 只出现在 About 页脚，不进入正文或残留在其他页面。
- 其他页面保留原有 `SHAWN` 首页链接；About 在 320px 和桌面宽度下只显示一个标识，不造成横向溢出。
- SHA 标识源码提交，与构建 ID 无关；它不证明所有资源绝不混版，也不包含本地未提交修改。测试期间不改变 HEAD，不访问 GitHub。
