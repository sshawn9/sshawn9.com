# 构建资源清单

验证离线清单能描述同一次构建的页面、资源及双向关系，同时不改变网站产物和加载策略。

- 原生依赖采集开启前后，隔离样例的 JS/CSS 文件名和内容一致；共享脚本、动态导入和样式依赖可读。
- Pagefind API 的初始化、索引、写入错误会阻止构建继续，并始终关闭后台服务；浏览器验收使用集成生成的实际搜索产物。
- HTML/CSS/模块引用按语法解析；普通导航链接、JSON 脚本不当作资源请求。大小图、模板资源和延迟脚本使用同一份关联集合；无画廊的页面不包含 PhotoSwipe。
- 字体根据页面文字、固定交互脚本文字和实际字体规则匹配 `unicode-range`，包括代码树形符号使用的回退分片；不会把全部全局声明都分配给每一页。
- 每个页面包含自身 HTML，公共资源去重，循环引用终止；正反关系一致，查询参数保留、片段去除。
- 大小按实际字节和 Node 默认 Brotli 计算；预压缩文件保持原大小。页面与全站合计按物理文件去重，不因查询参数、路径别名或跨页共享重复计数；缺失和外部资源明确显示未知，Markdown 与 JSON 使用同一份合计。
- 搜索只关联当前语言的索引和全部结果数据，Worker 不依赖第三方源码的空格或变量名；不包含备用 UI 或结果指向的文章资源。只忽略明确未使用的备用 UI 告警，不屏蔽其他未归属脚本的异常；版本数据只从版本比较组件的 sourceHref 提取。
- 最终产物名单和 SHA-256 在分析前校验：只缺一个结果分片、索引分片或 Worker 也会失败，CSS/JS/图片/响应头被改动同样被拒绝；旧字体规则或旧格式构建信息不可混用。
- CLI 在分析出错时不改旧报告；两个临时文件均写好后才开始替换，临时写入失败会清理临时文件而不替换正式报告。
- Markdown 从同一份分析结果生成，保留构建标识、完整双向关系和警告，提供索引、折叠详情和易读大小；不修改 JSON 数据，并转义标题与诊断中的 Markdown/HTML 特殊字符。
- 浏览器抽查普通文章、研究图、比较页、图片查看器和搜索的实际同源资源请求，以及中文 About、公式页和客户端交互图的冷启动字体请求。浏览器只用于验收，不参与日常清单生成。

已有构建时执行 `npm exec -- playwright test tests/build/resource-inventory/browser.spec.ts`；纯离线单测执行 `npm exec -- vitest run tests/build/resource-inventory/unit.test.ts`。完整验证仍使用根目录原有 `npm test`。

这不是缓存命中或多地测速测试。字体分析保守包含声明的回退字体、格式及交互文案变体，不声称每次访问都会下载；随机壁纸、外部 iframe 内部及任意动态计算的地址不在静态分析保证范围。
