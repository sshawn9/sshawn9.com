# 字体排版依赖缓存边界

- 目的：确保 Noto Sans SC 与 KaTeX 保持为独立、可长期缓存的全局 CSS，不随本站 CSS 改动换哈希。
- 自动化覆盖：真实 Vite 内存构建验证 `CSS ?url` 的哈希隔离；真实站点产物验证普通页面和独立 404 共用同一文件、其字体引用均已生成且 vendor 位于本站样式之前；浏览器验证从关于页导航到含中文和公式的文章后 URL、字体声明及本站公式样式仍可用。
- 盲区：不重复测试字体预加载、按需字体选择、加载门控和失败恢复；这些由 `tests/fonts/` 覆盖。未跨依赖升级比较 vendor 哈希，依赖内容变化时哈希应正常变化。
