# 新部署不沿用旧搜索索引

使用已构建的搜索页面和当前 Pagefind 创建的两份小型真实索引，在同一个本地 HTTP 地址依次提供部署 A、B。入口索引按站点的一年不可变策略缓存；不使用 Playwright 请求拦截（它会关闭 HTTP 缓存）。

先查询 A，再重新进入同部署确认入口确实命中浏览器缓存，最后更新 HTML 构建标识和索引。B 必须请求带新标识的入口并显示 B 的内容，不能显示 A。服务器和索引进程在案例结束后关闭，不另跑站点构建。

这里验证缓存协议；实际构建产物中 HTML、客户端和搜索标识一致由 build/artifact-identity 覆盖。不会模拟完整 Cloudflare 发布流程。
