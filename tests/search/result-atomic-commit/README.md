# 搜索结果原子提交

- 目的：让结果、摘要和所需字体作为一次可用替换提交；慢请求或刷新失败时保留旧结果。
- 触发：执行暖查询，并分别延迟片段、阻塞字体或中止片段请求。
- 预期：等待期旧卡片/摘要可见，成功后新 query 与摘要一起更新；失败时旧结果仍可用且区域内报错。
- 自动化覆盖：普通、慢片段、超过 10 秒数据响应期限的字体等待、请求失败和超时；失败后实际打开旧卡片，超时后执行新查询，旧响应迟到不得覆盖新结果。
- 盲区：rAF 仅证明采样帧非空；没有直接统计提交次数或验证字体网络像素。

结果片段齐备后停止数据响应超时，字体继续等待并重试；只有当前查询被替换或页面离开才取消这段字体准备。
