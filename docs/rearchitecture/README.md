## 当前边界

- `docs/site-behavior-cases/` 中的用户体验回退规范全部生效；实现说明、部署规则和测试方法不再混入行为契约。
- 当前生产站仍由旧根应用构建；v2 在 M5/M6 完成前不得提前删除旧回滚来源。
- 页面视觉、动画、交互和内容语义没有因技术重构自动获得变更授权。
- Cloudflare Static Assets 仍是优先目标；普通 HTML 和静态资源不得无理由进入 Worker。
- 代码的人类可读性、状态所有权和可删除性与行为正确同属验收条件。
