# 全站重构阶段 0：契约与证据基线

- 状态：已完成
- 开始日期：2026-08-28
- 完成日期：2026-08-29
- 本阶段允许的用户可见变化：无

## 目标

在编写新运行时之前，先把用户体验契约、测试证据、架构边界和审批流程变成可执行约束。阶段 0 不修改生产页面、视觉或交互。

## 已确认的设计原则

1. `docs/site-behavior-cases/` 是行为事实来源，测试和实现只能提供证据。
2. 当前 190 个案例全部生效；技术重构不自动授权行为回退。
3. 视觉、交互、内容和其他用户可见变化必须先形成提案并获得明确批准。
4. Cloudflare 免费 Static Assets 是优先部署目标，但平台名称不是永久产品契约。
5. 人类可读性和长期维护性属于验收条件；行为正确但设计不可维护的 POC 不得进入生产。
6. 新架构不能把旧实现中的全局事件、隐式状态和时序补丁原样搬到另一个框架。

## 阶段产物

- 行为契约治理和变更提案流程；
- 当前自动化、视觉、人工和平台证据基线；
- 自动检查行为案例目录、数量、索引和文档结构的单元测试；
- 目标架构 ADR，包括状态所有权、导航事务、字体、滚动和部署代际；
- Astro/ClientRouter 与 Qwik City 两个垂直切片的同条件验证计划；
- 迁移顺序、回滚路径和生产切换门槛。

当前设计产物见：

- [ADR-001：静态文档应用](./ADR-001-static-document-application.md)
- [ADR-002：客户端运行时与状态所有权](./ADR-002-client-runtime-and-state-ownership.md)
- [双垂直切片验证计划](./POC-PLAN.md)
- [迁移与回滚计划](./MIGRATION.md)

## 不在本阶段执行

- 不删除 Swup；
- 不引入 Svelte 或 Qwik 生产依赖；
- 不修改页面布局、动画、字体、颜色或交互语义；
- 不替换生产路由；
- 不修改 Cloudflare 线上配置。

## 质量约束

垂直切片必须采用生产级边界，而不是一次性 Demo：

- 状态所有权、依赖方向和销毁时机必须可从模块接口直接理解；
- 状态机使用可穷举的类型，不依赖散落的布尔值和事件顺序；
- 浏览器 API 隔离在适配器边界，领域逻辑可以独立单元测试；
- 行为测试不允许依赖框架私有对象或内部 CSS 类；
- 性能优化必须有测量结果，不能以增加不可解释复杂度换取假设收益；
- POC 中的临时代码不得直接复制进正式实现。

## 阶段退出条件

1. 190 个案例的结构和索引由自动测试保护；
2. 测试证据缺口按行为领域记录，并为垂直切片规定最低门槛；
3. 所有建议行为变化都有独立提案且未经批准不会进入实现；
4. 目标架构 ADR 经讨论确认；
5. 两个垂直切片使用同一代表路径、网络条件和验收案例；
6. 正式迁移可以与现有站点并行开发、独立预览和独立回滚。
