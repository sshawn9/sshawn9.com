## 架构结论

保留 Astro SSG、Static Assets、官方 ClientRouter、持久 SiteShell、按页增强和现有 Worker/KV 壁纸清单。已知故障来自视觉合成和首帧所有权的实现偏差，不要求推翻静态文档应用路线。

## 已确认根因与修正

1. **主题切换把整个文档截图后交叉淡化。** View Transition 伪元素脱离正常层叠，半透明 sticky header 背后的正文截图能被合成到 header 前面，任何操作也会出现整页变暗的中间帧。修正为注册语义颜色和透明度 token，直接在实时 DOM 上过渡；主题切换不再调用 `startViewTransition()`。
2. **壁纸曾同时存在 boot、运行时图层和响应式 URL 三套状态。** 现在独立 WallpaperSystem 每标签页只保存当前/下一张两个完整槽位；同一个启动函数读取当前字节并投影，随后异步补齐下一张，不再发生同图接管。
3. **新照片视觉状态和刷新状态曾非原子。** 现在照片先完成下载、校验、解码和槽位写入，再通过当前指针一次提交；快速刷新只可能恢复事务提交前或提交后的完整状态。
4. **页面导航截图必须低于持久 header。** root、page outlet、site header 使用明确 View Transition 层级；header 自身不动画，正文转场不能覆盖它。
5. **外观预绘脚本曾与导航协调器共同搬运壁纸状态。** 现在壁纸程序自身监听目标文档边界，持久画布保留图片；导航、字体和页面功能都不导入或改写壁纸状态。
6. **同图曾在 boot layer 与运行时 `<img>` 之间交接。** 现在所有可见照片始终由同一个双层 CSS 画布绘制；下载与解码只生成完整槽位值，不拥有任何可见图层。新图首次显示和刷新恢复使用同一份字节与视觉参数。
7. **亮暗遮罩曾被叠加。** v2 曾让亮色遮罩常驻，再在暗色主题上叠加暗色遮罩，破坏既有视觉参数。现在两个遮罩由互斥的注册透明度 token 控制，亮暗端点恢复旧版参数，主题切换只在两个实时层之间过渡。
8. **下一张照片事务缺少有限失败边界。** 图片读取或解码异常时，事务可能永久停留在 loading。现在下一张在后台有限尝试；失败保留当前与已有备用槽，重复操作合并，过期异步结果不能覆盖新的槽位事务。
9. **整页出口截图不能表达深滚动离场，动画能力也不能错误绑定到原生 View Transition。** `.page-outlet` 的边界覆盖整篇长页面；原生截图会把深滚动旧出口放进目标页顶部几何。此前自有动画又在无原生 API 时关闭，Astro 的 fallback animation 因而让旧正文和新导航态同时可见。现在 ClientRouter 只负责获取、代际、持久外壳和原子交换，fallback 固定为 `swap`；真实 DOM 两阶段事务只依赖实际使用的 Web Animations 能力：旧出口在原滚动位置淡出 180 ms，全透明时交换并放置目标滚动，再让新出口淡入 180 ms。缺少该能力或 reduced-motion 时直接原子交换。
10. **新旧内容不得交叉叠加。** Astro 默认 `fade()` 会让两张截图同时半透明，形成重影和亮度脉冲。当前两阶段事务只允许一个真实内容层可见；导航栏当前页状态在透明交换边界同步，壁纸始终不参与内容动画，正文内部合法的平滑锚点不受影响。
11. **字体曾被建成带超时、降级和缓存猜测的全站状态机。** 现在 RequiredFonts 只有一个无持久状态的 Promise 接口：以当前内容真实字符准备 Latin、CJK unicode-range、斜体、等宽和 KaTeX；成功才完成，失败保持 pending，可替代事务只通过所属 `AbortSignal` 取消。Manrope、Source Sans 3 和 JetBrains Mono 由构建期本地完整字体管线登记并预加载，Noto Sans SC 保留按真实汉字命中的 unicode-range 分片。
12. **字体首帧曾允许错误字形先出现，也曾在温刷新中重复撤下正文。** 现在冷初始文档只保留独立背景和进度线，必需字体与滚动位置完成后一次显示文字；客户端导航继续显示旧页直到目标字体就绪；温缓存由浏览器实际 `FontFaceSet` 状态在末端 render boundary 前同步提交，不显示加载帧。开发模式只把带 Astro 内容哈希或依赖包版本标识的字体响应设为 immutable，使开发刷新与生产缓存语义一致而不改变其他 Vite 资源。动态搜索结果使用局部同类门禁；字体不读取壁纸、Sidebar、导航阶段或动画状态。
13. **键盘焦点曾遗漏在导航事务之外。** Astro 可以播报新路由，但持久外壳会让激活链接继续持有焦点；v2 因此退回到旧版已经消除的键盘回归。现在点击来源在准备阶段成为事务字段，键盘或辅助激活在目标交换并完成滚动放置后把焦点移到 `main`，指针导航不抢焦点；被拦截或过期的激活意图不能污染后续导航。
14. **原生 Popover 不负责本站的跨组件生命周期。** 嵌套 popover、断点隐藏触发器和慢导航期间都可能留下多个临时覆盖层。现在共享控制器只治理显式标记的临时覆盖层，统一互斥、导航准备期关闭、断点失效关闭和有效焦点恢复；移动菜单内的壁纸设置改为内联内容，不再嵌套第二个 popover。
15. **媒体覆盖层曾到页面交换时才关闭。** 慢导航准备期仍会遮住可用旧页，PhotoSwipe 还会忽略打开动画期间的关闭请求。Figure 与媒体查看器现在在导航准备开始即收束；PhotoSwipe 把打开期间的关闭意图带到动画完成边界，避免迟到残留。
16. **Figure 聚焦曾在保存滚动位置前插入占位符。** 浏览器滚动锚定会先改变页面位置，再被当成“原位置”保存，退出后因此跳动。现在任何 DOM 变更前先捕获页面坐标，聚焦前后 header 几何和页面滚动保持一致。
17. **窄屏溢出来自两个局部内容根因。** Frenet `figure` 保留了浏览器默认横向边距，同时又声明 `width: 100%`；长 KaTeX 展示公式也没有自身滚动归属。前者显式归零横向边距，后者在正文模块内成为可横向滚动的公式容器，不用全局 `overflow` 掩盖内容错误。
18. **v2 页面集合曾遗漏根级 `404.html`。** 这不是视觉取舍，而是迁移完整性缺口。现在根级静态 404 使用 v2 字体与视觉基座，并在首屏绘制前按 URL 或已保存偏好解析中英文；未知路径保持 HTTP 404、可索引策略和本地化返回入口。

本地槽位不重新编码图片，不下载 Unsplash 原始大图，也不写入 Worker/KV。每次完整文档启动只计算一套宽度/质量策略；策略变化只更新下一张。响应过大、不可读或存储失败时保留当前画面，正文和默认背景始终可用。
