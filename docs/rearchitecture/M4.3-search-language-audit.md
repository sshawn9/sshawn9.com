# M4.3 搜索与语言审计

- 状态：审计完成；M4.3 语言实现与证据已闭环，搜索决策留待 M4.6 实施
- 日期：2026-08-29
- 范围：行为契约、Pagefind 代际、语言路由和新旧代码所有权
- 非范围：视觉重设计、完整实现、全量回归与平台验证

## 审计方法

本次只检查会改变架构边界的证据。格式、全量浏览器矩阵、最终视觉审计和 Cloudflare 验证集中留到对应实现分支的完成门，不在每个小步骤重复执行。

审计覆盖：

- `site-behavior-cases/search/` 的 9 个案例；
- `locale-theme-fonts/` 中语言路由、偏好、回退、滚动和文案边界的 6 个案例；
- 当前生产搜索、语言切换、Pagefind 构建与测试；
- v2 的 SiteShell、ClientRouter、StateLedger、文章语言回退与构建代际；
- Astro 7 ClientRouter/i18n 和 Pagefind 1.5 的官方能力。

## 必须保持的用户结果

### 语言

- 语言切换进入同一逻辑页面的对应语言路由，并保存偏好；
- 查询参数保持不丢失，文章版本和比较选择不得改变；
- 长页面以点击瞬间的实际滚动位置为转移依据，不使用旧快照；
- 界面语言由 URL 决定；回退文章只让正文使用实际内容语言；
- 中立 `/` 入口按“已保存偏好 → 系统语言 → 英语”解析，首帧不显示错误语言。

### 搜索

- `q` 是查询的唯一权威来源；输入、URL、结果和历史项一致；
- 搜索页直接显示工具，不增加 Hero、教程或快捷键噪声；
- 搜索期间只在结果区显示几何稳定的 Pagefind 骨架；迟到查询不能提交；
- 从结果返回时立即恢复查询和 URL，再由官方组件恢复结果、滚动与合理的焦点上下文；
- 英文和中文使用各自索引、界面文案与结果类型标签；
- JavaScript、入口索引或分片失败时，在有限时间内显示可用静态回退。

## 关键发现

### 1. 搜索当前依赖尚未迁移的项目页面

搜索契约明确要求首页、项目列表、项目详情、文章和 About 全部进入索引。v2 尚无项目列表和项目详情；它们原计划在 M4.5 迁移。因此现在关闭完整搜索分支只能选择以下一种坏结果：漏索引、制造临时项目页，或在 M4.5 再次打开已经关闭的搜索分支。

### 2. 旧 SearchClient 不能整体迁入

旧实现把 Pagefind Component UI、实例注册轮询、URL 同步、Swup history、结果 DOM 克隆、第三方样式覆盖、光标竞态和失败计时集中在一个组件中。它满足了大量现有行为，但所有权混杂且依赖第三方内部 DOM；直接搬入会把旧架构债务带进 v2。

Pagefind 官方 Web Components 已提供输入、防抖、键盘、辅助播报、翻译、结果骨架和懒加载。曾评估直接使用 JavaScript API 自建结果状态机，但那会重新实现官方组件已经解决的交互与无障碍边界，因此采用公共组件并只保留站点所需的薄接线。官方依据：

- <https://pagefind.app/docs/ui-usage/>
- <https://pagefind.app/docs/ui-web-components/>
- <https://pagefind.app/docs/multilingual/>
- <https://pagefind.app/docs/search-config/>

### 3. v2 的语言边界已有三个明确缺口

1. `/` 只是语言选择页面，没有读取保存偏好或系统语言；
2. 语言链接不保存偏好、不保留 query/hash，也没有点击瞬间滚动转移；
3. 回退文章把正文实际语言写入 `<html lang>`，导致站点界面语言、辅助技术和未来 Pagefind 索引语言被正文反向改写。

这些都属于既有契约的实现缺口，不是新体验取舍。

### 4. 搜索页面状态必须属于 URL/历史项，而不是全局组件

为了让“点击结果后返回”恢复正确上下文，`q`、滚动和可恢复焦点属于对应历史项；结果集合不复制为站点自己的 DOM 快照，而由 Pagefind 官方组件按当前查询重建并显示批准的结果区骨架。跨部署时不得把旧索引结果接到新文档；HTML 与 Pagefind 产物仍以 build ID 共享代际。

### 5. Pagefind 必须与 HTML 共享构建代际

v2 应在 Astro 产物生成后运行 Pagefind，并将同一个 `V2_BUILD_ID` 用于 HTML 代际门、搜索快照校验和入口 URL 缓存标识。部署必须复用已验证的同一份 HTML + Pagefind 产物，不能在部署步骤重新索引。

## 已批准的架构取舍

### D1：主线顺序——采用 A

**采用方案——拆开语言与搜索，搜索移到项目迁移之后**

- M4.3 只完成语言路由、偏好、滚动转移和回退语言边界；
- M4.4 保持壁纸、主题与视觉状态；
- M4.5 完成项目、内容关系与媒体；
- M4.6 完成全站搜索；
- 原研究交互分支顺延为 M4.7。

结果：每个分支一次闭环；Pagefind 只接入一次完整页面集合；完整搜索比原计划稍晚完成，但避免重复构建、索引、测试和文档审计。

### D2：搜索运行时——采用 Pagefind 官方组件

采用官方 `<pagefind-input>`、`<pagefind-summary>` 与 `<pagefind-results>`，保留 Pagefind 的防抖、键盘、辅助播报、翻译、懒加载、Escape 清空和结果骨架。本站只连接 URL、历史项、构建代际、失败释放和站点样式。

经讨论批准 `BCP-003`：不再要求旧结果保持到新结果就绪，也不再覆盖 Escape 为只取消焦点。骨架使用官方 placeholder 模板能力调整为接近最终结果几何；禁止克隆 Pagefind 内部 DOM、轮询私有注册状态或建立第二套搜索结果状态机。

### D3：中立入口语言解析——采用 A

**采用方案——静态 `/` + head 同步解析脚本**

脚本在首帧前读取 locale preference 和 `navigator.languages`，用 `location.replace()` 进入目标首页；无 JavaScript 时显示两个真实语言链接。不需要 Worker，也不让中立页成为客户端应用。

不采用 Worker + cookie：它会让 Worker 接管中立入口并增加缓存变量，而保存偏好和系统语言本来就只存在于浏览器。

## M4.3 语言实现边界

1. `/` 保持 Static Assets 文档。head 中的同步脚本只解析语言并执行 `location.replace()`；无脚本正文提供 `/en/` 与 `/zh/` 真实链接。
2. URL 是当前界面语言的唯一权威来源。保存偏好只影响以后进入中立入口，不能反向改写已经带语言前缀的 URL。
3. 偏好继续读取现有 `PARAGLIDE_LOCALE`，避免 v2 切换时丢失生产用户选择；读写通过共享 codec，不导入生成的 Paraglide 运行时。
4. 语言链接由类型化 URL 转换函数生成，保留同一 pathname 身份、query 和可获得的 hash。未来项目路由仍使用稳定 ID，不为语言切换建立路由表副本。
5. 普通左键切换在点击同步阶段保存目标语言，并把当前 `scrollX/scrollY` 写成带目标 route key 的一次性 session transfer；修改键或新标签页不改变当前标签页偏好和转移状态。
6. 同构建 ClientRouter 在 swap 后、目标可见前消费转移；完整文档导航由 head 初始文档协调器在静态文档末端 marker 出现后消费。同一条转移最多提交一次，目标不匹配或损坏时安全忽略。
7. `<html lang>` 始终表示 URL/界面语言；回退文章的 `<article lang>` 表示实际正文语言。正文语言不能反向改写导航、按钮、Pagefind 索引分区或站点文案。
8. 所有实现保持小型纯函数、显式存储依赖和一个事件所有者；不建立第二个路由器、全局 locale store 或通用插件层。

## M4.3 闭环证据

- `packages/site-domain/src/locales.ts` 是语言标签解析和偏好优先级的共享领域事实；
- `apps/site-v2/src/content/locale-routes.ts` 只转换 URL 的 locale segment，不复制业务路由表；
- `locale-preference.ts` 保持现有 `PARAGLIDE_LOCALE` 键，并生成中立入口的同步 head 脚本；
- `locale-navigation-transfer.ts` 使用显式 schema、目标 route key 与一次消费语义；正常导航和 head 初始文档协调器复用同一 decoder；
- `SiteShellController` 只在普通同标签页语言操作时补齐静态 HTML 不可见的 query/hash 并保存偏好；`NavigationCoordinator` 独占点击滚动转移；
- `BaseLayout` 的 `<html lang>` 只取 URL 界面语言，`ArticlePage` 的 `<article lang>` 只取实际正文语言；
- `tests/unit/v2-locale-navigation.test.ts` 覆盖解析、URL 转换、兼容键和一次性 transfer；`apps/site-v2/tests/e2e/locale-navigation.spec.ts` 覆盖中立入口/无脚本、同代持久外壳、跨代首帧滚动与回退正文语义。
