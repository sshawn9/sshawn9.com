# 案例：自动化未覆盖真实闪烁、系统指针或拖动性能时，必须用系统 Chrome 实测

### 场景

问题涉及人眼可见的瞬时帧、浏览器原生滚动条、系统指针或连续拖动掉帧，现有自动化无法忠实模拟。

### 正确行为

- 自动化负责可可靠观测的状态、帧采样和性能指标。
- 其覆盖边界之外，使用用户实际安装的 Chrome、真实输入和目标显示环境复现。
- 报告明确区分自动化证据与人工视觉结论。

### 禁止状态

- 最终 DOM 测试通过后否认肉眼可见的真实现象。
- 用无头浏览器合成指针代替系统指针并宣称完全等价。
- 人工测试没有步骤、环境和结果记录，无法复现。

### 验收

1. 记录系统 Chrome 版本、显示环境和实际操作步骤。
2. 对闪烁、滚动条拖动和 Sidebar 调宽分别录屏或采集性能轨迹。
3. 将发现转化为可自动化的部分，同时保留仍需人工确认的边界。
