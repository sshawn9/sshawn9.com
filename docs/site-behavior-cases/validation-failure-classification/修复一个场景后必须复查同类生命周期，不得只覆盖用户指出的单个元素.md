# 案例：修复一个场景后必须复查同类生命周期，不得只覆盖用户指出的单个元素

### 场景

用户指出某个按钮、标签或列表刷新闪烁，但根因位于共享的首帧恢复、水合或导航生命周期。

### 正确行为

- 从现象追踪到共享状态、布局和生命周期根因。
- 审查所有使用同一机制的页面和元素，识别可能的同类回归。
- 测试既覆盖原始复现，也覆盖共享机制的代表消费者。

### 禁止状态

- 只给被指出元素增加 visibility、延迟或固定坐标补丁。
- 一个元素不再抖动，但正文、标签、导航或其他 Sidebar 开始闪烁。
- 无限复制局部修复而不统一重复状态机。

### 验收

1. 记录原现象涉及的共享状态来源和生命周期阶段。
2. 枚举同一机制的其他消费者并选择代表场景。
3. 逐项验证原问题消失且其他消费者没有新闪烁、重建或状态丢失。
