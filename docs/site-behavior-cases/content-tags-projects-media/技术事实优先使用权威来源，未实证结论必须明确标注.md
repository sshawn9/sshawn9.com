# 案例：技术事实优先使用权威来源，未实证结论必须明确标注

### 场景

文章说明平台行为、技术机制、限制或最佳实践。

### 正确行为

- 可核验的技术事实优先引用官方文档、规范、源码或原始研究。
- 本站实测与一般平台事实分开表述，并保留测试条件。
- 推断、经验判断和尚未验证的结论明确标注其证据边界。

### 禁止状态

- 仅凭记忆断言可能变化的平台行为。
- 用二手文章替代可获得的官方来源而不说明原因。
- 把相关性、局部测试或作者猜测写成普遍事实。

### 验收

1. 抽取文章中的可验证技术断言并逐条检查来源类型。
2. 复现关键本地测试，记录环境和版本。
3. 对无法充分证明的内容确认使用了准确的限定表述。
