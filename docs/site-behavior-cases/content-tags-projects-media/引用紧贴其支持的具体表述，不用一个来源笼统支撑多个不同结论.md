# 案例：引用紧贴其支持的具体表述，不用一个来源笼统支撑多个不同结论

### 场景

一段文字包含多个来自不同证据的技术结论。

### 正确行为

- 每个引用紧邻其实际支持的句子或最小表述范围。
- 一个来源只承担其原文能够直接支持的结论。
- 作者推断与来源事实在句法和标注上清楚分开。

### 禁止状态

- 在长段末尾放一个链接，暗示它支持段内所有结论。
- 引用页面只提到相关主题，却不支持所写具体行为。
- 把多个来源综合得到的推断伪装成单一来源原结论。

### 验收

1. 逐个打开引用并定位其支持的具体表述。
2. 检查同段不同结论是否分别获得准确来源或推断标记。
3. 移除引用后反向判断哪些文字会失去证据，确认边界明确。
