# 案例：同一逻辑文章中的重复标签只计数一次

### 场景

数据来源可能因大小写、重复声明或多语言文件而为同一文章提供等价标签。

### 正确行为

- 标签在规范化后按逻辑文章去重计数。
- 一篇文章无论有多少版本、语言文件或重复声明，对同一标签只贡献一次。
- 目录计数与标签页面中的逻辑文章数量一致。

### 禁止状态

- 按文件或原始数组项累加，造成计数虚高。
- 只在界面去重，底层分页和总数仍重复。
- 大小写不同的等价标签被当作两个计数项。

### 验收

1. 构造包含重复、大小写变体和多语言文件的文章样例。
2. 独立按逻辑文章与规范标签计算计数。
3. 比较标签目录、标签页总数和文章列表完全一致。
