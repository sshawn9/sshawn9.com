# 案例：图注与图形保持整体，动态标签清晰且不得相互遮挡

### 场景

图形包含图注、图例和随参数移动的标签，并可能在不同宽度下重排。

### 正确行为

- 图注与所属图形在文档流和分页语义上保持一体。
- 动态标签根据数据和可用空间避让，保持完整可读。
- 图例、标签与关键数据区域的视觉优先级明确。

### 禁止状态

- 图注与图形被无关内容分开，读者无法确认对应关系。
- 参数变化后标签互相遮挡、越界或压住关键曲线。
- 为避免碰撞直接隐藏必要标签而没有替代信息。

### 验收

1. 遍历参数极值、中间值和窄宽容器。
2. 截图检查图注归属、标签边界和遮挡关系。
3. 调整字体、语言和 Sidebar 宽度后重复验证。
