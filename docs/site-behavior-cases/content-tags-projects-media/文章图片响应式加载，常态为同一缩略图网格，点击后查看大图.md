# 案例：文章图片响应式加载，常态为同一缩略图网格，点击后查看大图

### 场景

文章包含一组可浏览的图片，用户既需要快速扫视，也需要查看原始细节。

### 正确行为

- 常态使用尺寸一致、间距稳定的缩略图网格。
- 浏览器按容器和设备选择合适尺寸资源，不为小缩略图下载不必要的大图。
- 点击后在可访问的大图查看器中展示完整图片，并可返回原焦点和滚动位置。

### 禁止状态

- 不同原图比例让缩略图网格参差跳动。
- 首屏无条件下载全部原始大图。
- 打开大图后无法关闭、焦点逃逸或返回时页面位置丢失。

### 验收

1. 在桌面、移动端和不同像素密度下检查资源选择与网格几何。
2. 用鼠标和键盘打开、切换并关闭大图。
3. 检查加载前预留尺寸、关闭后的焦点及正文滚动位置。
