# 案例：文章图片响应式加载，常态为同一缩略图网格，点击后查看大图

### 场景

文章可能同时包含解释正文的单幅插图，以及适合集中浏览的图片组或附件。

### 正确行为

- 解释正文的单幅插图保持适合阅读的文档流尺寸；明确的图片组或附件使用尺寸一致、间距稳定的缩略图网格。
- 浏览器按容器和设备选择合适尺寸资源，不为小缩略图下载不必要的大图。
- 可放大的图片点击后在可访问的大图查看器中展示完整图片；无 JavaScript 时仍可通过普通链接访问原图。
- 关闭查看器后返回原焦点和滚动位置。

### 禁止状态

- 不同原图比例让缩略图网格参差跳动。
- 把需要随正文阅读的技术图强制缩成难以辨认的附件缩略图。
- 首屏无条件下载全部原始大图。
- 打开大图后无法关闭、焦点逃逸或返回时页面位置丢失。

### 验收

1. 在桌面、移动端和不同像素密度下分别检查正文插图、附件资源选择与网格几何。
2. 用鼠标和键盘打开、切换并关闭大图。
3. 检查加载前预留尺寸、关闭后的焦点及正文滚动位置。
