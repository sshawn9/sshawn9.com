# 案例：未完成的 About 页面保留简洁施工状态，不用临时 Demo 填充

### 场景

About 页面尚未具备可公开的正式内容，但路由需要存在。

### 正确行为

- 页面以简洁、诚实的施工中状态说明当前情况。
- 保留正常站点外壳、语言、主题和导航能力。
- 正式内容完成后可直接替换主体，不背负临时演示组件。

### 禁止状态

- 用无关 Demo、虚构简历或模板介绍填满页面。
- 因未完成而返回错误状态、空白页或破坏导航。
- 临时内容被搜索、首页或项目数据误当成真实资料。

### 验收

1. 在两种语言、主题和无 JavaScript 条件下打开 About。
2. 确认施工信息准确、页面结构完整且无虚构内容。
3. 检查搜索索引对该页面的描述与实际状态一致。
