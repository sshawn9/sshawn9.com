# 案例：内嵌视频不得自动播放

### 场景

文章或项目页面包含本地或第三方视频。

### 正确行为

- 视频初始暂停，只有用户明确操作后才开始播放。
- 未播放时提供稳定封面和必要控件，不发出声音或抢占媒体焦点。
- 页面导航离开后停止相关播放和资源活动。

### 禁止状态

- 页面加载、滚动进入视口或水合完成时自动播放。
- 通过静音规避规则却仍自动消耗带宽和注意力。
- 多个视频同时启动或站内导航后继续后台播放。

### 验收

1. 冷打开、刷新和站内导航进入含视频页面。
2. 确认未操作前播放状态、声音和网络行为符合预期。
3. 主动播放后离开页面，检查播放与资源活动停止。
