# 案例：技术图中的方向、比例、符号和对应关系必须与正文语义一致

### 场景

文章使用示意图、曲线、车辆、坐标轴或控制关系解释技术概念。

### 正确行为

- 图形方向、坐标系、符号和对象对应关系与正文定义一致。
- 有意义的比例必须准确；纯示意关系则明确避免让读者误判为定量图。
- 同一变量在正文、公式、图例和交互状态中使用一致命名与颜色语义。

### 禁止状态

- 箭头方向、左右关系或正负号与正文相反。
- 为视觉好看随意拉伸会影响结论的几何比例。
- 图中同色对象在正文代表不同含义却没有说明。

### 验收

1. 按正文定义逐项核对坐标、方向、符号和对象映射。
2. 使用已知边界值验证静态图和交互图输出。
3. 邀请未参与实现者仅凭图文复述关系，检查是否产生歧义。
