# 案例：首页只呈现真实内容，不填充虚构介绍

### 场景

首页需要表达站点当前真实内容和作者实际提供的信息。

### 正确行为

- 所有介绍、项目和内容入口都有真实来源或已存在页面支撑。
- 信息不足时宁可保持简洁，不用模板化文案填满版面。
- 后续新增内容通过真实数据进入首页，不需要维护虚构占位。

### 禁止状态

- 编造作者经历、项目、客户、成就或站点能力。
- 使用与实际内容无关的营销口号和虚假统计。
- 把尚未完成的功能描述成已经可用。

### 验收

1. 逐项追溯首页事实到真实内容、代码能力或作者材料。
2. 检查所有入口存在且描述与目标页面一致。
3. 无法核验的陈述必须删除或改为准确的未完成状态。
