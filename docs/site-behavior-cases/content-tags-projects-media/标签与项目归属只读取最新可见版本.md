# 案例：标签与项目归属只读取最新可见版本

### 场景

同一逻辑文章的历史版本和最新版本拥有不同标签或项目元数据。

### 正确行为

- 当前列表、标签计数和项目关联只使用当前环境最新可见版本的元数据。
- 历史版本保留自己的元数据用于历史页面，不反向污染当前索引。
- Production 遇到更新版本仍为草稿时，使用最新已发布版本的归属。

### 禁止状态

- 合并所有历史版本标签，导致已删除主题仍出现在当前目录。
- 草稿元数据泄露到 Production 标签或项目页面。
- 正文来自一个版本，标签和项目却来自另一个版本。

### 验收

1. 准备历史与最新版本归属不同的文章。
2. 分别在 Dev、Preview 和 Production 核对标签计数与项目列表。
3. 打开历史版本，确认其页面信息保留但不改变当前索引。
