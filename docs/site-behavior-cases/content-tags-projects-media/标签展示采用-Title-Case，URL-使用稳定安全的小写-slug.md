# 案例：标签展示采用 Title Case，URL 使用稳定安全的小写 slug

### 场景

同一标签同时用于界面阅读和稳定路由，需要分别满足可读性与地址安全性。

### 正确行为

- 界面显示使用统一的 Title Case 规范，并保留技术专名需要的既定写法。
- 路由使用规范化、稳定、安全的小写 slug。
- 同一标签在博客、文章、项目和搜索中显示名称与路由映射一致。

### 禁止状态

- 直接把显示文本原样塞入 URL，产生大小写和特殊字符漂移。
- 同一标签在不同页面出现不同显示大小写。
- 修改纯展示格式时无意改变已有稳定 URL。

### 验收

1. 检查普通英文、缩写、含空格和技术专名标签。
2. 比较各页面显示文本及链接 slug。
3. 更新显示规范后复查既有路由仍可访问且规范地址不变。
