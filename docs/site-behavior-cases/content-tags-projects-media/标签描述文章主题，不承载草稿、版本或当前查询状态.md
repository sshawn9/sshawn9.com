# 案例：标签描述文章主题，不承载草稿、版本或当前查询状态

### 场景

内容需要按主题分类，同时还存在草稿状态、公开版本和用户筛选状态。

### 正确行为

- 标签只表达文章长期有效的主题或领域。
- 草稿由发布元数据处理，版本由版本模型处理，当前查询由 URL 和交互状态处理。
- 标签目录在不同部署与操作状态下保持清晰、可理解的主题体系。

### 禁止状态

- 添加 Draft、Latest、Selected 等运行状态标签。
- 用标签模拟版本号或部署环境。
- 因当前用户选择而动态修改文章永久标签元数据。

### 验收

1. 审查标签集合，识别是否混入发布、版本或界面状态。
2. 在 Dev、Preview、Production 与多版本文章中检查职责边界。
3. 改变筛选状态，确认内容标签数据本身不变。
