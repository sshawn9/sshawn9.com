# 案例：外部资料链接可直接核验，并在新标签页打开

### 场景

读者从文章中的引用或延伸资料进入站外页面核验信息。

### 正确行为

- 链接直接指向支持内容的具体权威页面，而不是搜索结果或无关首页。
- 外部链接在新标签页打开，原文章阅读位置保持。
- 链接文本能说明目标内容，并使用安全的外链关系属性。

### 禁止状态

- 链接到搜索结果、短链跳转或无法判断内容的泛化入口。
- 外链覆盖当前文章标签页，导致阅读上下文丢失。
- 使用“点击这里”等缺乏目标含义的链接文本。

### 验收

1. 抽查外部链接的最终目标、状态码和支持内容。
2. 点击链接确认在新标签页打开且原页位置不变。
3. 使用键盘和辅助技术检查链接名称及外链安全属性。
