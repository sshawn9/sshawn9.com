# 案例：文章 description 只概括用途或主旨，不复制正文或写成总结

### 场景

文章需要为列表、搜索和元数据提供简短描述。

### 正确行为

- description 用少量文字说明文章解决什么问题或讨论什么主旨。
- 文案独立可读，不机械复制开头段落，也不提前给出整篇结论清单。
- 中文与英文描述忠实对应各自正文，不添加正文不存在的信息。

### 禁止状态

- 截取正文前若干字作为描述，造成断句或重复阅读。
- 写成逐节总结，挤占列表空间并泄露完整结构。
- 为吸引点击夸大文章能力或编造结论。

### 验收

1. 抽查不同类型文章的 description 与正文开头、结论。
2. 在博客列表、搜索结果和页面元数据中检查长度与可读性。
3. 确认每项表述都能在正文中得到支持。
