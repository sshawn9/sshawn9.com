# 案例：项目页面以项目正文为主体，并自动列出最新版本元数据关联的文章

### 场景

用户进入项目详情，既需要了解项目本身，也需要查阅与项目相关的文章。

### 正确行为

- 存在项目正文时，正文是页面主要内容，不被文章列表反客为主。
- 尚无项目正文时，页面使用真实描述、标签和自动关联文章形成诚实的内容中心，不渲染空正文或虚构占位；以后补充正文即可自然成为主体。
- 相关文章从每篇逻辑文章最新可见版本的项目元数据自动生成。
- 文章更新归属后，项目列表随内容源变化，无需维护第二份手工关系。

### 禁止状态

- 没有正文时只显示一组无上下文链接，或伪造项目背景填补页面。
- 手工复制文章链接，长期与元数据漂移。
- 合并历史版本归属或泄露草稿关联。

### 验收

1. 分别检查有正文和无正文项目，并对照文章最新可见版本的项目字段。
2. 修改文章归属后重新构建，确认列表自动更新。
3. 在 Preview 与 Production 核对草稿和版本可见范围。
