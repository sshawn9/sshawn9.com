# 案例：一篇文章可归属多个项目

### 场景

一篇文章同时记录多个项目共享的技术、基础设施或研究成果。

### 正确行为

- 文章元数据允许显式关联多个项目。
- 该逻辑文章在每个关联项目中各出现一次，链接到同一稳定文章入口。
- 多项目归属不影响标签、版本、语言或博客列表去重。

### 禁止状态

- 强制文章只能属于一个项目，丢失真实关系。
- 为多个项目复制文章内容或创建多个逻辑文章。
- 同一项目因重复声明而显示多次同一文章。

### 验收

1. 为测试文章关联两个项目并生成站点。
2. 检查两个项目页均出现且各只出现一次。
3. 核对稳定 URL、文章总数与其他索引没有重复。
