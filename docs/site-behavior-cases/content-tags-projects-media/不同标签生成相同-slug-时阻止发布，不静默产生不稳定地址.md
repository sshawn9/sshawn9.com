# 案例：不同标签生成相同 slug 时阻止发布，不静默产生不稳定地址

### 场景

两个不同标签经过小写化、空格和特殊字符规范化后得到相同 slug。

### 正确行为

- 构建或内容校验明确报告冲突的原始标签与目标 slug。
- 冲突在发布前阻断，由作者选择新的规范标签或显式映射。
- 解决后映射保持确定，不受输入顺序或构建环境影响。

### 禁止状态

- 后出现的标签静默覆盖先出现的标签。
- 自动追加随机数字，使地址随构建顺序改变。
- 两个标签共用路由却展示不可预测的文章集合。

### 验收

1. 添加能产生同一 slug 的两个测试标签并执行最小内容校验。
2. 确认发布失败且错误信息能直接定位冲突。
3. 明确解决冲突后重复构建，核对路由映射稳定。
