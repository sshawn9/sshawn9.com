# 案例：文章列表按逻辑文章去重，不因语言文件或版本文件重复出现

### 场景

同一篇文章包含多个公开版本和多种语言文件，网站生成博客、标签、项目或搜索列表。

### 正确行为

- 列表以逻辑文章为唯一单位，每篇文章在同一结果集合中只出现一次。
- 当前环境先确定最新可见版本，再选择当前语言或明确回退语言的展示数据。
- 版本数和语言文件数不会改变文章总数或分页去重结果。

### 禁止状态

- 每个版本或语言文件各生成一条列表项。
- 标题相同就草率去重，误合并实际不同的逻辑文章。
- 列表显示新版本标题，却链接到旧版本或另一语言文件。

### 验收

1. 对含多版本、多语言的文章核对逻辑身份与列表条目。
2. 检查博客、标签、项目和搜索四类索引的去重结果。
3. 在不同语言和发布环境下确认条目内容与链接来自同一可见版本。
