# 案例：文章列表按首次发布日期排序

### 场景

文章可能在首次发布后多次更新或增加版本，列表需要保持稳定时间顺序。

### 正确行为

- 所有文章列表以逻辑文章的首次发布日期排序。
- 新版本和小修订不把旧文章重新推到列表顶部。
- 日期相同的文章使用稳定且可复现的次级顺序。

### 禁止状态

- 按最后更新时间排序，导致每次修订重排整个列表。
- 不同语言或环境使用不同日期字段而产生顺序漂移。
- 构建间对同日期文章随机换序。

### 验收

1. 对照首次日期独立排序一组含多版本文章。
2. 更新其中一篇文章后重新生成列表，确认原排序不变。
3. 比较不同语言、Preview 与 Production 的共同文章顺序。
