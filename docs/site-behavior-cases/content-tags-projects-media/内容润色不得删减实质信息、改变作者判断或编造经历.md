# 案例：内容润色不得删减实质信息、改变作者判断或编造经历

### 场景

文章进行语言优化、翻译或结构整理，但作者原始经验和技术判断已经确定。

### 正确行为

- 润色改善表达、连贯性和结构，同时保留全部实质信息与限定条件。
- 作者的观点、置信程度、经历和结论不得被擅自增强或替换。
- 发现疑点时标记并核验，不用听起来更完整的虚构内容填补。

### 禁止状态

- 为缩短篇幅删除会影响结论成立条件的信息。
- 把推测改写成事实，或替作者编造测试、项目经历和动机。
- 只因语言更流畅就改变技术含义。

### 验收

1. 对原稿与润色稿进行逐段语义对照。
2. 单独核对数字、条件、否定、置信表达和第一人称经历。
3. 所有新增事实必须有作者材料或可核验来源支持。
