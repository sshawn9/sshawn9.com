# 案例：Sidebar 标题为“文章标签”，折叠按钮位于标题左侧且位置稳定

### 场景

用户需要识别 Sidebar 当前内容，并在展开与折叠之间切换。

### 正确行为

- 展开时标题明确显示“文章标签”。
- 折叠按钮位于标题左侧，由 Sidebar 级结构承载，不属于标签列表项。
- 展开和折叠两种状态下，按钮的屏幕锚点稳定，不因标题出现、消失或宽度改变而横向抖动。

### 禁止状态

- 使用含义模糊的“浏览文章”代替实际模块名称。
- 同时显示 Sidebar 标题和子模块内重复的“文章标签”。
- 按钮随折叠状态跳到另一位置，带动正文或边界位移。

### 验收

1. 在默认宽度、最小宽度和用户调整宽度下反复折叠、展开。
2. 逐帧比较按钮中心坐标和正文起点。
3. 检查标题仅在需要的位置出现且没有重复文本。
