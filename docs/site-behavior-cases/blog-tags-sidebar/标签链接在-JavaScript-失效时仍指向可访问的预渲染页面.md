# 案例：标签链接在 JavaScript 失效时仍指向可访问的预渲染页面

### 场景

用户点击标签，但博客增强脚本被禁用、加载失败，或链接被搜索引擎和外部工具直接访问。

### 正确行为

- 每个标签使用真实 href 指向可直接访问的稳定标签路由。
- 标签页面由发布内容预渲染，显示该标签的正确文章集合和计数语义。
- JavaScript 正常时可以增强为页内筛选，但不能破坏链接的基础导航能力。

### 禁止状态

- 使用空 href、仅按钮或依赖点击处理器的伪链接。
- 静态标签 URL 返回空页、404 或与标签无关的全量列表。
- 增强逻辑阻止默认导航后失败，使点击完全无响应。

### 验收

1. 禁用 JavaScript 后逐个打开若干标签链接。
2. 直接复制标签 href 到新会话，核对状态码、文章集合和语言。
3. 开启 JavaScript 后确认增强筛选与普通链接表达相同语义。
