# 案例：Sidebar 右边界常态低调，视觉线与可操作命中区分离

### 场景

Sidebar 需要始终表达与正文的空间边界，同时允许用户抓取调宽。

### 正确行为

- 常态显示一条低对比度灰色细线，作为 Sidebar 的稳定右边界。
- 实际可拖动命中区可以比细线宽，但不扩大可见线宽。
- 靠近或悬停不高亮；只有按下、拖动或键盘操作期间适度提高同色亮度。

### 禁止状态

- 边界线颜色或亮度过强，持续抢夺正文注意力。
- 鼠标仅靠近就高亮或改变颜色。
- 为扩大命中区而显示粗条，或命中区覆盖标签滚动条和正文交互。

### 验收

1. 在不同主题和壁纸背景上观察常态边界对比度。
2. 依次悬停、按下、拖动和释放，记录视觉反馈出现阶段。
3. 从细线两侧测试命中区，确认易操作但不劫持相邻控件。
