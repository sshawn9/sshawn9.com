# 案例：增减标签不得导致标签列表、滚动位置或周围布局跳动

### 场景

用户在已滚动的标签目录中连续选择或取消标签。

### 正确行为

- 标签项目的尺寸、顺序和目录总高度不因选中样式改变。
- 标签列表保留当前滚动位置，Sidebar 和正文边界保持原坐标。
- 只有结果内容和筛选语义发生必要变化。
- 同一博客资源内的 `tag`、`page` 点击及其前进后退只更新局部视图：不请求 HTML、不整页淡出，列表与 Sidebar 保持可见稳定，控件状态和 URL 同步。
- 点击标签不主动滚动页面；点击分页只将结果区保持在可继续阅读的位置。

### 禁止状态

- 选中状态通过字重、边框或额外元素改变项目宽高并推挤邻项。
- 每次选择后标签列表跳回顶部。
- 标签操作带动 Sidebar 宽度、正文起点或 Header 位移。
- 同页筛选或分页被当作跨文档导航，出现整页转场、两列短暂消失或重新可见。

### 验收

1. 将标签列表滚到中部，记录滚动值和关键元素矩形。
2. 连续增减多个标签、分页并前进后退，比较每帧可见布局、控件状态、URL 与历史项；确认没有 HTML 导航请求或整页淡出。
3. 在不同 Sidebar 宽度及长标签名称下重复验证。
