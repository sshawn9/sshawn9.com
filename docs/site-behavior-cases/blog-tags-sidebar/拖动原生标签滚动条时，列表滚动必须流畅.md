# 案例：拖动原生标签滚动条时，列表滚动必须流畅

### 场景

用户按住标签目录的原生滚动条滑块并连续拖动。

### 正确行为

- 浏览器原生滚动直接驱动内容位置，不被同步存储或高频布局写入阻塞。
- 滚动位置持久化经过合并或在操作结束后提交，不影响每帧输入。
- 滚动期间标签文本、Sidebar 边界和正文保持稳定。

### 禁止状态

- 每个 scroll 事件都同步写存储、强制测量或重绘大范围页面。
- 滑块移动与内容明显脱节、掉帧或间歇停顿。
- 为消除卡顿而取消滚动位置恢复能力。

### 验收

1. 使用系统 Chrome 拖动滑块从顶部到底部并反向拖回。
2. 记录性能轨迹，检查滚动处理器没有连续长任务和布局抖动。
3. 释放后刷新，确认最终位置仍能恢复。
