# 案例：隐藏筛选中间态时，只能约束相关结果区，不能隐藏整个页面外壳

### 场景

某些冷入口无法由静态 HTML 直接表达最终筛选状态，需要短暂等待客户端完成相关内容接管。

### 正确行为

- 可见性约束仅覆盖会出现错误中间态的标签状态、结果列表和相应统计。
- Header、导航、壁纸、无关页面结构和页脚按正常首帧绘制。
- 约束区域预留最终几何，释放时不引发布局跳动。

### 禁止状态

- 在根元素上隐藏整个 body，使全页直到水合才出现。
- 只隐藏文章却让不一致的数量、分页或标签状态提前出现。
- 释放可见性时重新播放普通入场动画。

### 验收

1. 延迟博客交互脚本并录制带筛选或分页冷入口。
2. 检查外壳和无关区域立即可见，相关区域没有错误状态泄漏。
3. 测量释放前后页面几何，确认没有跳动或动画重播。
