# 案例：水合噪声不得覆盖已保存的标签滚动位置，水合期间真实滚动必须优先

### 场景

客户端水合可能临时改变目录高度并触发浏览器钳位或 scroll 事件；用户也可能在水合期间真实滚动。

### 正确行为

- 控制器区分结构变化产生的噪声值与用户真实输入。
- 水合恢复前不得把临时钳位值提交为持久位置。
- 如果用户在恢复窗口内主动滚动，用户输入优先，后续恢复不得把它覆盖。

### 禁止状态

- 先把水合期间的零值写入存储，再从同一存储恢复零值。
- 为避免噪声而无条件清空所有待写值，连用户真实滚动也丢弃。
- 多个恢复钩子互相覆盖，位置在顶部和保存值之间反复跳。

### 验收

1. 人为延迟水合并制造目录高度变化，检查保存位置不被零值覆盖。
2. 在延迟期间主动滚动目录，确认最终停留在用户选择位置。
3. 刷新后验证最终有效位置被保存且仅恢复一次。
