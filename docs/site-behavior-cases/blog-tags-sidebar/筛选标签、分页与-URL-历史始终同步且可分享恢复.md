# 案例：筛选标签、分页与 URL 历史始终同步且可分享恢复

### 场景

用户筛选标签、翻页、复制地址，或使用浏览器前进和后退。

### 正确行为

- URL 完整表达当前标签集合和有效页码，可直接复制分享。
- 用户改变筛选或页码时，可见结果与地址历史同步提交，不出现半完成状态。
- 冷打开、刷新、前进和后退均恢复地址表达的同一状态。

### 禁止状态

- 页面已筛选但 URL 没有变化，分享后丢失状态。
- URL 先变化而内容稍后才匹配，期间出现错误可见帧。
- 前进或后退只改变地址，不恢复标签、结果或分页。

### 验收

1. 依次执行选标签、增标签、翻页、取消标签并记录历史。
2. 逐次使用前进和后退，核对地址、左侧状态、结果与分页。
3. 在新标签页冷打开每个记录地址，确认恢复完全一致。
