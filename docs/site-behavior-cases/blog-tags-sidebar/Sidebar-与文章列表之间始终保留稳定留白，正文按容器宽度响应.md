# 案例：Sidebar 与文章列表之间始终保留稳定留白，正文按容器宽度响应

### 场景

Sidebar 展开、调宽或折叠，文章列表需要随可用空间变化。

### 正确行为

- Sidebar 边界与文章列表之间保留明确、稳定的间距，滚动条和分隔线不紧贴正文。
- 文章布局根据主栏容器宽度响应，而不是仅根据整个视口宽度判断。
- 调宽只影响相关布局区域，不改变 Header、全局导航或页面外框。

### 禁止状态

- 标签滚动条、分隔线和文章文字贴在一起。
- Sidebar 调窄后正文仍沿用宽屏布局而溢出或截断。
- 使用视口断点导致同一主栏宽度在不同外部布局中表现不一致。

### 验收

1. 在最小、默认、最大和折叠宽度下测量边界到正文的间距。
2. 检查文章标题、摘要、日期和标签在每个容器宽度的重排。
3. 确认 Header 与页面外框坐标不受 Sidebar 调宽影响。
