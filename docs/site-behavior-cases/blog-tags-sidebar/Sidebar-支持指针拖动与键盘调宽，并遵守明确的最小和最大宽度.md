# 案例：Sidebar 支持指针拖动与键盘调宽，并遵守明确的最小和最大宽度

### 场景

桌面用户通过分隔边界调整左侧 Sidebar 宽度，键盘用户需要获得同等能力。

### 正确行为

- 指针拖动期间宽度连续跟随，释放时保存最终值。
- 可聚焦的调节控件支持方向键按稳定步长调整，并暴露当前值、范围和方向语义。
- 所有输入均限制在设计允许的最小、最大宽度内，正文保留可用空间。

### 禁止状态

- 只有鼠标能调整，键盘无法操作。
- 拖动越过边界导致 Sidebar 或正文不可读。
- 拖动每一帧把持久状态写到全局根节点或同步存储，造成卡顿。

### 验收

1. 使用鼠标和触控板从中间值拖到两端，观察跟手性与约束。
2. 仅用键盘聚焦调节控件，验证步进、边界和可访问值。
3. 释放后刷新页面，确认保存的是最终合法宽度。
