# 案例：桌面 Sidebar 侧向折叠，为文章列表释放真实横向空间

### 场景

桌面视口中用户希望暂时隐藏左侧辅助内容，让文章列表获得更大阅读宽度。

### 正确行为

- 折叠沿横向收起 Sidebar 内容与占用宽度，只保留可恢复的控制入口。
- 释放出的空间由文章主栏实际使用，主栏按新容器宽度重新排布。
- 展开时恢复用户保存宽度，而不是强制回到默认宽度。

### 禁止状态

- 只把标签内容竖向收起，却留下同样宽的空白栏。
- Sidebar 视觉隐藏，但网格仍保留原列宽。
- 展开后丢失用户调整值，或正文先跳到默认宽度再恢复。

### 验收

1. 测量折叠前后 Sidebar 和文章主栏的实际宽度。
2. 确认释放宽度被正文利用，并且翻页、标签等内容正常重排。
3. 调整到非默认宽度后折叠、展开和刷新，验证宽度恢复一致。
