# 案例：同时选择多个标签时采用并集筛选

### 场景

用户选择两个或更多标签，希望查看属于任一所选主题的文章。

### 正确行为

- 文章只要包含至少一个选中标签就进入结果集合。
- 同时命中多个选中标签的文章只出现一次。
- 总数、分页和 URL 均以去重后的并集为准。

### 禁止状态

- 把多标签选择解释为必须同时包含所有标签的交集。
- 同一文章因命中多个标签而重复出现或重复计数。
- 左侧表现为多选，结果却只使用最后一次选择。

### 验收

1. 选择文章集合部分重叠的两个标签。
2. 独立计算两组文章的去重并集并与页面逐项比对。
3. 刷新、翻页和历史返回后再次确认筛选语义不变。
