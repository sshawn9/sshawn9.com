# 案例：带分页参数冷进入时，不得先显示错误的静态第一页

### 场景

用户通过分享地址或新标签页直接打开包含非第一页参数的博客 URL。

### 正确行为

- 首个可见结果就是 URL 指定的有效页及其文章集合。
- 总数、页码、翻页入口和可能存在的标签筛选从首帧一致。
- 页面可操作后不把已经正确的结果替换成另一页再改回。

### 禁止状态

- 先出现第一页，随后才跳到目标页。
- 为避免第一页闪现而无限隐藏结果区。
- 地址为目标页，但分页文案或翻页入口暂时属于第一页。

### 验收

1. 在冷缓存和禁用预取条件下直接打开第二页及最后一页地址。
2. 在慢速加载条件下，连续记录首帧到页面可操作的文章和分页。
3. 与该 URL 最终结果比对，任一中间页状态出现即失败。
