# 案例：带标签筛选状态硬刷新时，首帧原子恢复完整筛选结果

### 场景

用户选择标签后刷新带有该筛选状态的博客地址。

### 正确行为

- 首帧中的 URL、选中标签、文章集合、文章标签高亮、数量和分页同时一致。
- 多个 `tag` 参数仍按并集筛选；与 `page` 组合时，分享或刷新该 URL 能独立重建同一页结果。
- 筛选状态不会降低 Header、壁纸、列表和 Sidebar 的刷新稳定性。

### 禁止状态

- 全部文章先出现，再缩减为筛选结果。
- 左侧标签、文章标签和统计分多个阶段依次更新。
- 列表消失重现，或筛选结果重新播放入场。

### 验收

1. 分别用一个和多个标签刷新中英文博客。
2. 从首帧连续检查筛选结果、两处标签状态、统计、分页和 Sidebar。
