# 案例：标签目录始终展示全量标签及全局计数，不因当前筛选而缩减

### 场景

用户已选择部分标签，仍需要看到整个内容体系并继续增加或取消筛选条件。

### 正确行为

- 左侧标签目录始终列出当前发布范围内的全部标签。
- 每个计数表示该标签关联的全部逻辑文章数量，不随当前筛选改变。
- 选中状态只改变筛选表达，不改变目录成员、顺序或计数。

### 禁止状态

- 选择一个标签后，其他标签消失或只剩交集中的标签。
- 计数随筛选结果缩小，使同一标签在操作前后显示不同数字。
- 因筛选重建目录而改变项目顺序或滚动几何。

### 验收

1. 记录无筛选时的标签名称、顺序与计数。
2. 连续选择和取消多个标签，逐项比较目录数据不变。
3. 用文章索引独立核算若干标签的全局去重计数。
