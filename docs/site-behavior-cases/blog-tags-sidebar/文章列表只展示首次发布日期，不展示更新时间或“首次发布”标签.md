# 案例：文章列表只展示首次发布日期，不展示更新时间或“首次发布”标签

### 场景

博客列表需要提供稳定、低噪声的时间信息；文章详情页另行承担完整版本时间说明。

### 正确行为

- 每条列表项只显示该逻辑文章的首次发布日期。
- 日期使用当前页面语言的既定格式，位置在所有列表项中保持一致。
- 更新时间和版本信息只在需要它们的文章详情环境展示。

### 禁止状态

- 同时显示首次发布和最后更新，挤占列表扫描空间。
- 在日期前重复显示“首次发布”等无必要标签。
- 新版本发布后把列表日期改成更新时间，破坏文章的原始时间顺序。

### 验收

1. 检查单版本文章和有历史版本的文章列表项。
2. 对照内容元数据，确认展示值始终为首次发布日期。
3. 发布新版本后复查列表日期和排序不变。
