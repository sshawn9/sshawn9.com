# 案例：标签列表滚动位置在首次进入、刷新和离开后返回时都能首帧恢复

### 场景

用户把标签目录滚到中部，随后刷新、进入文章再返回，或离开博客后重新进入。

### 正确行为

- 每个历史目标项保存自己的有效文档与标签目录滚动位置，并在目录可滚动后恢复。
- 前进、后退和刷新恢复目标历史项的快照；不得为了保持当前 Sidebar 位置而覆盖该目标项的目录位置。
- 首次恢复就成功，不依赖先失败一次、再次滚动和第二次刷新。
- 恢复在目录可见前或同一首帧完成，不从顶部可见地滚到保存位置。

### 禁止状态

- 第一次刷新回顶部，第二次刷新才保持位置。
- 离开后返回时每次第一次都丢失位置。
- 目录先显示顶部再跳到保存值，或使用平滑滚动恢复。

### 验收

1. 清理该页面会话状态后，从全新首次进入开始测试。
2. 滚动目录，依次执行刷新、进入文章后返回、离开博客后重返。
3. 每条路径从首帧记录 scrollTop，且至少重复两轮排除偶然时序。
