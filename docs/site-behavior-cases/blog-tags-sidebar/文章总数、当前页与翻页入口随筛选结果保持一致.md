# 案例：文章总数、当前页与翻页入口随筛选结果保持一致

### 场景

用户浏览全部文章或应用标签筛选，并在结果页之间翻页。

### 正确行为

- 总篇数只统计当前筛选集合中的逻辑文章。
- 当前页、总页数、可用翻页入口和当前显示文章集合由同一结果集计算。
- 筛选使当前页超出新总页数时，页面原子地回到有效页码并同步 URL。
- 总数与页码状态只在结果区右上方显示一次；底部分页只保留贴近结果区左右边缘的上一页和下一页入口。

### 禁止状态

- 文章已经筛选，但总数或总页数仍来自全量文章。
- 当前页没有结果，却仍显示可返回的较小有效页码。
- 翻页入口指向不存在的页，或显示状态与 URL 页码不一致。
- 同一页码状态在结果区顶部和底部重复出现，或单侧入口隐藏后带动另一侧错位。

### 验收

1. 在无筛选、单标签和多标签状态下分别核对总数与分页。
2. 从靠后的页码增加筛选条件，验证页码纠正、列表和 URL 同时完成。
3. 使用前进、后退和分享后的冷入口恢复各分页状态。
