# 案例：标签滚动条使用透明轨道和低干扰滑块，仅在实际操作时提高亮度

### 场景

标签数量超过可用高度，目录需要独立的原生滚动条。

### 正确行为

- 滚动条轨道透明，不显示网页主滚动条式的背景槽框。
- 滑块常态可辨认但低调，颜色与 Sidebar 边界系统协调。
- 悬停或靠近不产生效果；按住滑块或滚动条处于实际操作时只提高同色亮度。

### 禁止状态

- 复制页面主滚动条的厚重轨道与高对比背景。
- 指针移入滚动区域而未操作时滑块就高亮。
- 操作反馈突然切换到无关强调色或改变滚动条尺寸。

### 验收

1. 在支持不同滚动条样式的目标浏览器观察轨道和滑块。
2. 分别测试靠近、悬停、滚轮滚动、按住滑块和释放。
3. 确认只有实际操作期间亮度提高，结束后恢复常态。
