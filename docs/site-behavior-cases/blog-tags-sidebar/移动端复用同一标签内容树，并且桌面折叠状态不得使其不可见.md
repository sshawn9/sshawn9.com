# 案例：移动端复用同一标签内容树，并且桌面折叠状态不得使其不可见

### 场景

用户在桌面折叠 Sidebar 后切换到移动视口，或直接在移动设备浏览标签筛选。

### 正确行为

- 桌面和移动端使用同一份标签语义与数据，不维护两套会漂移的目录。
- 移动端按自身布局提供标签入口，不受仅适用于桌面的折叠宽度和隐藏属性影响。
- 切回桌面时恢复桌面状态，不把移动端临时呈现误写为展开状态。

### 禁止状态

- 为不同断点复制两份标签 DOM，导致选中、计数或监听不同步。
- 桌面折叠产生的 hidden、inert 或零宽状态让移动标签也不可见。
- 切换视口后重置用户保存的桌面宽度。

### 验收

1. 在桌面折叠后切到移动视口，确认标签入口仍可见可用。
2. 在移动端筛选并切回桌面，核对筛选一致且桌面几何恢复。
3. 检查页面中不存在两套可同时交互的标签内容树。
