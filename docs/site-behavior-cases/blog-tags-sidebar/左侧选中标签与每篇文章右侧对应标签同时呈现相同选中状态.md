# 案例：左侧选中标签与每篇文章右侧对应标签同时呈现相同选中状态

### 场景

筛选已生效，页面在目录和文章元数据两个位置显示相同标签。

### 正确行为

- 所有选中标签在左侧目录和每篇文章的对应标签上使用同一语义状态。
- 两处状态在首个可见帧同时出现，并在每次筛选变更时原子更新。
- 未选标签保持普通样式，不能因文章命中其他标签而误亮。
- 选中态必须明显强于悬停态：目录使用强调色边界、底色与粗体，文章标签使用实心强调色和对应前景色。

### 禁止状态

- 左侧标签先亮，文章卡片标签稍后才亮，或顺序相反。
- 结果集合正确，但文章卡片保留上一筛选状态。
- 同名标签在两处使用互相矛盾的选中语义。

### 验收

1. 选择单个和多个标签，逐帧记录两处样式变化。
2. 对结果中的每篇文章核对对应标签状态。
3. 延迟客户端脚本后刷新带筛选 URL，确认首帧仍同步。
