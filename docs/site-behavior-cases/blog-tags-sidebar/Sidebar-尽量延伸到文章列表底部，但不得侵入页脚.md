# 案例：Sidebar 尽量延伸到文章列表底部，但不得侵入页脚

### 场景

桌面博客页的文章列表和分页形成主要内容高度，Sidebar 需要在视觉上与其对齐。

### 正确行为

- Sidebar 可用高度尽量延伸到分页上方分隔线附近，避免过早截断形成无意义空白。
- 页面接近底部时，Sidebar 下边界在页脚之前停止，并保留既定间距。
- 长标签目录在该高度内独立滚动，不通过延长文档挤压页脚。

### 禁止状态

- Sidebar 在列表尚有大量内容时提前结束于视口中部。
- Sidebar 或其滚动条穿过页脚分界线。
- 为追求底部对齐而让 Sidebar 在接近页脚时整体上移跳动。

### 验收

1. 在第一页、最后一页和不同筛选结果高度下滚到页面底部。
2. 比较 Sidebar 底部、分页分隔线和页脚顶部的相对位置。
3. 连续滚动接近底部，确认 Sidebar 没有突然上移或改变高度。
