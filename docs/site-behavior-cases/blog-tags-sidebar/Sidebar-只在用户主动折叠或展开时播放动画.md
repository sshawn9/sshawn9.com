# 案例：Sidebar 只在用户主动折叠或展开时播放动画

### 场景

Sidebar 状态可能由用户点击、刷新恢复、历史恢复或响应式布局变化产生。

### 正确行为

- 用户明确点击折叠或展开时，Sidebar 与正文使用既定过渡动画。
- 刷新首帧、站内返回恢复和断点初始化直接呈现目标状态，不播放恢复动画。
- 减少动态效果偏好下，主动动画按站点规则收敛或取消。

### 禁止状态

- 页面加载时从默认宽度动画到保存宽度。
- 返回博客页面时重复播放一次折叠或展开动画。
- 为避免加载动画而彻底移除用户主动操作时已有的正确动画。

### 验收

1. 录制主动点击与刷新恢复两种路径，比较动画是否只出现在前者。
2. 测试历史返回和移动、桌面布局切换。
3. 开启 reduced-motion 后复查主动操作反馈仍明确且不过度运动。
