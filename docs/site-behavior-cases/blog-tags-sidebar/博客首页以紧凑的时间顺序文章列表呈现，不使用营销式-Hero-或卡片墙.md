# 案例：博客首页以紧凑的时间顺序文章列表呈现，不使用营销式 Hero 或卡片墙

### 场景

用户进入博客首页，希望快速浏览已有文章，而不是先阅读站点宣传内容。

### 正确行为

- 页面主体从文章浏览功能开始，文章按时间顺序形成连续、易扫描的列表。
- 标题、摘要、日期和标签具有清晰层级，单屏能看到足够多的文章。
- 标题常态无下划线，只有悬停或键盘聚焦时出现明确的链接下划线反馈。
- 视觉设计服务于内容查找，不把文章拆成占用大量空间的营销卡片。

### 禁止状态

- 使用大幅 Hero、口号或说明占据文章列表上方主要视口。
- 把每篇文章包装成高装饰、高留白的卡片墙，显著降低浏览密度。
- 为追求紧凑而删掉辨识文章所需的摘要、日期或标签。
- 所有标题常态显示下划线，给连续列表增加无意义的视觉噪声。

### 验收

1. 分别在桌面和移动视口首次进入博客首页。
2. 确认无需越过宣传区即可开始浏览文章，且标题、摘要、日期和标签可辨认。
3. 比较不同长度标题和摘要，确认列表仍连续、紧凑且没有互相遮挡。
