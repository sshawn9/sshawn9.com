# 案例：页面滚动、文章列表与标签列表滚动彼此独立

### 场景

博客页内容超过视口，标签目录也有独立溢出，用户在不同区域滚动。

### 正确行为

- 页面滚动负责正文列表和整体文档位置，标签列表在 Sidebar 内独立滚动。
- 滚动正文不改变标签目录的 scrollTop；滚动目录不移动正文位置。
- Sidebar 通过布局约束保持可用，但不劫持页面滚轮或制造嵌套滚动陷阱。

### 禁止状态

- 滚动博客列表时整个 Sidebar 随正文离开视口。
- 在标签目录滚动会同时推动页面。
- 指针离开目录后滚轮仍被旧的 Sidebar 监听器拦截。

### 验收

1. 分别记录文档和标签容器的滚动值。
2. 在正文、标签目录及边界附近使用滚轮、触控板和键盘滚动。
3. 确认每次只有目标滚动上下文变化，且到达边界后的行为符合浏览器预期。
