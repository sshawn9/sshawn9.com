# 案例：筛选结果高度变化不得带动 Sidebar 改变位置

### 场景

筛选使文章数量从多页变成少量结果，或取消筛选使列表重新变长。

### 正确行为

- Sidebar 的顶部、宽度和可用高度由页面布局及视口决定，不依赖结果列表高度。
- 结果变短时 Sidebar 仍保持既定位置，并在页脚边界前结束。
- 结果变长时 Sidebar 独立保持可用，不随正文内容滚走。

### 禁止状态

- 筛选后 Sidebar 突然缩短、上移或下移。
- 为匹配短结果而让 Sidebar 侵入页脚或失去内部滚动。
- 取消筛选时 Sidebar 重新挂载并闪烁。

### 验收

1. 在全量、多结果标签和极少结果标签之间切换。
2. 连续测量 Sidebar 顶部、底部、宽度和滚动容器高度。
3. 滚到页面底部检查页脚边界，确认结果高度变化不破坏布局。
