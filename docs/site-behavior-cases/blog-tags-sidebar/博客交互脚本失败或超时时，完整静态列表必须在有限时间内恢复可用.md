# 案例：博客交互脚本失败或超时时，完整静态列表必须在有限时间内恢复可用

### 场景

博客增强脚本下载失败、解析失败或长时间没有完成水合。

### 正确行为

- 服务端 HTML 提供可阅读、可点击的文章和标签链接。
- 如果为避免中间态而短暂约束结果可见性，必须有较短且确定的失败释放期限。
- 失败后用户仍可通过普通链接浏览标签页和文章，站点外壳始终可用。

### 禁止状态

- 脚本失败导致列表永久空白或长时间白屏。
- 失败释放依赖脚本自身执行，脚本未加载时永远不会触发。
- 静态回退展示与 URL 完全无关的不可用内容且没有可导航入口。

### 验收

1. 拦截博客交互 bundle 并从无筛选、标签和分页地址冷进入。
2. 记录结果区恢复可见所需时间，并确认外壳从未隐藏。
3. 使用标签、分页和文章静态链接继续浏览，确认核心路径可用。
