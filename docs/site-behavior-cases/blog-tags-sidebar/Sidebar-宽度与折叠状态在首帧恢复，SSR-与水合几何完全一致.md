# 案例：Sidebar 宽度与折叠状态在首帧恢复，SSR 与水合几何完全一致

### 场景

用户改变过 Sidebar 宽度或折叠状态，随后刷新或重新进入博客页面。

### 正确行为

- 保存状态在页面首次绘制前应用到实际布局容器。
- 服务端标记、绘制前状态和客户端控制器对宽度及折叠含义一致。
- 水合完成只接管后续操作，不再次写入导致可见几何变化。

### 禁止状态

- 先显示默认展开宽度，再恢复保存宽度或折叠状态。
- 折叠按钮固定，但标签列表、正文或导航仍在刷新期间移动。
- 每次首次进入无法恢复，必须操作并刷新第二次才生效。

### 验收

1. 分别保存非默认宽度和折叠状态，执行冷、温缓存刷新。
2. 从首帧连续测量按钮、Sidebar 边界和正文起点。
3. 离开博客进入其他页面后返回，再次验证首次进入即恢复。
