# 案例：调整图形分栏只改变可用空间，不永久缩放几何比例

### 场景

用户调整交互图的左右分栏后，图形需要适配新容器。

### 正确行为

- 调整只改变视口或画布可用空间，模型中的真实几何和数据比例不被改写。
- 恢复原宽度时图形按原始数据重新适配，不累计缩放误差。
- 需要保持等比例的轴或对象继续遵守其数学约束。

### 禁止状态

- 每次调宽都把当前像素比例写回模型数据。
- 来回拖动后对象越来越扁、越来越小或坐标范围漂移。
- 为填满容器而扭曲有定量意义的几何关系。

### 验收

1. 记录模型数据与轴比例，反复调宽多个循环。
2. 恢复初始宽度并与初始图形及数值比较。
3. 检查等比例、固定范围和自动适配图形各自遵守契约。
