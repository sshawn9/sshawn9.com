# 案例：闭环时序图通过直接拖动时间点调整参数，不回退到滑块

### 场景

闭环控制时序图的核心任务是理解多个时间事件及其相对关系。

### 正确行为

- 用户直接拖动图中的时间点或事件标记调整相应参数。
- 拖动受到合法时序约束，相关区间、连线和数值同步更新。
- 键盘提供对同一时间点的等价调整，不另造脱离图形语义的主滑块。

### 禁止状态

- 用页面外滑块替代直接操纵，使图形与参数关系割裂。
- 时间点可以越过不允许的事件顺序。
- 拖动只改标记位置，数值和时序关系稍后才更新。

### 验收

1. 拖动每类时间点到允许范围和边界。
2. 观察参数、区间、连线与控制结果的同步变化。
3. 使用键盘完成同样调整并验证约束一致。
