# 案例：分隔条拖动时两侧布局与图形实时更新

### 场景

交互图由两个可调宽区域组成，用户拖动中间分隔条比较内容。

### 正确行为

- 分隔条、两侧容器和内部图形在拖动期间同步响应。
- 尺寸受明确上下限约束，两侧始终保留可操作内容。
- 指针与键盘均可调整，释放时保存必要的最终状态。

### 禁止状态

- 只移动分隔条视觉线，图形在释放后才重排。
- 拖到极端导致一侧负宽、溢出或控件不可见。
- 每个移动事件重建图形而产生明显掉帧。

### 验收

1. 使用指针连续拖到两端并来回快速调整。
2. 记录两侧尺寸、图形重绘和帧率。
3. 使用键盘验证步进、范围语义和最终布局一致。
