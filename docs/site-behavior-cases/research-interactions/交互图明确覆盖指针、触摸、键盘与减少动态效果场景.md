# 案例：交互图明确覆盖指针、触摸、键盘与减少动态效果场景

### 场景

用户通过鼠标、触控笔、触摸屏或键盘操作交互图，并可能启用减少动态效果偏好。

### 正确行为

- 核心参数和选择提供指针、触摸与键盘可达的等价操作路径。
- 触摸命中区足够且不依赖悬停；键盘焦点顺序与状态名称明确。
- reduced-motion 下取消非必要运动，同时保留直接、可理解的状态反馈。

### 禁止状态

- 核心信息只能通过 hover 查看。
- 触摸滚动与图形拖动无法区分，页面被锁死。
- 减少动态效果后连必要结果更新也停止。

### 验收

1. 分别使用鼠标、真实触摸或触控模拟及纯键盘完成核心任务。
2. 检查焦点、命中范围和页面滚动冲突。
3. 开启 reduced-motion 重复操作，确认信息完整且运动收敛。
