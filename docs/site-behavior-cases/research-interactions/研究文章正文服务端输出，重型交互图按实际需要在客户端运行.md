# 案例：研究文章正文服务端输出，重型交互图按实际需要在客户端运行

### 场景

研究文章包含可直接阅读的解释、公式和多种重型交互图。

### 正确行为

- 正文、公式说明、图注和非交互回退由服务端直接输出。
- 只有确实需要浏览器状态或绘图运行时的图形在客户端初始化。
- 每个交互图独立按可见性和用途加载，不把整篇文章变成单个客户端应用。

### 禁止状态

- 为使用少量交互图而让全部正文等待 JavaScript。
- 客户端失败后文章只剩空白图框且没有解释。
- 所有图形无条件同时加载，阻塞首屏阅读。

### 验收

1. 禁用 JavaScript 打开研究文章，确认正文、公式、图注和回退可读。
2. 开启 JavaScript 记录各图形的加载与初始化时机。
3. 拦截单个图形脚本，确认其他正文和交互不受牵连。
