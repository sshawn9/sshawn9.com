# 案例：滑块拖动过程中连续更新数值与图形，不等待释放

### 场景

用户拖动研究图中的参数滑块以观察连续关系。

### 正确行为

- 数值标签和图形在拖动过程中连续、同步更新。
- 更新以最新输入为准并与动画帧协调，不积压所有中间计算。
- 释放后最终值精确提交，键盘调整获得同等反馈。

### 禁止状态

- 只有 pointerup 或 change 后才更新图形。
- 数值先变化、图形明显滞后，或旧帧在释放后继续播放。
- 为流畅性任意丢弃最终输入或大幅降低响应率。

### 验收

1. 以慢速和快速连续拖动滑块，并录制数值与图形。
2. 检查帧顺序、最终值和主线程长任务。
3. 使用方向键调整，确认更新契约一致。
