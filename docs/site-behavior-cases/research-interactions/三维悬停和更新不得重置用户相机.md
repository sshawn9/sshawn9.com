# 案例：3D 悬停和更新不得重置用户相机

### 场景

用户旋转、缩放或平移三维图后继续悬停、拖动参数或更新数据。

### 正确行为

- 相机是用户状态，普通数据和样式更新复用当前相机。
- 悬停高亮、标签更新和主题变化不触发自动视角重算。
- 只有用户明确选择重置视图时才回到默认相机。

### 禁止状态

- 每次悬停或参数变化都跳回初始视角。
- 组件重新布局后悄悄覆盖用户相机。
- 不同更新路径分别保存相机，导致偶发回退。

### 验收

1. 设置明显不同于默认值的三维相机。
2. 执行悬停、参数拖动、主题切换、调宽和聚焦。
3. 逐项比较相机值，最后验证明确重置操作才改变它。
