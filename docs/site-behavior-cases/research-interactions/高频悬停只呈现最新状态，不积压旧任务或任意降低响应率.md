# 案例：高频悬停只呈现最新状态，不积压旧任务或任意降低响应率

### 场景

指针快速扫过曲线、点集或三维对象，连续产生大量悬停状态。

### 正确行为

- 渲染调度合并过期任务，每帧只处理最新仍有效的悬停目标。
- 提示与高亮跟随当前指针，不在指针停止后继续回放旧状态。
- 性能优化依据实际计算成本，不能用固定低频节流破坏跟手性。

### 禁止状态

- 每个原始事件都排队计算，导致提示明显落后。
- 任意限制到低刷新率，使正常设备也感到卡顿。
- 指针离开图形后旧提示仍继续闪现。

### 验收

1. 快速往返扫过密集数据区域并录制提示位置。
2. 记录任务队列、长任务和最终悬停目标。
3. 在不同性能设备上确认跟手且无过期状态回放。
