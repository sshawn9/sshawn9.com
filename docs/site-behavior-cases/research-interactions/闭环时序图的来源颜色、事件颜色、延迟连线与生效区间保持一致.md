# 案例：闭环时序图的来源颜色、事件颜色、延迟连线与生效区间保持一致

### 场景

闭环时序图同时表达信息来源、事件、传输延迟和控制生效区间。

### 正确行为

- 来源拥有稳定颜色，相关事件、连线和区间继承同一语义体系。
- 延迟连线的起止点与实际事件时序准确对应。
- 生效区间随参数变化连续更新，并与正文、图例和数值一致。

### 禁止状态

- 同一颜色在不同位置代表互相冲突的来源。
- 连线连接错误事件或方向相反。
- 区间视觉更新滞后于时间点，产生短暂错误因果关系。

### 验收

1. 按来源逐项核对颜色、事件、连线和区间。
2. 拖动各时间点，逐帧检查关系同步。
3. 对照正文定义和边界参数验证因果顺序。
