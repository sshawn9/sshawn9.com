# 案例：二维关系图显示对应点，三维图使用引导关系而不添加冗余点

### 场景

文章用二维和三维图解释同一对象或映射关系，两种表达的信息密度不同。

### 正确行为

- 二维图明确显示需要比较的对应点，帮助读者建立一一关系。
- 三维图通过适当的引导线、投影或高亮表达关系，不额外堆叠没有新信息的点。
- 两种图的颜色、名称和选中状态保持一致映射。

### 禁止状态

- 二维图缺少对应点，读者只能猜测映射。
- 三维图复制全部二维标记，造成遮挡和视觉噪声。
- 同一对象在两种图中使用不同颜色或标签。

### 验收

1. 逐项核对二维对应点与三维引导关系。
2. 在旋转、缩放和参数变化时观察遮挡与映射。
3. 仅依靠图例和图形复述对象关系，确认没有歧义。
