# 案例：交互图水合前预留最终几何，不以空白岛或第二套骨架改变布局

### 场景

客户端交互图尚未完成加载和水合，正文已经开始绘制。

### 正确行为

- 服务端占位使用与最终图形一致的宽高比、标题和必要说明。
- 水合在同一几何区域内接管，不插入第二套骨架或重新撑开正文。
- 加载失败时占位转为有意义回退，不永久保留空白大块。

### 禁止状态

- 首帧没有高度，图形加载后把后续正文整体向下推。
- SSR 骨架与客户端图形短暂同时存在，造成双倍高度。
- 为固定高度裁切在窄容器中实际需要的内容。

### 验收

1. 延迟图形 bundle，从首帧到水合完成测量容器与后续正文坐标。
2. 在桌面、移动和 Sidebar 不同宽度下比较最终几何。
3. 拦截脚本确认失败回退不会留下无意义空区。
