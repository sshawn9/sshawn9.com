# 案例：可拖动控制点跟手更新，并允许拖动期间继续查看悬停信息

### 场景

用户直接拖动图中的控制点，同时需要观察当前位置及派生量。

### 正确行为

- 控制点、关联曲线和数值在拖动过程中保持同一状态帧。
- 指针捕获保证拖出点的原命中区域后仍可连续操作。
- 拖动期间仍展示必要悬停信息，释放或取消时正确结束状态。

### 禁止状态

- 控制点跟手但曲线晚一拍，或反向。
- 开始拖动后悬停信息全部失效。
- 指针离开点即丢失拖动，留下未提交的半状态。

### 验收

1. 缓慢和快速拖动控制点跨越整个合法区域。
2. 观察点、曲线、数值和悬停提示的同步性。
3. 测试指针移出图形、取消和释放后的最终状态。
