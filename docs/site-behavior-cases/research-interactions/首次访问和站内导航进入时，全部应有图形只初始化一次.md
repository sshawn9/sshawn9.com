# 案例：首次访问和站内导航进入时，全部应有图形只初始化一次

### 场景

用户直接打开含多个交互图的文章，或从站内其他页面导航进入并反复往返。

### 正确行为

- 当前文章所需的每个图形在每次有效进入中恰好初始化一次。
- 离场时释放页面级实例，再次进入创建新的单一实例。
- 持久外壳更新、字体就绪和主题事件不得触发重复初始化。

### 禁止状态

- 首次访问只加载部分图，站内进入却重复创建两份。
- 一次主题切换或 Sidebar 变化重新执行初始化。
- 旧页面图形离场后仍保留观察器和动画循环。

### 验收

1. 记录每个图形挂载、销毁和资源请求次数。
2. 分别直接访问、站内进入并往返同一文章多次。
3. 操作主题、字体和 Sidebar，确认实例数始终符合当前页面需求。
