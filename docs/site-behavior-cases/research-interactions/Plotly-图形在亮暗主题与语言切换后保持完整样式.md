# 案例：Plotly 图形在亮暗主题与语言切换后保持完整样式

### 场景

用户查看 Plotly 图形时切换亮暗主题或页面语言。

### 正确行为

- 背景、坐标轴、网格、字体、图例、悬停框和标注同时切换到目标主题。
- 语言变化更新图形内文案，但保留数据、相机和用户参数。
- 更新在现有实例上完成，不出现旧新主题混合帧或整图重建。

### 禁止状态

- 只更新背景，留下旧主题坐标文字或悬停框。
- 语言切换后图例、单位或提示仍是上一语言。
- 更新样式时相机复位、参数丢失或图形闪白。

### 验收

1. 修改图形参数和相机后切换主题与语言。
2. 检查所有视觉部件、文本和交互状态。
3. 连续快速切换，确认迟到更新不会覆盖最新选择。
