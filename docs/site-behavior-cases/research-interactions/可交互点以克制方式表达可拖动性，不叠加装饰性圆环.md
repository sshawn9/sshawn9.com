# 案例：可交互点以克制方式表达可拖动性，不叠加装饰性圆环

### 场景

图形中的少量点支持直接拖动，需要让用户发现但不能遮蔽数据。

### 正确行为

- 可拖动性通过指针、适度尺寸、对比或操作反馈表达。
- 命中区域可以大于可见点，但视觉仍保持图形语义。
- 聚焦、拖动和悬停状态清晰区分，并兼顾键盘与触摸。

### 禁止状态

- 为提示拖动叠加长期存在的装饰性双圆环或脉冲动画。
- 扩大可见点到遮挡相邻数据。
- 只靠鼠标指针提示，触摸和键盘用户无法识别或操作。

### 验收

1. 在未操作、悬停、聚焦和拖动状态下比较视觉表达。
2. 测试实际命中范围与相邻数据可见性。
3. 使用触摸和键盘完成等价调整。
