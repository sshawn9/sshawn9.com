# 案例：Sidebar 等无关界面状态变化不得重置研究交互状态

### 场景

用户已经调整图形参数、相机和控制点，随后操作文章 Sidebar、主题、语言之外的布局控件。

### 正确行为

- Sidebar 折叠、展开、调宽和内部滚动只改变可用布局。
- 研究交互组件保持同一实例及参数、相机、选择和动画进度。
- 图形仅执行必要的尺寸适配，不重新请求数据或恢复默认状态。

### 禁止状态

- 无关布局状态被作为组件 key，导致全部图形重挂载。
- 折叠 Sidebar 后参数、控制点或三维相机复位。
- 为保状态而拒绝响应容器尺寸变化，造成裁切。

### 验收

1. 为多个图形设置明显的非默认状态。
2. 依次折叠、展开、拖动两侧 Sidebar 并滚动其内部内容。
3. 记录组件实例、状态、网络请求和最终尺寸，确认只有布局适配发生。
