# 案例：项目车辆预览支持连续二维拖动，并实时更新最近投影与控制响应

### 场景

项目卡片或详情中的车辆预览允许用户在二维平面拖动车辆，观察路径跟踪关系。

### 正确行为

- 车辆可在合法二维区域连续拖动，而不是只沿预设一维滑轨移动。
- 每帧根据当前位置重新计算最近路径投影、误差和控制响应。
- 车辆、投影点、引导关系和数值保持同步，并适配卡片容器变化。

### 禁止状态

- 拖动被锁定为单轴，无法探索横向偏差。
- 使用上一次投影缓存造成图形与数值错位。
- 卡片布局或 Sidebar 变化重置车辆状态。

### 验收

1. 在路径两侧、弯道内外和端点附近连续二维拖动。
2. 对照独立计算核验最近投影和控制量。
3. 调整容器、主题并往返页面，检查状态与几何行为。
