# 案例：数值输入允许合法的编辑中间态，不能因即时校验阻断输入

### 场景

用户编辑负数、小数或科学计数值，输入过程中会暂时出现空字符串、负号或小数点。

### 正确行为

- 输入状态与已提交数值分离，允许正常编辑所需的中间文本。
- 有效完整值即时或按规则更新图形；无效最终值在失焦或提交时给出明确反馈。
- 约束不会把光标强制移位或不断回写旧值。

### 禁止状态

- 输入负号或删除原值时立即被还原，导致无法键入目标数。
- 每次按键都格式化文本并把光标跳到末尾。
- 暂时无效文本直接传入模型产生 NaN 或图形崩溃。

### 验收

1. 输入负数、小数、科学计数和从旧值全选替换。
2. 测试空白、越界和非数值的失焦、回车及取消路径。
3. 检查光标位置、错误反馈和图形最终值。
