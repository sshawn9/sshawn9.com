# 案例：聚焦模式保留参数、滚动位置、相机与图形比例，并使用原生对话框语义

### 场景

用户把交互图打开为更大的聚焦视图，操作后再关闭返回正文。

### 正确行为

- 聚焦前后使用同一交互状态，参数、相机、图形比例和选择不重置。
- 打开时锁定背景交互，焦点进入聚焦内容；关闭后焦点和正文滚动位置恢复。
- 使用原生对话框语义及可靠的 Escape、遮罩和关闭操作。

### 禁止状态

- 聚焦模式创建第二个不同步实例或把图形恢复默认值。
- 关闭后正文跳到页面顶部或焦点丢失。
- 仅用视觉浮层模拟对话框，背景仍可聚焦和滚动。

### 验收

1. 修改参数、相机和比例后从正文中部打开聚焦模式。
2. 在聚焦中继续操作，并用按钮、Escape 和遮罩路径关闭。
3. 核对状态、焦点、背景可交互性和滚动位置。
