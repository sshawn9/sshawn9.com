# 案例：动态图例与标注随数据避让，保持可读且不遮挡图形

### 场景

数据、语言、容器宽度或参数变化使图例和标注占用区域改变。

### 正确行为

- 图例与标注根据当前数据范围和可用空间动态选择安全位置。
- 避让优先保留关键数据、单位和对象对应关系。
- 位置变化稳定，不在相邻参数值之间无必要来回跳。

### 禁止状态

- 使用固定像素位置压住曲线、点或轴标签。
- 标注越出画布、互相覆盖或被裁切。
- 为保证不遮挡而把图例移到与数据关系难以理解的位置。

### 验收

1. 遍历数据极值、语言、字体和容器宽度组合。
2. 检查图例、标注、数据与画布边界的重叠。
3. 连续微调参数，确认布局不会抖动且关系仍清楚。
