# 案例：Escape 采用搜索输入的标准清空语义，并同步完整查询状态

### 场景

用户在搜索输入框中按 Escape，或使用清空按钮移除当前查询。

### 正确行为

- Escape 遵循 Pagefind 搜索输入的标准语义，清空查询并重置搜索。
- 输入文本、URL、摘要、结果和空查询状态同步更新。
- 清空操作只影响搜索状态，不同时关闭或改变无关界面。

### 禁止状态

- 输入已清空但 URL、摘要或结果仍保留旧查询。
- 为保留旧行为拦截并重新实现 Pagefind 的完整输入状态机。
- 一个 Escape 同时清空搜索并关闭无关浮层。

### 验收

1. 输入查询后按 Escape，检查输入、URL、摘要和结果全部归零。
2. 分别使用清空按钮与键盘删除文本，核对相同状态结果。
3. 在移动菜单或其他浮层存在时重复测试事件边界。
