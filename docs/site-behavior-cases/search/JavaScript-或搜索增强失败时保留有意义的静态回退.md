# 案例：JavaScript 或搜索增强失败时保留有意义的静态回退

### 场景

搜索能力或结果数据无法加载。

### 正确行为

- 页面仍显示搜索用途、可访问的输入语义和通向主要内容入口的静态回退。
- 错误在有限时间内明确呈现，不让用户无限等待空结果。
- Header、导航、壁纸和页脚保持正常，不因搜索失败被隐藏。

### 禁止状态

- 搜索页永久空白或一直显示加载中。
- 为掩盖失败隐藏整个页面。
- 错误回退提供看似可用但永远无响应的输入框。

### 验收

1. 分别模拟搜索能力、入口数据和结果数据不可用。
2. 记录失败释放时间与可见错误或回退内容。
3. 使用静态导航继续访问博客、项目和首页，确认站点仍可用。
