# 案例：全站索引包含首页、项目列表、项目详情、文章与未完成的 About

### 场景

用户通过站内搜索查找文章之外的站点页面。

### 正确行为

- 索引覆盖首页、项目列表、每个项目详情、可见文章和 About 页面。
- 每类结果使用真实标题、描述、语言和稳定 URL。
- 未完成的 About 以其准确施工状态参与索引，不被伪装成完整介绍。

### 禁止状态

- 搜索只索引文章，导致项目和基础页面不可发现。
- 把导航、版本或语言文件重复索引成多个页面。
- 索引草稿或当前环境不可访问的路由。

### 验收

1. 为每类页面选择唯一关键词并执行搜索。
2. 核对结果 URL、标题、语言及可见范围。
3. 比较 Preview 与 Production，确认草稿和部署边界正确。
