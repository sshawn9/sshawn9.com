# 案例：Escape 只取消输入框焦点；清空查询必须由明确操作触发

### 场景

用户在搜索输入框中按 Escape，或希望主动清空当前查询。

### 正确行为

- Escape 只让输入框失去焦点，保留查询文本、URL 和结果。
- 清空由明确的清空控件或用户删除文本触发，并同步更新 URL 和结果。
- 键盘行为与页面其他浮层的 Escape 语义协调，不产生双重副作用。

### 禁止状态

- 按 Escape 直接删除查询或导航离开搜索页。
- 清空按钮只清输入框，结果和 URL 保留旧值。
- 一个 Escape 同时关闭无关界面并清空查询。

### 验收

1. 输入查询后按 Escape，检查焦点、文本、URL 和结果。
2. 分别使用清空按钮与键盘删除文本，核对完整状态变化。
3. 在移动菜单或其他浮层存在时重复测试事件优先级。
