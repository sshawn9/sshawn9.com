# 案例：搜索页直接呈现搜索工具，不使用巨型搜索 Hero、教程或快捷键噪声

### 场景

用户进入搜索页的目标是立即输入查询并浏览结果。

### 正确行为

- 主内容直接从可聚焦的搜索输入和结果区域开始。
- 必要提示简洁、就近呈现，不挤占搜索结果空间。
- 每个页面的主命中与章节命中共享一个完整的结果卡片边界，不得溢出或游离在卡片外。
- 页面沿用正常站点外壳，不重复导航已经表达的页面身份。

### 禁止状态

- 用巨型标题、插图或营销说明占据首屏。
- 展示大段搜索教程、快捷键列表或无实际需要的统计。
- 只给主命中绘制卡片，却把同一页面的章节命中排在卡片外。
- 为追求极简而移除输入名称、清空操作或结果状态。

### 验收

1. 在桌面和移动端进入搜索页，确认无需滚动即可开始输入。
2. 使用鼠标、触摸和键盘完成查询及清空。
3. 检查空查询、无结果和有结果状态都清晰且不冗余。
