# 案例：搜索期间结果区显示稳定骨架，完成后提交当前查询结果

### 场景

用户修改查询，新一轮搜索需要异步计算或加载索引分片。

### 正确行为

- 搜索开始后，结果区使用与最终结果几何相近的 Pagefind 骨架明确表示加载。
- 输入、Header、背景、导航和页脚保持可见稳定；骨架不得扩散到整个页面。
- 当前查询的结果、数量和空状态准备完成后作为一个整体提交。
- 迟到的旧查询结果不得覆盖更新后的查询。

### 禁止状态

- 为保留旧结果而克隆 Pagefind 内部 DOM、建立双层可交互结果或依赖其私有 class。
- 加载时结果区完全空白、页面高度无约束坍塌或整个 body 被隐藏。
- 结果先替换，数量或状态文案稍后更新。
- 较慢的旧请求在新请求后完成并回写页面。

### 验收

1. 人为延迟不同查询并快速连续输入。
2. 逐帧记录输入、骨架、站点外壳、新结果和数量。
3. 核对骨架与结果卡片的主要几何，不出现整页跳变。
4. 确认没有空窗、混合状态或迟到结果覆盖。
