# 案例：从搜索结果进入页面再返回时，回到同一查询和结果状态

### 场景

用户搜索后点击某条结果阅读目标页面，再通过返回操作回到搜索。

### 正确行为

- 返回后直接恢复原查询、结果集合和搜索页滚动位置。
- 已聚焦或选中的结果上下文在合理范围内保留，便于继续浏览。
- 搜索引擎不重复显示空状态后再重算同一结果。

### 禁止状态

- 返回后搜索页被重置为空查询。
- 输入值恢复但结果先消失、稍后重新出现。
- 页面回到顶部，用户无法找到刚才打开的结果位置。

### 验收

1. 查询后滚动到中部并打开不同类型结果。
2. 使用站内返回和浏览器后退分别返回搜索页。
3. 从首帧检查查询、结果、滚动位置和焦点上下文。
