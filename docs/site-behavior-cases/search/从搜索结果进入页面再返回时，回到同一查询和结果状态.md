# 案例：从搜索结果进入页面再返回时，回到同一查询和结果状态

### 场景

用户搜索后点击某条结果阅读目标页面，再通过返回操作回到搜索。

### 正确行为

- 返回后原查询和 URL 立即恢复；已有结果应继续显示并恢复搜索页滚动位置。只有首次载入、没有可复用结果时才允许显示几何稳定的骨架。
- 已聚焦或选中的结果上下文在合理范围内保留，便于继续浏览。
- 搜索引擎不得先显示空查询、错误旧结果或整页空白后再重算。

### 禁止状态

- 返回后搜索页被重置为空查询。
- 输入值已经恢复，但结果区完全空白、显示另一查询结果或发生无约束高度坍塌。
- 页面回到顶部，用户无法找到刚才打开的结果位置。

### 验收

1. 查询后滚动到中部并打开不同类型结果。
2. 使用站内返回和浏览器后退分别返回搜索页。
3. 从首帧检查查询、URL、已有卡片（或仅首次加载时限定在结果区的骨架）、最终结果、滚动位置和焦点上下文。
