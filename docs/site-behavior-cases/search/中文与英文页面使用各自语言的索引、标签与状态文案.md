# 案例：中文与英文页面使用各自语言的索引、标签与状态文案

### 场景

用户分别在中文和英文搜索页面输入查询、查看类型标签和结果状态。

### 正确行为

- 每种语言页面加载对应语言的索引与界面文案。
- 结果标题、描述和类型标签优先使用当前语言，缺少翻译时遵守明确回退规则。
- 无结果、加载、错误和计数文案与当前界面语言一致。

### 禁止状态

- 中文页面查询英文索引或混入另一语言状态文案。
- 仅翻译输入框，结果类型和空状态仍使用源语言。
- 语言切换后保留旧索引实例并返回错误结果。

### 验收

1. 使用只存在于中文、只存在于英文和两者共有的关键词搜索。
2. 切换语言并核对索引、类型、计数和状态文案。
3. 检查回退文章的实际语言标记与提示。
