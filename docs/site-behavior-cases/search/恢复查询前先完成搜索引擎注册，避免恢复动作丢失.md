# 案例：恢复查询前先完成搜索引擎注册，避免恢复动作丢失

### 场景

用户带查询 URL 冷进入或返回搜索页，客户端需要恢复查询和结果。

### 正确行为

- 页面先确认当前搜索引擎和索引实例已可接受查询，再提交恢复值。
- 查询恢复只执行一次，并对应当前语言与部署版本。
- 引擎迟到时保留待恢复意图，不把查询当成空值丢弃。

### 禁止状态

- 在自定义搜索组件注册前设置查询，事件无人接收。
- 注册后再次用默认空值覆盖已恢复查询。
- 旧语言引擎迟到后接管当前页面。

### 验收

1. 人为延迟搜索组件和索引加载，从带查询 URL 冷进入。
2. 记录注册、恢复和首次结果顺序，确认查询只提交一次。
3. 在延迟期间切换语言或离开页面，确认迟到实例不会污染当前状态。
