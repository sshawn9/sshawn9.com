# 案例：搜索增强失败时保留有意义的静态回退

### 场景

JavaScript 正常运行，但搜索组件、索引或结果数据无法加载。

### 正确行为

- 页面显示搜索用途、不可误操作的输入语义和通向主要内容的静态入口。
- 错误在有限时间内明确呈现，不让用户无限等待空结果。
- Header、导航、壁纸和页脚保持正常。

### 禁止状态

- 搜索页永久空白或一直显示加载中。
- 为掩盖搜索故障隐藏整个页面。
- 错误回退提供看似可用但永远无响应的输入框。

### 验收

1. 分别模拟搜索组件、索引和结果数据不可用。
2. 记录失败释放时间与可见回退内容。
3. 使用静态导航继续访问博客、项目和首页。
