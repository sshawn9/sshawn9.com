# 案例：搜索增强失败时保留有意义的静态回退

### 场景

JavaScript 正常运行，但搜索组件、索引或结果数据无法加载。

### 正确行为

- 首次加载在尚无已提交结果时失败，页面显示搜索用途、不可误操作的输入语义和通向主要内容的静态入口。
- 已有结果后的刷新失败不得退回整页静态导航：保留旧卡片、数量和可操作链接，并在结果附近给出错误提示。
- 错误在有限时间内明确呈现，不让用户无限等待空结果；刷新错误提示不应遮住或禁用旧结果。
- Header、导航、壁纸和页脚保持正常。

### 禁止状态

- 搜索页永久空白或一直显示加载中。
- 为掩盖搜索故障隐藏整个页面。
- 错误回退提供看似可用但永远无响应的输入框。
- 刷新失败清空已显示结果，或把一次刷新失败误判成首次加载失败而切换到静态回退。

### 验收

1. 在首次进入时分别模拟搜索组件、索引和结果数据不可用。
2. 再在已有结果后模拟索引分片或结果数据失败。
3. 记录首次失败的释放时间与静态回退内容，以及刷新失败时保留的旧结果和邻近错误提示。
4. 首次失败后使用静态导航继续访问博客、项目和首页；刷新失败后继续打开旧结果链接。
