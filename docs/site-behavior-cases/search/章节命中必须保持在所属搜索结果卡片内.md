# 案例：章节命中必须保持在所属搜索结果卡片内

### 场景

一篇页面同时命中主结果和多个章节，搜索结果展示章节摘要。

### 正确行为

- 主命中和全部章节命中共同位于同一结果卡片边界内。
- 内容在不同视口宽度下换行或裁切，不突破卡片。
- 320px 窄屏下，长标题、代码标识符和路径不能撑宽结果列表；主标题与正文摘要按需换行，不能依靠整页裁切隐藏溢出。章节摘要仍可保持单行省略。

### 禁止状态

- 章节标题和摘要从卡片底部或右侧溢出。
- 下一张卡片与上一条章节命中重叠。

### 验收

1. 使用能产生多个章节命中的中英文查询。
2. 在桌面、窄窗口和长文本情况下检查每张结果卡片边界。
3. 在 320px 与桌面宽度间切换，检查真实查询结果以及含连续长词和高亮片段的内容；确认卡片不超出结果区，主文本不超出自身宽度。
