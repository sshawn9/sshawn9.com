# 案例：照片池按 Unsplash 创建时间合并、去重、限量并避免无变化写入

### 场景

定时任务周期性获得与旧池部分重复、顺序不同或包含不合格项的候选照片。

### 正确行为

- 候选先按规则筛选，再以稳定照片 ID 去重合并。
- 池按 Unsplash created_at 维护新旧顺序，并限制为 250 张。
- 合并结果没有实质变化时不重复写 KV。

### 禁止状态

- 用抓取时间冒充照片创建时间，造成顺序不稳定。
- 同一照片以不同尺寸 URL 重复占位。
- 每次定时任务无条件全量覆写相同清单。

### 验收

1. 构造重复、乱序、超量和无效候选集。
2. 断言最终 ID 唯一、顺序稳定且数量不超过 250。
3. 对完全相同输入再次刷新，确认没有写入。
4. 检查公开清单不泄露维护字段。
