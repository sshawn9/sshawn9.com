# 案例：定时刷新失败时保留原有效清单；首次无清单时安全回退

### 场景

定时任务遇到 Unsplash 超时、错误响应、无合格照片或 KV 写入失败。

### 正确行为

- 已有有效清单继续对外服务，不因刷新失败被空值覆盖。
- 无任何历史清单时，端点明确返回暂不可用，页面使用默认背景。
- 下一次定时任务可以重新尝试，不要求重新部署网站。

### 禁止状态

- 上游一次失败清空整个照片池。
- 返回结构损坏的半份清单。
- 页面因增强背景不可用而阻塞正文。

### 验收

1. 分别在有旧清单和无清单时模拟上游与 KV 失败。
2. 检查旧清单内容、状态码和默认背景回退。
3. 恢复上游后再次运行定时任务，确认可自愈。
4. 验证故障期间正文和主题功能不受影响。
