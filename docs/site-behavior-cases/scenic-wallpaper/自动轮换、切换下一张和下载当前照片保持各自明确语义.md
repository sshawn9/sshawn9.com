# 案例：自动轮换、切换下一张和下载当前照片保持各自明确语义

### 场景

用户打开壁纸控制面板，看到自动轮换开关、下一张和下载操作。

### 正确行为

- 自动轮换只决定是否按计划换图。
- 下一张只从现有队列立即展示下一候选，不代表下载文件或固定照片。
- 下一张准备期间保留原按钮、命中区域和可用样式，以忙碌状态提供反馈；重复点击合并到同一个换图事务，不并行下载或累计跳图。
- 下载只保存当前可见照片，不改变队列、主题或自动轮换。

### 禁止状态

- 点击“下一张”同时改变自动轮换开关。
- 仅因下一张仍在加载或解码就禁用、淡化或替换按钮。
- 在默认背景下点击固定当前却先随机出一张照片。
- 下载操作切换到另一张照片。

### 验收

1. 分别记录三种操作前后的偏好、照片 ID、队列和下载事件。
2. 在景观开启、关闭和只有一张照片时验证控件状态。
3. 延迟下一张资源并快速连续点击，确认按钮保持原节点和命中区域，且只有一个换图事务。
4. 检查键盘名称与可见文案表达相同语义。
