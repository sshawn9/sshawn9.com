# 案例：清单更新时保留当前照片，只协调剩余队列而不立即切图

### 场景

用户正在观看某张照片时，客户端获取到新增、删除或重新排序的清单。

### 正确行为

- 当前照片仍在可展示状态时保持不变。
- 从待轮换队列删除新清单已不存在的照片，并纳入新增照片。
- 清单同步与照片切换使用同一队列模型，不创建第二套轮换逻辑。

### 禁止状态

- 每次清单刷新立即切换背景。
- 当前照片仍有效却被重置到清单第一项。
- 更新逻辑另建一套随机状态，导致重复或漏图。

### 验收

1. 记录当前照片与剩余队列，注入含新增和删除项的新清单。
2. 确认当前照片不变，剩余队列只包含有效且未重复项目。
3. 继续轮换，检查新增照片可进入且旧照片不回归。
4. 刷新页面确认协调后的会话状态可恢复。
