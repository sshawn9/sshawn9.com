# 案例：自动轮换采用 5–9 分钟随机间隔，并在一轮内避免重复照片

### 场景

景观背景和自动轮换均已开启，标签页持续可见。

### 正确行为

- 每次轮换后重新选择 5–9 分钟之间的随机等待。
- 随机队列在可用照片走完前不重复已显示照片。
- 池中只有一张可用照片时不启动无意义轮换。

### 禁止状态

- 使用固定间隔形成机械节奏。
- 连续两次随机到同一照片，或频繁在少数照片之间循环。
- 多个计时器并存造成短时间连换多张。

### 验收

1. 使用可控时钟采集多次计划间隔，确认全部位于范围内且并非固定值。
2. 用小型照片池完整走一轮，检查无重复。
3. 切换自动轮换开关，确认始终只有一个计时器。
4. 用单照片清单确认不安排轮换。
