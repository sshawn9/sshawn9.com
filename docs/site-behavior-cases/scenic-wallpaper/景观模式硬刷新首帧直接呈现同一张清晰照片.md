# 案例：景观模式硬刷新首帧直接呈现同一张清晰照片

### 场景

用户已在景观模式看到清晰照片，随后硬刷新同一页面。

### 正确行为

- 绘制前恢复保存的当前照片及必要元数据。
- 首个可见帧直接使用与刷新前相同的清晰照片。
- 客户端接管识别该图层为当前状态，不重新加载或重新过渡。

### 禁止状态

- 先出现默认背景，再切回照片。
- 同一照片从模糊重新变清晰。
- 首帧照片正确，但运行时又添加第二层相同照片造成闪亮。

### 验收

1. 在照片完全清晰后进行冷、温缓存硬刷新。
2. 从导航提交开始录制到接管完成。
3. 检查每帧背景类型、照片 ID、清晰度和图层数量。
4. 用正式 Worker Preview 与系统 Chrome复核本地结论。
