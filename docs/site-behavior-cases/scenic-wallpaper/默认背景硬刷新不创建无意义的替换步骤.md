# 案例：默认背景硬刷新不创建无意义的替换步骤

### 场景

用户关闭景观背景，页面使用内建默认背景并执行硬刷新。

### 正确行为

- 默认背景由稳定页面样式直接提供。
- 刷新过程中不存在旧层清理、新层补建或同图替换。
- 客户端壁纸增强未启用时不介入背景绘制。

### 禁止状态

- 默认背景也经历淡出、替换或闪烁。
- 为统一代码路径给默认背景创建临时图片层。
- 接管后才移除一个本可不存在的占位背景。

### 验收

1. 关闭景观背景并多次硬刷新。
2. 检查背景相关 DOM、样式和帧序列。
3. 确认没有临时图片层、透明度动画或资源请求。
4. 在亮暗主题分别验证。
