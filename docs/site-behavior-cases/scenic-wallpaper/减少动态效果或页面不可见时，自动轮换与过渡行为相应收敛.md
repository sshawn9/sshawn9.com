# 案例：减少动态效果或页面不可见时，自动轮换与过渡行为相应收敛

### 场景

用户启用 prefers-reduced-motion，或浏览器标签页进入后台后再恢复。

### 正确行为

- reduced-motion 下停止非必要自动轮换，并缩减装饰性过渡。
- 页面不可见时暂停轮换与清单同步计时，不积压切换。
- 恢复可见后从当前状态重新计划，不补播后台错过的照片。

### 禁止状态

- 后台标签页持续下载和切换背景。
- 返回页面瞬间连续补播多张照片。
- reduced-motion 只关闭 CSS 动画，JavaScript 计时仍在换图。

### 验收

1. 模拟 reduced-motion，等待超过轮换间隔并检查照片不变。
2. 将页面置于后台，推进时钟后恢复。
3. 观察网络、计时器和照片 ID，确认没有后台积压。
4. 关闭偏好后确认正常轮换可以重新启动且只有一个计划。
