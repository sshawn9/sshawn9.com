# 案例：每个标签页只保留当前与下一张景观照片

### 场景

用户在一个或多个标签页中浏览、刷新、开关景观模式并长期自动轮换照片。

### 正确行为

- 每个标签页独立保存当前照片和已经可直接显示的下一张照片。
- 下一张在后台完成下载、校验与解码后才进入备用槽；刷新或离线不必重新请求它。
- 换图只交换两个固定槽位，随后异步补齐新的下一张，不保存应用级历史图片。

### 禁止状态

- 不同标签页互相改变当前照片或轮换队列。
- 每换一张就新增永久记录，导致本站存储随使用时间持续增长。
- 因景观模式暂时关闭而清空当前或下一张照片。

### 验收

1. 在两个标签页分别轮换并刷新，确认状态互不影响。
2. 长时间轮换后确认仍只有当前与下一张两个固定图片槽位。
3. 断网后刷新并切换下一张，确认已准备的两个槽位仍可使用。
