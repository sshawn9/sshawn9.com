# 案例：开关景观模式时过渡完整复合背景，不出现先变亮、照片先消失或遮罩残留

### 场景

用户主动在默认背景与景观背景之间切换，当前主题可能为亮色或暗色。

### 正确行为

- 照片、遮罩、色调和默认底层作为完整视觉状态共同过渡。
- 关闭时从当前景观复合层平滑到默认层；开启时反向完成。
- 文字对比度在整个过渡期间保持可读。

### 禁止状态

- 关闭时先突然变亮，再回到默认背景。
- 照片先消失，遮罩稍后才移除。
- 开启时默认背景被瞬间替换，或文字短暂失去对比。

### 验收

1. 在亮暗主题下分别开关景观模式并逐帧录制。
2. 采样背景亮度、照片层、遮罩层和正文对比度。
3. 检查整个过渡为一条连续视觉路径。
4. 快速反向切换，确认旧过渡能正确取消且最新状态获胜。
