# 案例：Unsplash 密钥与照片池维护只存在于 Worker 端

### 场景

站点需要从 Unsplash 获取候选照片，同时公开网站代码和浏览器请求均可被访客检查。

### 正确行为

- Unsplash 访问密钥只由 Worker 的受保护环境读取。
- 搜索、筛选、去重、容量维护和清单写入都在服务端完成。
- 浏览器只接收展示所需的公开照片元数据与资源地址。

### 禁止状态

- 密钥出现在客户端 bundle、HTML、公开仓库或响应数据中。
- 浏览器直接调用需要密钥的 Unsplash 搜索接口。
- 为方便本地开发把真实密钥写入可提交文件。

### 验收

1. 扫描构建产物、HTML、source map 和公开响应中的密钥及变量值。
2. 观察浏览器网络请求，确认没有上游搜索 API。
3. 检查 Worker 在缺少密钥时安全失败且不泄露配置。
4. 验证示例环境文件只包含占位说明。
