# 案例：只有用户明确下载当前照片时才上报下载行为

### 场景

照片可能因首次展示、自动轮换、手动下一张或明确下载而被使用。

### 正确行为

- 普通显示、自动轮换和下一张只属于浏览行为，不调用下载报告。
- 用户明确点击下载按钮时，才执行文件下载并报告一次。
- 重复提交与失败重试不能制造多次报告。

### 禁止状态

- 每个访客显示照片都消耗一次下载报告额度。
- 自动轮换被误认为用户下载。
- 下载失败却上报成功多次。

### 验收

1. 依次触发初始显示、自动轮换、下一张和明确下载。
2. 统计报告端点调用，仅下载操作应产生一次。
3. 模拟双击和网络失败，检查去重与错误语义。
4. 确认普通浏览不受报告端点故障影响。
