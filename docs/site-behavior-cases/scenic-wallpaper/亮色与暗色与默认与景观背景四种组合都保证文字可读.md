# 案例：亮色/暗色与默认/景观背景四种组合都保证文字可读

### 场景

主题和背景模式独立组合，景观照片还可能包含明暗复杂区域。

### 正确行为

- 四种组合各有明确的文字、边界、遮罩和表面层级。
- 标题、正文、标签、目录、导航和署名均达到可辨识对比。
- 解决方案作用于全站视觉变量，而不是为每个文本块单独打底。

### 禁止状态

- 暗色景观中文字灰到几乎不可见。
- 亮色景观只让正文加不透明卡片，其他文字继续失败。
- 默认背景被景观专用高对比配色破坏。

### 验收

1. 选择包含亮天空、暗树枝和复杂纹理的真实照片。
2. 在四种组合下检查所有文字层级和交互状态。
3. 结合自动对比度检查与系统 Chrome视觉确认。
4. 发现局部失败时追溯全局变量，不接受无边界补丁。
