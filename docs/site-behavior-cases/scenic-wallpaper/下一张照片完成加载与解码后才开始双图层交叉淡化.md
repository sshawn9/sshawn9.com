# 案例：下一张照片完成加载与解码后才开始双图层交叉淡化

### 场景

自动轮换或用户手动切换下一张照片，目标图片可能较大或网络较慢。

### 正确行为

- 当前照片持续清晰显示，直到目标照片完成下载和解码。
- 目标就绪后才通过两层背景执行连续交叉淡化。
- 过渡完成后清理旧层，但不得影响新层。

### 禁止状态

- 先隐藏当前照片，再等待目标下载。
- 切换期间露出默认背景、空白或破损图片。
- 两层透明度叠加造成明显亮度脉冲。

### 验收

1. 延迟目标图片响应并触发自动与手动切换。
2. 逐帧记录两层资源、透明度和合成亮度。
3. 确认目标 decode 完成前当前照片不变。
4. 模拟目标失败，确认保留当前照片并尝试合理后续候选。
