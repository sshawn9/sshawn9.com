# 案例：亮色景观模式必要时牺牲照片清晰度以保证正文可读性

### 场景

亮色主题叠加复杂景观照片，单纯加深文字仍不足以保持稳定阅读。

### 正确行为

- 优先保证正文和操作信息清楚，允许通过统一遮罩降低照片存在感。
- 照片仍应可辨识，但不能与正文争夺前景。
- 遮罩策略覆盖整个页面视觉系统，并与暗色方案分别调校。

### 禁止状态

- 为追求背景“通透”让文字落在黑色树枝等高干扰区域。
- 每个组件各自增加白底补丁。
- 直接把所有照片完全抹掉，失去景观模式意义。

### 验收

1. 使用多种高反差照片在亮色主题浏览长文和列表。
2. 检查正文、标签、目录和导航的连续可读性。
3. 调整窗口和滚动位置，确认遮罩不依赖照片某一局部。
4. 与暗色模式对比，确认两者各自平衡而非共用错误参数。
