# 案例：关闭景观模式时自动轮换不可操作；重新开启时保留原照片与队列

### 场景

用户关闭景观总开关，之后可能调整自动轮换或重新开启景观背景。

### 正确行为

- 景观关闭时，自动轮换控件显示不可用语义并停止计时。
- 自动轮换偏好本身可以保留，不被景观开关重写。
- 重新开启后恢复关闭前的当前照片、队列和自动偏好。

### 禁止状态

- 景观关闭后计时器仍在后台换照片。
- 用户操作不可用控件却悄悄改变状态。
- 重新开启时抛弃会话照片并立即随机换图。

### 验收

1. 开启自动轮换后关闭景观背景。
2. 检查控件可用性、计时器和照片状态。
3. 等待超过轮换区间，再重新开启。
4. 确认照片、队列与偏好连续，且只创建一个新计时器。
