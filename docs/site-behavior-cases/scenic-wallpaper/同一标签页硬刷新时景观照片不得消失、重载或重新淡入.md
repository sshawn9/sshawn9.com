# 案例：同一标签页硬刷新时景观照片不得消失、重载或重新淡入

### 场景

景观照片和署名已经稳定显示，用户在同一标签页刷新页面。

### 正确行为

- 首个可见帧继续显示同一照片、同一遮罩和同一署名。
- 整个刷新过程没有同图过渡，正文不等待装饰背景。

### 禁止状态

- 照片短暂消失、露出黑帧或默认背景。
- 同一照片重新淡入、从模糊变清晰或发生明暗变化。
- 署名晚于照片出现或先显示上一张照片的信息。

### 验收

1. 在照片稳定后连续刷新至少六次。
2. 观察每一次从首帧到页面可操作的照片、遮罩和署名。
3. 断开网络后刷新，确认已有照片能够继续稳定呈现；确实无法恢复时正文仍立即可读。
