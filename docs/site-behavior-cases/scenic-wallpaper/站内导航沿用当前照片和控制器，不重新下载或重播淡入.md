# 案例：站内导航沿用当前照片和控制器，不重新下载或重播淡入

### 场景

用户在景观模式下通过主导航连续访问多个页面。

### 正确行为

- 壁纸控制器和当前图层属于持久外壳，跨页面导航保持实例。
- 当前照片不变时不重新设置资源、不重复 decode、不重播淡入。
- 页面内容切换不重置自动轮换计时和剩余队列。

### 禁止状态

- 每次导航背景从透明重新出现。
- 相同图片因页面切换产生新网络请求。
- 新页面创建第二个壁纸计时器。

### 验收

1. 记录图层节点、照片 ID、请求数、队列与下一轮换时间。
2. 连续导航多个页面。
3. 断言节点与状态连续、没有同图重复请求或淡入。
4. 等待一次自然轮换，确认只发生一次。
