# 案例：背景偏好跨浏览器会话保存，当前照片与随机队列按标签页保存

### 场景

用户设置景观开关和自动轮换，随后刷新、关闭重开浏览器，或在多个标签页独立浏览。

### 正确行为

- 景观总开关和自动轮换属于用户偏好，跨浏览器会话保存。
- 当前照片和随机队列只属于当前标签页会话。
- 新标签页可以独立随机，不能意外继承另一个标签页的进行中队列。

### 禁止状态

- 一次随机照片被永久保存成所有未来访问的固定背景。
- 刷新丢失当前照片，或重启浏览器仍强制恢复旧会话队列。
- 两个标签页互相改写当前照片。

### 验收

1. 设置偏好并刷新、重启浏览器，检查偏好持续存在。
2. 在同一标签页刷新，确认当前照片与队列连续。
3. 新开两个标签页，确认随机会话相互独立。
4. 模拟存储损坏，确认安全回退。
