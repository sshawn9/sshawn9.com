# 案例：摄影署名首帧完整、更新时原位替换且保持最低视觉权重

### 场景

景观照片需要显示摄影者和 Unsplash 来源，照片可能在刷新或轮换时变化。

### 正确行为

- 已保存照片的署名在首个可见帧同时出现。
- 换图时在同一位置原子更新摄影者和来源链接。
- 署名可读、可点击，但视觉优先级低于正文和导航。

### 禁止状态

- 图片先出现，Photo by 信息稍后闪入。
- 轮换后照片和署名短暂不匹配。
- 署名因字体等待单独消失重现，或突出到抢夺注意。

### 验收

1. 在景观模式温缓存硬刷新，逐帧检查照片与署名对应。
2. 触发轮换并记录照片 ID、摄影者和链接的更新时刻。
3. 延迟字体，确认署名遵循统一字体生命周期。
4. 检查键盘访问、外部链接和视觉层级。
