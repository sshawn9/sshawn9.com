# 案例：文章页不显示历史版本宣传条、相邻文章链接或无用版本数量

### 场景

文章页需要保持阅读聚焦，同时提供真正必要的版本能力。

### 正确行为

- 历史版本状态由版本列表和当前状态清楚表达，不额外插入宣传式横幅。
- 页面不自动增加上一篇、下一篇等相邻文章导航。
- 不显示没有决策价值的版本总数文案。

### 禁止状态

- 在正文顶部用醒目条幅反复提示“这是历史版本”。
- 在文末添加未要求的相邻文章链接，改变阅读结尾。
- 为显示数量而占用 Sidebar 空间，却不能帮助选择版本。

### 验收

1. 检查最新、历史、单版本和多版本文章。
2. 确认版本身份仍可理解，但不存在上述冗余界面。
3. 检查正文开头、结尾和 Sidebar 未被额外模块挤压。
