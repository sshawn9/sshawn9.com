# 案例：目录选中样式不得通过字重变化引起换行或几何位移

### 场景

正文滚动使当前章节在目录中不断变化，长标题可能占用多行。

### 正确行为

- 选中状态通过不改变文本度量的颜色、标记线或预留样式表达。
- 项目宽高、换行位置和后续条目坐标在选中前后保持稳定。
- 选中状态在亮暗主题与景观背景下均清晰可辨。

### 禁止状态

- 使用更粗字重导致标题重新换行并推挤整个目录。
- 动态增加未预留的边框或内边距。
- 为避免位移而让选中状态几乎不可辨认。

### 验收

1. 准备接近换行边界的长目录标题。
2. 逐节滚动并测量项目矩形、换行和目录 scrollTop。
3. 在各主题与 Sidebar 宽度下确认几何不变、状态可辨。
