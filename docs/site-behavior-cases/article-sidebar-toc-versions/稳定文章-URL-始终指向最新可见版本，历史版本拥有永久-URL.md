# 案例：稳定文章 URL 始终指向最新可见版本，历史版本拥有永久 URL

### 场景

用户通过普通文章链接访问最新内容，或通过引用访问特定历史版本。

### 正确行为

- 无版本段的稳定 URL 渲染当前环境中最新可见版本。
- 每个公开历史版本有不会随新版本发布而改变含义的永久 URL。
- 导航、规范链接和版本界面明确区分稳定入口与历史快照。

### 禁止状态

- 新版本发布后稳定 URL 仍停留在旧版本。
- 历史 URL 自动重定向到最新内容，破坏引用可复现性。
- 草稿版本让 Production 稳定 URL 失效或泄露草稿。

### 验收

1. 在新增公开版本前后分别访问稳定 URL。
2. 保存所有历史 URL 并在新版本后再次核对内容不变。
3. 在 Preview 与 Production 中验证“最新可见”遵守各自发布范围。
