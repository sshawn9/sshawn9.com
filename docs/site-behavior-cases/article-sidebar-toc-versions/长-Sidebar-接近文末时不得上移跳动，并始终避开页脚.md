# 案例：长 Sidebar 接近文末时不得上移跳动，并始终避开页脚

### 场景

用户阅读到长文章底部，右侧 Sidebar 自身也有很长的目录。

### 正确行为

- Sidebar 的顶部锚点和可用高度在正常滚动过程中保持稳定。
- 接近文末时通过明确的页脚边界约束停止延伸，不把整个 Sidebar 向上推。
- Sidebar 下边界始终位于页脚之前，正文“回到顶部”等结尾内容保持独立。

### 禁止状态

- 到达文末前后，Sidebar 整体突然上移或按钮被推到视口外。
- 目录滚动条、边界线或内容侵入页脚。
- 通过缩短所有页面的 Sidebar 来掩盖只在文末发生的问题。

### 验收

1. 在短文、长文和目录特别长的文章中连续滚到最底部。
2. 逐帧记录 Sidebar 顶部、底部、按钮和页脚顶部坐标。
3. 比较到达“回到顶部”前后，确认没有上移跳变且边界不相交。
