# 案例：折叠或调宽右侧 Sidebar 不得重建正文交互图

### 场景

文章包含多个重型交互图，用户折叠、展开或拖动右侧 Sidebar。

### 正确行为

- Sidebar 几何变化只改变正文可用空间，不卸载正文组件。
- 交互图按新容器尺寸调整显示，保留参数、相机、悬停和内部状态。
- 拖动期间更新经过适当调度，不让多个图形反复执行昂贵初始化。

### 禁止状态

- 每次宽度变化都重建或重新水合全部交互图。
- 图形恢复默认参数、相机或动画起点。
- 为避免卡顿而禁止 Sidebar 调宽或取消图形响应布局。

### 验收

1. 修改多个交互图的参数和相机后反复折叠、展开。
2. 连续拖动 Sidebar，并记录组件挂载次数、长任务和帧率。
3. 确认状态保留、图形最终尺寸正确且没有重复网络请求。
