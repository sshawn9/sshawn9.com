# 案例：错字、格式和链接修复只保留在 Git 历史中，不制造公开版本

### 场景

文章只修正错字、排版、失效链接或其他不改变实质含义的问题。

### 正确行为

- 修复直接更新当前版本，并由 Git 历史记录变更。
- 公共版本列表不增加无阅读价值的新版本。
- 修复不能改变文章结论、版本语义或首次发布日期。

### 禁止状态

- 每次微小格式调整都生成新版本并污染版本列表。
- 借“修错字”名义改写实质观点却不创建版本。
- 修复后意外改变列表排序、标签或项目归属。

### 验收

1. 分别准备纯修正和实质修订样例，确认版本判定不同。
2. 纯修正后检查公开版本数量、首次日期和稳定 URL 不变。
3. 对照 Git diff 确认修正范围没有越过实质内容边界。
