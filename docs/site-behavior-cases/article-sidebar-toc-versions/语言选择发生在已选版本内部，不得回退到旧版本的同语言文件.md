# 案例：语言选择发生在已选版本内部，不得回退到旧版本的同语言文件

### 场景

用户正在阅读特定版本并切换语言，而该版本可能缺少目标语言。

### 正确行为

- 先确定当前版本，再在该版本内部选择目标语言文件。
- 当前版本缺少目标语言时，按回退规则展示该版本实际可用语言并明确提示。
- 版本身份、正文、日期和资源始终属于同一版本。

### 禁止状态

- 为满足目标语言而悄悄跳到更旧版本。
- 页面标记仍是新版本，正文却来自旧版本语言文件。
- 语言切换改变稳定 URL 的版本语义且没有提示。

### 验收

1. 构造新版本缺少某语言、旧版本拥有该语言的文章。
2. 在新版本切换语言，核对版本不变、实际语言与提示正确。
3. 检查文章信息、资源和目录均来自同一版本。
