# 案例：点击目录项时，URL 锚点、正文目标与选中章节同时稳定

### 场景

用户点击本文目录中的任一层级章节。

### 正确行为

- URL 锚点、正文目标位置和目录选中项表达同一章节。
- 跳转考虑有效 Header 偏移，目标标题不会被遮挡。
- 点击后的目录内部滚动保证选中项可见，但不劫持正文滚动。

### 禁止状态

- 地址已变化，正文或选中项仍停在上一章节。
- 观察器在跳转过程中短暂选中沿途章节并造成闪烁。
- 目录自动滚动把正文也带动，或覆盖用户刚完成的滚动。

### 验收

1. 点击顶部、中部、底部及嵌套章节。
2. 连续记录 URL、目标标题坐标、选中项和两个滚动容器。
3. 刷新点击后的地址，确认同一章节从首帧恢复。
