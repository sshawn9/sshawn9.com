# 案例：右侧 Sidebar 不设置冗余标题，折叠按钮位于 Sidebar 外侧右上方

### 场景

文章右侧已经由“文章信息”“本文目录”等子模块说明内容，不需要额外占用一行总标题。

### 正确行为

- Sidebar 不显示“文章概览”等冗余总标题。
- 折叠按钮位于 Sidebar 内容区域外侧的右上方，不占用子模块可用高度。
- 展开和折叠时按钮保持稳定锚点，并具有明确的可访问名称和状态。

### 禁止状态

- 在 Sidebar 内新增只为容纳按钮的空 Header。
- 按钮压住目录内容、随内部滚动离开或因折叠横向跳动。
- 子模块标题与总标题重复表达同一含义。

### 验收

1. 在有无文章信息、目录和版本的组合下检查右上角布局。
2. 反复折叠、展开并滚动 Sidebar，记录按钮位置。
3. 使用键盘和辅助技术确认按钮名称、展开状态与操作结果一致。
