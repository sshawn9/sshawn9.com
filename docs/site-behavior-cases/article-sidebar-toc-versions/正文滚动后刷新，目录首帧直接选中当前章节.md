# 案例：正文滚动后刷新，目录首帧直接选中当前章节

### 场景

用户通过滚轮阅读到文章中部某章节，随后硬刷新页面并恢复正文位置。

### 正确行为

- 首个可见帧的目录选中项对应恢复后的正文章节。
- 绘制前恢复、URL 锚点和客户端观察器使用同一当前章节判定。
- 水合完成后不会先显示滚动前章节，再跳到当前章节。

### 禁止状态

- 首帧选中旧章节或第一节，观察器启动后才改正。
- 正文位置正确但目录选中状态晚一帧出现。
- 为避免闪烁而隐藏整个文章页面直到水合。

### 验收

1. 通过普通滚动停在不同深度的章节并刷新。
2. 延迟目录脚本，从首帧连续记录选中项与正文位置。
3. 在有无 URL 锚点两种情况下确认全程一致。
