# 案例：文章信息展示首次发布与最后更新，不展示阅读时长

### 场景

用户在文章详情页查看该逻辑文章的时间信息。

### 正确行为

- 文章信息明确展示首次发布日期与最后更新时间。
- 两个值分别来自逻辑文章的初始发布和当前可见版本更新语义。
- 页面不展示基于字数推算、精度虚假的阅读时长。

### 禁止状态

- 把更新时间误标为首次发布，或两个字段显示同一错误来源。
- 在文章列表和详情页混用不同时间语义。
- 添加“约几分钟阅读”等未经真实用户行为支持的指标。

### 验收

1. 对照单版本及多版本文章元数据核对两个日期。
2. 切换历史版本，确认页面对时间语义的表达符合版本规则。
3. 搜索文章界面，确认不存在阅读时长字段。
