# 案例：客户端接管目录时只更新状态，不重建服务端目录链接

### 场景

服务端已输出完整目录，客户端开始绑定当前章节追踪和内部滚动恢复。

### 正确行为

- 客户端复用既有目录节点，添加观察和状态更新能力。
- 水合前后的链接文本、层级、顺序和几何一致。
- 接管不会重置目录滚动位置或重新播放出现动画。

### 禁止状态

- 水合时删除服务端目录并创建外观相同的新树。
- 目录短暂消失、回到顶部或选中项闪回默认值。
- 重建使焦点、用户选择或浏览器锚点失效。

### 验收

1. 延迟目录脚本并记录水合前后关键链接节点身份。
2. 在目录中滚动并聚焦链接后触发水合。
3. 确认节点、焦点、滚动位置和几何均连续。
