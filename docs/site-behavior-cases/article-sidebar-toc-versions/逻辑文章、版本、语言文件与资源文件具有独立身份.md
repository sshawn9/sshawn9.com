# 案例：逻辑文章、版本、语言文件与资源文件具有独立身份

### 场景

同一主题可能存在多个公开版本、每个版本可能有多种语言，并附带图片或交互资源。

### 正确行为

- 逻辑文章是列表、标签、项目和稳定 URL 的去重单位。
- 版本表示公开内容快照，语言文件只是该版本的语言表达，资源归属于明确版本。
- 各层身份可独立解析，不依赖文件数量猜测文章数量或版本关系。

### 禁止状态

- 把每个语言文件当成独立文章重复索引。
- 把翻译更新误当成新的逻辑文章，或把资源目录当成版本。
- 通过当前目录结构偶然排序推断最新版本。

### 验收

1. 选择含多版本、多语言和资源的文章核对解析结果。
2. 检查列表去重、版本选择、语言切换和资源引用各使用正确身份。
3. 缺少某语言文件时确认不会改变文章与版本数量。
