# 案例：右侧 Sidebar 的宽度与折叠状态在首帧恢复

### 场景

用户调整右侧 Sidebar 宽度或折叠后，刷新文章或打开另一篇文章。

### 正确行为

- 保存的右侧 Sidebar 偏好在首个可见帧前应用。
- 按钮、Sidebar 边界、正文宽度和内部模块从首帧就是最终几何。
- 页面可操作后不再从默认值进行第二次可见修正。

### 禁止状态

- 先显示默认展开宽度，再跳到保存宽度或折叠状态。
- 只有按钮稳定，正文、目录或 Header 仍发生位移。
- 第一篇文章恢复失败，操作一次后第二次刷新才生效。

### 验收

1. 分别保存非默认宽度和折叠状态，执行冷、温缓存刷新。
2. 从首帧连续测量按钮、边界和正文起点。
3. 在不同文章间站内导航，确认偏好继承且无恢复动画。
