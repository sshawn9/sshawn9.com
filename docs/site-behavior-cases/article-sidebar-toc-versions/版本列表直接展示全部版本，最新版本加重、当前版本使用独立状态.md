# 案例：版本列表直接展示全部版本，最新版本加重、当前版本使用独立状态

### 场景

多版本文章需要让用户直接看清全部公开版本及当前阅读位置。

### 正确行为

- 版本列表不经额外下拉即可展示全部公开版本。
- 最新版本通过稳定的字重层级表达；当前版本另有不会与“最新”混淆的选中状态。
- 在阅读旧版本时，最新标记和当前标记分别落在正确项上。

### 禁止状态

- 只显示当前版本，必须打开多层控件才能看到历史。
- 把“当前”与“最新”当作同一状态，阅读旧版本时信息错误。
- 选中样式改变行高或换行，导致列表跳动。

### 验收

1. 从稳定 URL 和每个历史 URL 打开同一文章。
2. 核对全部版本、最新状态和当前状态。
3. 在窄 Sidebar 与不同语言下检查列表几何稳定。
