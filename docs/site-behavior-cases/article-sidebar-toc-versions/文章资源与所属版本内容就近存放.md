# 案例：文章资源与所属版本内容就近存放

### 场景

文章版本包含图片、数据、交互脚本或其他只属于该快照的资源。

### 正确行为

- 资源与其版本内容位于同一可识别范围，引用关系明确。
- 新版本可以拥有独立资源，不覆盖历史版本所需文件。
- 构建、迁移和删除检查能从版本边界判断资源归属。

### 禁止状态

- 所有版本共用无所有权的全局杂物目录。
- 新版本用同名文件覆盖旧资源，使历史页面改变。
- 删除当前版本时误删仍被历史版本引用的共享资源。

### 验收

1. 检查含图片、数据和交互代码的多版本文章目录关系。
2. 发布使用新资源的新版本，重新打开历史版本核对不变。
3. 运行引用检查，确认不存在悬空资源或不明确的跨版本依赖。
