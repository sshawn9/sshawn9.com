# 案例：无 JavaScript 时文章信息、完整目录和正文仍可阅读

### 场景

文章客户端脚本被禁用、失败或尚未加载。

### 正确行为

- 服务端 HTML 直接包含文章信息、完整目录链接和正文。
- 目录链接使用真实锚点，可由浏览器完成基本章节跳转。
- 缺少增强交互时内容顺序、语言和版本信息仍然准确。
- 文档与辅助技术顺序为“文章头 → 文章信息、目录与版本支持 → 正文”；不得让线性阅读者读完整篇长文后才能访问目录或版本。
- 桌面视觉仍为正文左、支持 Sidebar 右；视觉位置由 CSS Grid 决定，不反向改变文档顺序。

### 禁止状态

- 右侧只输出空容器，等待客户端生成目录。
- JavaScript 失败后正文不可见或目录永久显示加载状态。
- 基础锚点依赖点击处理器才能工作。
- 为匹配桌面左右布局而把正文排在支持信息之前，或使用脚本在响应式切换时搬运正文节点。

### 验收

1. 禁用 JavaScript 直接打开有长目录和多版本信息的文章。
2. 阅读文章信息并逐个点击若干目录链接。
3. 确认 DOM 与辅助技术顺序为文章头、支持信息、正文。
4. 确认正文、锚点和历史导航均可用，且没有空白岛；桌面视觉仍为正文左、Sidebar 右。
