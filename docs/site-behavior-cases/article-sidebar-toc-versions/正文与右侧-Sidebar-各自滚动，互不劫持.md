# 案例：正文与右侧 Sidebar 各自滚动，互不劫持

### 场景

长文章和长目录同时超过视口，用户分别阅读正文和浏览目录。

### 正确行为

- 文档滚动控制正文阅读位置，Sidebar 内容在自身容器内独立滚动。
- 滚动正文不改变目录容器位置；滚动目录不移动正文。
- 滚轮、触控板和键盘输入作用于当前明确的滚动上下文，边界行为符合浏览器预期。

### 禁止状态

- 正文滚动带着整个 Sidebar 一同离开可用区域。
- 在目录中滚动时页面同时移动。
- 全局监听器无条件阻止滚动，造成嵌套滚动陷阱。

### 验收

1. 同时记录文档和 Sidebar 的滚动值。
2. 在正文、目录和两者边界分别使用滚轮、触控板及键盘。
3. 确认每次只有目标滚动上下文变化，且目录项仍可点击。
