# 案例：单版本文章不显示版本界面，多版本文章默认打开最新版本

### 场景

文章可能只有一个公开版本，也可能已有多个历史快照。

### 正确行为

- 单版本文章不显示没有选择价值的版本模块或比较入口。
- 多版本文章从稳定 URL 进入时默认展示最新可见版本。
- 历史版本 URL 仍明确显示当前正在阅读的版本。

### 禁止状态

- 单版本文章显示只有一个选项的冗余版本控件。
- 多版本稳定入口随机打开旧版本或依赖客户端修正。
- 访问历史版本时界面误标为最新版本。

### 验收

1. 打开单版本、双版本和多版本文章。
2. 分别从稳定 URL 与历史 URL 进入并核对当前版本。
3. 禁用 JavaScript 确认默认版本和界面可见性仍正确。
