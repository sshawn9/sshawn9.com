# 案例：单语文章仍出现在另一语言列表中，并以实际 lang 与回退提示呈现

### 场景

某篇文章只有一种语言，但用户正在浏览另一种语言的博客列表或文章入口。

### 正确行为

- 逻辑文章仍可出现在另一语言列表，避免内容因缺少翻译完全不可发现。
- 打开后文档 lang、排版和辅助技术语言使用实际正文语言。
- 页面明确、克制地提示当前显示的是回退语言。

### 禁止状态

- 从另一语言列表完全删除单语文章，造成内容不可发现。
- URL 或界面显示目标语言，但正文 lang 伪装成目标语言。
- 为满足列表语言而跨版本选择旧翻译。

### 验收

1. 在两种语言列表中查找仅有一种语言的文章。
2. 打开文章并检查文档 lang、字体、目录和回退提示。
3. 使用屏幕阅读器或语言检测确认实际语言语义正确。
