# 案例：实质修订创建完整版本快照，旧版本保持不变

### 场景

文章发生会改变结论、结构、方法或读者理解的实质修订。

### 正确行为

- 修订以新的完整公开版本保存，不依赖运行时拼接旧版本差异。
- 已发布旧版本内容、元数据和资源保持可访问且不被覆盖。
- 最新稳定 URL 更新到新版本，历史版本永久地址继续指向原快照。

### 禁止状态

- 直接覆盖旧版本文件，使历史链接内容悄然变化。
- 只保存补丁而无法独立渲染历史版本。
- 新版本发布后旧资源被替换或删除，导致历史页面失真。

### 验收

1. 对实质修订前后内容、元数据和资源做逐项快照比较。
2. 打开稳定 URL 与所有历史版本 URL，确认各自内容正确。
3. 在无客户端增强条件下验证每个版本可独立阅读。
