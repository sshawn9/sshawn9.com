# 案例：右侧 Sidebar 默认展开，文章信息、目录、版本与比较均为其子模块

### 场景

用户打开有文章信息、目录或版本能力的文章页，桌面右侧需要提供统一的辅助浏览区域。

### 正确行为

- 首次没有保存偏好时，桌面右侧 Sidebar 默认展开。
- 文章信息、本文目录、版本选择和版本比较都是 Sidebar 的独立子模块。
- Sidebar 负责这些模块共同的宽度、折叠、滚动和页脚边界，子模块只负责自身内容。

### 禁止状态

- 每个子模块各自实现一套悬浮、折叠或调宽逻辑。
- 默认状态因文章类型或水合时序随机变成折叠。
- 子模块直接控制正文列宽，导致移除一个模块就破坏整体布局。

### 验收

1. 清除保存偏好后打开单版本、多版本和长目录文章，确认均默认展开。
2. 检查各模块层级及共同布局控制归属。
3. 分别缺少目录或版本数据时，确认剩余模块与 Sidebar 仍正常。
