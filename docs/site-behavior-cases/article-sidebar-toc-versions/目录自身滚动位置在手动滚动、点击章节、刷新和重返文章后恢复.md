# 案例：目录自身滚动位置在手动滚动、点击章节、刷新和重返文章后恢复

### 场景

长目录需要内部滚动；用户可能手动滚动目录、点击深层章节、刷新或离开后返回。

### 正确行为

- 每篇文章保存自己的有效目录滚动位置。
- 手动滚动和点击章节后产生的最终位置都能在首次刷新及重返时恢复。
- 恢复直接呈现目标位置，不从目录顶部可见地滚过去。

### 禁止状态

- 只有纯手动滚动能恢复，点击目录项后的状态丢失。
- 第一次刷新回顶部，第二次才恢复。
- 不同文章共用一个位置并互相污染。

### 验收

1. 清理会话状态后分别测试手动滚动和点击深层目录项。
2. 对每种路径执行刷新、进入另一文章再返回和历史返回。
3. 从首帧记录目录 scrollTop，确认首次即恢复且按文章隔离。
