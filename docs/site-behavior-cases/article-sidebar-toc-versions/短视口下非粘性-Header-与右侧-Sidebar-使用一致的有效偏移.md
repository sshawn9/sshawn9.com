# 案例：短视口下非粘性 Header 与右侧 Sidebar 使用一致的有效偏移

### 场景

视口高度较短时，Header 的粘性策略发生变化，右侧 Sidebar 仍需正确定位。

### 正确行为

- Sidebar 的顶部偏移派生自当前有效的 Header 布局契约，而不是重复硬编码。
- Header 不再粘性时，Sidebar 使用该状态对应的偏移和可用高度。
- 断点前后正文、按钮和 Sidebar 不重叠，也不留下无意义空隙。

### 禁止状态

- Header 已改变策略，Sidebar 仍使用旧的固定像素偏移。
- CSS 与脚本分别维护不同偏移值并产生漂移。
- 改变视口高度时 Sidebar 跳到 Header 下方错误位置。

### 验收

1. 在目标断点上下逐步改变视口高度。
2. 测量 Header 底部、Sidebar 顶部及其可用高度。
3. 检查刷新和站内导航后使用同一有效偏移。
