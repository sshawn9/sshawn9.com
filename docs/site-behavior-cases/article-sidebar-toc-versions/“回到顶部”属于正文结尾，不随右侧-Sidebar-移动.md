# 案例：“回到顶部”属于正文结尾，不随右侧 Sidebar 移动

### 场景

用户阅读到文章末尾，正文提供“回到顶部”操作，右侧 Sidebar 同时受页脚边界约束。

### 正确行为

- “回到顶部”位于正文内容流结尾，并随正文列布局。
- Sidebar 的高度、折叠或文末约束不改变该操作的位置。
- 操作返回文章顶部，焦点和滚动行为符合既定可访问规则。

### 禁止状态

- 把“回到顶部”放入 Sidebar，使其随目录滚动或折叠消失。
- Sidebar 接近页脚时把该操作向上推或遮挡。
- 点击后焦点丢失或触发不受控的多次滚动。

### 验收

1. 在 Sidebar 展开、折叠和不同宽度下滚到文末。
2. 比较“回到顶部”相对正文及页脚的位置。
3. 用鼠标和键盘激活，确认滚动与焦点结果一致。
