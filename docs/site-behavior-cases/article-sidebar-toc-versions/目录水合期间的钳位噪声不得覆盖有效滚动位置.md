# 案例：目录水合期间的钳位噪声不得覆盖有效滚动位置

### 场景

目录水合时内容高度可能短暂变化，浏览器将 scrollTop 钳位并产生非用户滚动事件。

### 正确行为

- 恢复逻辑不会先把水合噪声提交到持久存储。
- 结构稳定后从最后有效位置恢复；水合期间真实用户滚动则具有更高优先级。
- 一个生命周期只进行必要的恢复，不由多个钩子相互覆盖。

### 禁止状态

- 临时零值覆盖原位置，随后只能恢复到顶部。
- 简单清空所有待写状态，连真实用户输入也丢失。
- 目录在保存值与钳位值之间来回跳。

### 验收

1. 保存深层目录位置并人为延迟、扰动水合高度。
2. 检查存储值和可见位置未被钳位事件覆盖。
3. 在水合期间主动滚动，确认用户最终位置胜出并被保存。
