# 案例：回滚前先通过受保护的不可变版本地址核验目标版本

### 场景

Production 需要回滚到某个历史部署版本。

### 正确行为

- 操作者先在该版本的受保护不可变地址核对内容和关键行为。
- 核验通过后才把 Production 流量切向确切版本标识。
- 回滚记录保留来源版本、目标版本、核验结果和时间。

### 禁止状态

- 只凭提交说明或模糊时间选择回滚目标。
- 在公开 Production 上先切流再检查。
- 使用会随分支更新的地址作为历史版本证据。

### 验收

1. 选择历史版本并通过其不可变地址执行关键冒烟检查。
2. 对比版本标识后进行流量切换。
3. 确认公开站点与已核验快照一致，且可审计回滚过程。
