# 案例：构建错误、测试错误、环境错误、上游错误与凭据错误分别处理

### 场景

开发或部署流程失败，需要决定修代码、修测试、调整环境、重试或更新凭据。

### 正确行为

- 报告保留失败命令、阶段、退出信息和可复现条件。
- 根据证据区分代码构建、测试断言、运行环境、外部上游和认证授权问题。
- 后续动作与类别匹配，不用一种通用重试掩盖所有错误。

### 禁止状态

- 任何失败都归咎于代码，或任何失败都归咎于环境。
- 测试本身错误却修改产品行为迎合它。
- 凭据无效时反复运行构建，制造噪声而不解决根因。

### 验收

1. 为各类别保留至少一个可控失败样例。
2. 检查日志能否在不暴露秘密的前提下完成分类。
3. 验证每类失败触发正确处置且不会误改部署流量。
