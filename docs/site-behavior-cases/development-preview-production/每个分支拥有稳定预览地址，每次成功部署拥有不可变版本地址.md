# 案例：每个分支拥有稳定预览地址，每次成功部署拥有不可变版本地址

### 场景

同一分支持续部署供审阅，同时需要准确引用某次已验证构建。

### 正确行为

- 分支预览地址持续指向该分支最近一次成功部署。
- 每次成功部署另有不可变版本地址，之后不会被新提交覆盖。
- 界面或部署输出明确区分“最新分支状态”和“特定版本快照”。

### 禁止状态

- 每次部署只产生随机地址，没有稳定分支入口。
- 所谓版本地址随下一次部署改变内容。
- 失败部署把稳定分支地址切到不完整产物。

### 验收

1. 对同一分支连续完成两次成功部署并记录两类地址。
2. 确认分支地址更新、旧版本地址内容不变。
3. 制造一次失败部署，核对稳定地址仍指向上次成功版本。
