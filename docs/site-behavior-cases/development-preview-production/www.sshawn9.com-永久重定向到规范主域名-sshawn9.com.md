# 案例：www.sshawn9.com 永久重定向到规范主域名 sshawn9.com

### 场景

用户或搜索引擎访问带 www 的历史或误写地址。

### 正确行为

- www 主机使用永久重定向到 sshawn9.com。
- 路径、查询参数和必要锚点语义在重定向后保持。
- 页面规范链接、站点地图和内部链接统一使用无 www 主域名。

### 禁止状态

- www 与无 www 同时提供可索引的重复内容。
- 所有 www 请求都重定向到首页并丢失原路径或查询。
- 形成 http、https、www 与主域之间的重定向循环。

### 验收

1. 请求 www 首页、深层文章、查询参数和不存在路径。
2. 检查状态码、Location、跳转次数及路径保留。
3. 扫描内部链接、canonical 与 sitemap，确认只使用规范主域。
