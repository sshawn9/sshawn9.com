# 案例：just dev 提供 Astro Dev Toolbar 草稿入口，可直接查看全部草稿

### 场景

作者在本地运行 just dev，需要快速确认当前有哪些草稿文章。

### 正确行为

- 本地 Astro Dev Toolbar 中提供范围明确的草稿入口。
- 操作可直接到达只包含草稿的浏览结果，无需在正式博客 UI 增加筛选控件。
- 工具只承担“快速查看草稿”这一实际需求，不附带无关控制台设施。

### 禁止状态

- just dev 启动后工具栏缺失或草稿入口未注册。
- 为草稿入口修改正式博客筛选状态机或页面布局。
- 自作主张增加草稿标记、详情提示或其他未要求的周边能力。

### 验收

1. 从干净进程运行实际 just dev 入口。
2. 在系统 Chrome 打开 Toolbar 并激活草稿入口。
3. 核对结果只含草稿、正式博客结构未增加控制元素，停止 Dev 后工具不存在。
