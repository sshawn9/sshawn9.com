# 案例：拉取请求验证不依赖部署密钥，部署复用同一份已验证构建产物

### 场景

来自分支或外部贡献的拉取请求需要安全验证，合并后再发布已验证内容。

### 正确行为

- 构建、类型检查和测试不需要部署凭据即可运行。
- 有权部署的阶段获取已验证的不可变产物，而不是重新构建另一份未知结果。
- 部署密钥只暴露给最小权限、明确受信任的发布环境。

### 禁止状态

- 为运行普通测试向所有拉取请求注入生产密钥。
- 测试一份源码，部署阶段重新解析依赖并生成不同产物。
- 未受信任代码可读取或间接输出部署凭据。

### 验收

1. 在无任何部署密钥条件下运行拉取请求验证。
2. 记录验证产物摘要并与实际上传产物比较。
3. 审查凭据作用域、触发条件和日志，确认无泄露路径。
