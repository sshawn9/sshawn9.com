# 案例：只有可判定为瞬时上游故障的操作才有限重试

### 场景

部署流程调用外部 API、上传服务或平台接口时出现失败。

### 正确行为

- 仅对证据表明可恢复的超时、限流或瞬时服务故障进行有限重试。
- 重试采用有上限的退避，并保持操作幂等或可判定结果。
- 语法、测试、权限和永久配置错误立即失败并给出明确原因。

### 禁止状态

- 用无上限重试掩盖确定性代码错误。
- 重试非幂等发布操作，产生重复部署或不可知状态。
- 每次失败立即高频重试，加剧上游限流。

### 验收

1. 模拟瞬时 5xx、限流、认证失败和构建失败。
2. 检查仅前两类按策略重试，次数和退避符合上限。
3. 核对重试后部署记录没有重复或半完成产物。
