# 案例：草稿不是标签，草稿工具不得进入正式页面结构

### 场景

开发者需要快速查找草稿，但该能力只服务非正式环境。

### 正确行为

- 草稿状态由发布元数据表达，不污染长期主题标签体系。
- 草稿入口作为独立开发工具存在，不成为 BlogBrowser、Sidebar 或正式布局的业务分支。
- Production 源输出和产物中都不存在草稿控制界面及其样式、脚本。

### 禁止状态

- 添加 Draft 标签并让计数、筛选和 URL 承担发布状态。
- 在主页面结构中永久挂载只在开发时隐藏的草稿按钮。
- 为开发工具修改所有正式组件的交互状态机。

### 验收

1. 检查内容标签数据和正式页面 DOM，不存在草稿主题或隐藏工具。
2. 比较加入工具前后的主线组件接口和 Production 产物。
3. 在非正式环境使用工具，确认其功能无需主结构参与。
