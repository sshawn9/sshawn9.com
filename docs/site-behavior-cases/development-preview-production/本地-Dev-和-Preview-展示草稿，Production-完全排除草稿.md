# 案例：本地 Dev 和 Preview 展示草稿，Production 完全排除草稿

### 场景

作者需要在本地和受保护预览中审阅草稿，而公开网站只能包含已发布内容。

### 正确行为

- 本地 Dev 与部署 Preview 的文章路由和浏览入口包含草稿。
- Production 在构建数据源阶段排除草稿，而不是只在界面隐藏。
- 同一判定覆盖所有语言和版本，不存在从旁路访问草稿的方式。

### 禁止状态

- Production 列表不显示草稿，但直接 URL 仍可访问。
- 本地 Dev 因复用 Production 条件而看不到草稿。
- 仅依赖客户端筛选保护已经进入产物的草稿内容。

### 验收

1. 使用同一内容集合分别构建或运行三种环境。
2. 检查草稿列表项、直接路由、页面源文件和产物内容。
3. 对多语言、多版本草稿重复验证，不只检查博客首页。
