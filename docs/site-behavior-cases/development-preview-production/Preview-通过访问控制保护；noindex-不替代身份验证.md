# 案例：Preview 通过访问控制保护；noindex 不替代身份验证

### 场景

Preview 可能包含草稿、未公开项目或内部审阅信息。

### 正确行为

- 未授权访问在内容到达浏览器前被访问控制阻止。
- noindex 只作为搜索引擎提示，与身份验证形成不同层次的保护。
- 授权流程覆盖所有 Preview 路由和静态数据入口。

### 禁止状态

- 认为 noindex 能阻止知道 URL 的人访问内容。
- 只保护首页，文章、搜索分片或资源可匿名读取。
- 把认证逻辑放在客户端，敏感 HTML 已经下发。

### 验收

1. 在无凭据会话请求首页、文章、资源和索引数据。
2. 确认内容未泄露，并验证授权后正常访问。
3. 独立检查 noindex，确认两项保护均存在且职责不同。
