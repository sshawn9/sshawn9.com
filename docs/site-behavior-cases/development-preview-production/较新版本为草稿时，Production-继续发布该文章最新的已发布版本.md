# 案例：较新版本为草稿时，Production 继续发布该文章最新的已发布版本

### 场景

一篇已发布文章正在编写新版本，新版本仍标记为草稿。

### 正确行为

- Production 的稳定文章 URL 继续指向该逻辑文章最新已发布版本。
- 标签、项目、搜索、列表摘要和资源也使用同一已发布版本。
- Dev 与 Preview 可以查看草稿新版本，同时保留访问历史版本的能力。

### 禁止状态

- 因最新版本是草稿而把整篇已发布文章从 Production 删除。
- Production 正文来自旧版本，列表元数据却泄露草稿版本。
- 稳定 URL 返回 404 或重定向到草稿地址。

### 验收

1. 为已发布文章添加元数据不同的草稿新版本。
2. 在三种环境核对稳定 URL、列表、标签、项目、搜索和资源。
3. 确认 Production 各入口一致使用最新已发布版本。
