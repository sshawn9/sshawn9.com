# 案例：预览失败不得改变 Production 或其他分支的正常流量

### 场景

某个分支的构建、上传或 Preview 健康检查失败。

### 正确行为

- 失败被限制在当前分支当前尝试，不切换稳定预览流量。
- Production 和其他分支继续服务各自最近一次成功版本。
- 失败状态清楚指出阶段和影响范围。

### 禁止状态

- 预览失败清空或覆盖 Production 部署。
- 共享可变资源让其他分支同时不可用。
- 工作流失败后仍把稳定地址指向部分上传产物。

### 验收

1. 在构建、上传和验证阶段分别制造可控失败。
2. 请求当前分支旧预览、其他分支和 Production。
3. 核对流量版本未变，失败报告能准确定位范围。
