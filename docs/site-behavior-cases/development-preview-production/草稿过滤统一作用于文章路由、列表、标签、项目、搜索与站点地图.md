# 案例：草稿过滤统一作用于文章路由、列表、标签、项目、搜索与站点地图

### 场景

Production 构建从同一内容集合生成多种路由和索引产物。

### 正确行为

- 草稿可见性在共享内容选择边界统一判定。
- 文章路由、博客列表、标签计数、项目关联、搜索索引和站点地图消费同一可见集合。
- 各派生产物的数量和链接不会互相矛盾。

### 禁止状态

- 每个页面各写一份草稿判断并逐渐漂移。
- 草稿不在列表却进入搜索、标签计数或 sitemap。
- 为修一个入口只添加局部过滤补丁。

### 验收

1. 添加带独有标题、标签和项目的草稿文章。
2. 在 Production 产物中搜索其标题、路径、标签和资源引用。
3. 在 Dev 与 Preview 检查相同派生产物按环境正确包含它。
