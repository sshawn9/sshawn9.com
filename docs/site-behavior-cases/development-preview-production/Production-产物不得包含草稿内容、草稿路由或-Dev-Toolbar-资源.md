# 案例：Production 产物不得包含草稿内容、草稿路由或 Dev Toolbar 资源

### 场景

Production 构建完成，即将公开部署。

### 正确行为

- 产物级检查确认没有草稿正文、唯一文本、直接路由和资源引用。
- 不包含 Astro Dev Toolbar 或本站开发工具的脚本、样式及注册代码。
- 排除发生在生成阶段，公开服务器无需依靠隐藏规则保护这些内容。

### 禁止状态

- 草稿文件已进入产物，只靠 robots、CSS 或认证页面遮挡。
- Dev Toolbar 界面不显示，但 bundle 仍随 Production 下载。
- 只检查首页 HTML，不检查搜索分片、站点地图和静态资源。

### 验收

1. 使用草稿唯一标识扫描完整 Production 产物。
2. 枚举输出路由、搜索数据、sitemap 与资源清单。
3. 检查网络构建图中不存在 Dev Toolbar 和开发工具入口。
