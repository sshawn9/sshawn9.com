# 案例：本地 Dev 与部署模式是两个独立维度

### 场景

网站既有本地开发服务器，也有部署后的 Preview 和 Production，两类概念决定不同能力。

### 正确行为

- “是否本地 Dev”只决定本地调试工具和开发运行时能力。
- “Preview 或 Production”决定内容可见范围、索引策略、访问保护和部署流量。
- 同一内容规则由明确环境信号产生，不用某个偶然命令名称猜测。

### 禁止状态

- 把所有非 Production 都当作 Astro Dev，导致部署 Preview 引入本地工具。
- 因本地不是部署环境就跳过 Preview 内容规则。
- 多个互相矛盾的布尔值分别控制同一草稿可见性。

### 验收

1. 列出本地 Dev、部署 Preview 和 Production 的环境矩阵。
2. 核对每种环境的内容、工具、索引与访问控制。
3. 使用实际启动和部署入口验证信号来源唯一且结果可预测。
