# 案例：Cloudflare 边缘缓存与浏览器本地缓存分别验证，不能混为一谈

### 场景

同一响应同时经过 Cloudflare 边缘缓存和用户浏览器缓存，问题可能发生在任一层。

### 正确行为

- 浏览器 Cache-Control、条件请求和本地命中独立于边缘缓存状态观察。
- 边缘命中、重新验证和清理通过相应响应头与不同客户端请求验证。
- 结论明确指出是哪一层复用、过期或返回了旧内容。

### 禁止状态

- 看到边缘 HIT 就断言浏览器没有发起请求。
- 清除浏览器缓存后把边缘旧响应误判为本地缓存。
- 只用 curl 的单次响应推断真实浏览器缓存行为。

### 验收

1. 分别使用全新浏览器配置、已预热浏览器和独立 HTTP 客户端请求同一资源。
2. 记录浏览器网络来源、请求头、响应缓存头和边缘状态。
3. 独立改变或清理一层，确认另一层的行为可区分。
