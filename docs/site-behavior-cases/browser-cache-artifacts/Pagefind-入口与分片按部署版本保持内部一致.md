# 案例：Pagefind 入口与分片按部署版本保持内部一致

### 场景

Pagefind 搜索入口文件会继续加载同一构建生成的索引元数据和内容分片。

### 正确行为

- 入口、清单、词典和结果分片来自同一部署版本。
- 缓存策略允许入口发现新部署，同时保证其引用的版本化分片可稳定复用。
- 部署切换是原子的，不让用户获取跨版本混合索引。

### 禁止状态

- 长期缓存稳定入口，却清理它引用的旧分片。
- 新入口配到旧分片或反向混用，导致搜索报错或漏结果。
- 将搜索失败误判为查询逻辑问题，而不检查部署和缓存一致性。

### 验收

1. 记录一个部署的 Pagefind 入口及全部引用关系。
2. 预热缓存后发布索引变化，再执行旧会话和新会话搜索。
3. 检查每次请求形成同一版本的完整引用闭包且结果正确。
