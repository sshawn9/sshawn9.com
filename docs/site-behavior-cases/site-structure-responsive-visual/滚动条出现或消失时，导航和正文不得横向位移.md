# 案例：滚动条出现或消失时，导航和正文不得横向位移

### 场景

页面或浮层改变可滚动状态，浏览器主滚动条随之出现或消失。

### 正确行为

- 页面应为滚动条宽度保留一致空间，或采用不会改变内容宽度的等效策略。
- Header、正文和居中容器保持相同水平基线。
- 预留空间不能形成始终可见的难看空槽。

### 禁止状态

- 打开浮层或切换页面时，全站向左或向右跳动。
- 只修 Header，正文仍移动，或反之。
- 为消除位移永久显示不符合设计的宽滚动轨道。

### 验收

1. 在有主滚动条与无主滚动条页面间来回导航。
2. 打开和关闭可能锁定滚动的对话框或浮层。
3. 逐帧比较 Header、正文与页脚的横向边界。
4. 在支持覆盖式和占位式滚动条的环境分别观察。
