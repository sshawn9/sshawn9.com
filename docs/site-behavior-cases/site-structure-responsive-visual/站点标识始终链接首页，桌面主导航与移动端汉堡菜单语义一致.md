# 案例：站点标识始终链接首页，桌面主导航与移动端汉堡菜单语义一致

### 场景

用户在桌面或移动设备上访问任意页面，并通过 Header 识别站点和切换主要栏目。

### 正确行为

- 站点标识是稳定的首页入口。
- Projects、Blog、About、GitHub 等主要目的地在桌面和移动端表达相同信息架构。
- 移动端只改变呈现方式，不改变链接目标、当前项或键盘语义。

### 禁止状态

- 站点标识在不同页面指向不同地址或不可点击。
- 移动端缺少桌面已有的核心入口。
- 同一栏目在两种布局中使用不同路由或当前项判断。

### 验收

1. 在所有一级页面检查站点标识和主导航链接。
2. 跨越桌面断点，比较两种布局的目标、顺序和当前项。
3. 使用鼠标与键盘分别完成跳转。
4. 禁用 JavaScript 再验证一次核心入口。
