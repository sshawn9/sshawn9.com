# 案例：RSS 入口及其相关界面不得重新出现

### 场景

网站曾经包含 RSS 入口，但当前产品决定是不提供 RSS 界面。

### 正确行为

- Header、Footer、首页、博客页和文章页均不显示 RSS 按钮、文案或推广。
- 不为 RSS 保留空占位、图标间距或不可达菜单项。
- 后续组件升级不能因模板默认值重新带回 RSS。

### 禁止状态

- 视觉入口已删除，但无障碍树中仍有 RSS 链接。
- Footer 或移动菜单仍残留 RSS。
- 空白占位导致导航间距异常。

### 验收

1. 搜索构建后的 HTML 与可访问性树中的 RSS 文案、链接和图标。
2. 检查桌面、移动导航与 Footer。
3. 对组件升级后的构建执行同一负向检查。
4. 发现任何用户可达 RSS 入口即失败。
