# 案例：同一响应式布局在桌面、移动端与 iPad 浏览器中保持完整可用

### 场景

用户通过桌面 Chrome、移动端或 iPad Safari/Chrome 打开网站，可能旋转设备或缩放页面。

### 正确行为

- 响应式变化基于真实容器和可用空间，不能假设设备名称等于能力。
- 导航、Sidebar、图表、浮层和主要操作在各平台均可见、可达、可关闭。
- 触摸与指针布局共享语义状态，不出现平台专属的隐藏残留。

### 禁止状态

- 只针对某个 iPad 截图添加特殊 CSS 补丁。
- Safari 和 iPad Chrome 同时失败却归咎于单一浏览器品牌。
- 旋转设备后留下桌面折叠状态、遮罩或不可访问控件。

### 验收

1. 覆盖窄手机、iPad 竖横屏、桌面临界点和宽桌面。
2. 逐项操作导航、浮层、两侧 Sidebar、图表和滚动区域。
3. 在打开临时界面时旋转或改变视口。
4. 记录真实平台现象；只在根因能泛化时接受修复。
