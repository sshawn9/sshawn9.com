# 案例：临时浮层互斥显示，并在导航、触发器失效或视口变化时关闭

### 场景

用户打开壁纸控制、移动导航或其他临时浮层，随后打开另一浮层、导航离开或改变视口。

### 正确行为

- 同一时刻最多保留一个临时浮层。
- 导航开始、触发器隐藏或断开、断点或方向变化使锚点失效时，当前浮层关闭。
- 关闭后焦点回到仍然有效的触发器；触发器已不存在时进入合理的替代位置。

### 禁止状态

- 多个 Popover 相互覆盖并同时接收输入。
- 页面已经导航，旧浮层仍悬在新内容上。
- 桌面触发器消失后，浮层停留在无锚点位置。

### 验收

1. 依次打开所有可并存候选浮层，检查互斥关系。
2. 在浮层打开时执行导航、窗口缩放和方向切换。
3. 检查浮层关闭、焦点去向及页面滚动锁是否恢复。
4. 重复操作，确认没有遗留遮罩或监听器。
