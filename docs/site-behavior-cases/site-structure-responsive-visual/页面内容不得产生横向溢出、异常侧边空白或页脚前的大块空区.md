# 案例：页面内容不得产生横向溢出、异常侧边空白或页脚前的大块空区

### 场景

用户在不同视口、语言和页面类型中浏览长文、列表、图表和宽内容。

### 正确行为

- 页面宽度受视口和容器约束，必要内容可以在自身区域滚动或响应缩放。
- 主内容两侧留白有明确布局意义，并在同类页面中一致。
- 内容结束到页脚之间只保留设计需要的节奏空间。
- 列表分页与页脚之间保留可辨识的结束留白，不让翻页入口紧贴页脚分隔线。

### 禁止状态

- 页面可横向拖出空白区域。
- Sidebar 折叠或图表加载后出现无来源的大块侧边空白。
- 首页或文章页在内容结束后留下异常高的空分区。

### 验收

1. 在窄移动端、桌面临界点、常规和超宽视口检查 scrollWidth。
2. 分别加载中英文、长标题、图表和 Sidebar 展开/折叠状态。
3. 比较内容末尾、分页分隔线与页脚的垂直距离。
4. 任何无设计依据的溢出或空区均失败。
