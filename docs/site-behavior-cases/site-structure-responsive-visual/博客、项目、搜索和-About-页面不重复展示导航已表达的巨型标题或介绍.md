# 案例：博客、项目、搜索和 About 页面不重复展示导航已表达的巨型标题或介绍

### 场景

用户通过导航进入列表页或工具页，页面职责已经由当前导航项清楚表达。

### 正确行为

- 页面直接进入其主要任务：文章列表、项目内容、搜索框或 About 当前内容。
- 只有真正帮助理解和使用页面的信息才占据首屏。
- 未完成页面可以明确表达施工状态，但不使用虚构 Demo 填充。

### 禁止状态

- 巨型 Blog、Projects 或 Search 标题重复导航信息。
- 营销式 Hero、无实际信息的说明和 CTA 挤占主要内容。
- 为填满页面而增加与真实站点无关的演示数据。

### 验收

1. 检查四类页面首屏的第一个主要任务元素。
2. 确认删除标题后页面仍有清楚的文档标题与无障碍名称。
3. 对照真实内容，排除虚构介绍、示例项目和演示搜索块。
4. 在移动端确认主要任务仍位于合理首屏位置。
