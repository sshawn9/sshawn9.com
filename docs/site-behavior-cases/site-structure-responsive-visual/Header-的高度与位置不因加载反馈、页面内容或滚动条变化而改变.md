# 案例：Header 的高度与位置不因加载反馈、页面内容或滚动条变化而改变

### 场景

用户在不同页面间导航，触发慢请求、长短内容切换或页面滚动条出现与消失。

### 正确行为

- Header 使用稳定几何，加载反馈直接叠加在既有边界上。
- 页面内容高度和滚动条状态不能改变 Header 的垂直位置。
- 固定或非固定策略在同一断点下保持一致。

### 禁止状态

- 进度线出现时 Header 增高并推动正文。
- 从短页到长页时 Header 横向或纵向移动。
- 加载结束后 Header 留下额外边框或空隙。

### 验收

1. 在短页、长页、慢速导航和失败导航中逐帧记录 Header 边界。
2. 比较进度反馈前、中、后的高度与正文起点。
3. 强制滚动条出现、消失，检查 Header 横向位置。
4. 任一可见几何变化即失败。
