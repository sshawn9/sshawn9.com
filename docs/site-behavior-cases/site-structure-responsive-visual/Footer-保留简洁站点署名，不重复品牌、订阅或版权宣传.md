# 案例：Footer 保留简洁站点署名，不重复品牌、订阅或版权宣传

### 场景

用户浏览到任意页面底部。

### 正确行为

- Footer 保留简洁的 SHAWN 站点署名。
- Footer 与正文通过稳定边界区分，但不抢夺主要内容注意力。
- 不增加站点其他位置已有的品牌和导航信息。

### 禁止状态

- 出现订阅、RSS、营销口号或重复导航。
- 同一页面多次显示站点名称和冗余版权句。
- Footer 因页面类型不同而突然改变核心内容。

### 验收

1. 检查首页、项目、博客、搜索和文章页 Footer。
2. 对比中英文页面内容和布局。
3. 确认只存在预期署名，没有被历史组件重新引入的附加块。
4. 检查 Footer 不遮挡 Sidebar 或页面操作。
