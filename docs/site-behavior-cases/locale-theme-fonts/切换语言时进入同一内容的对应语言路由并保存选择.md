# 案例：切换语言时进入同一内容的对应语言路由并保存选择

### 场景

用户在首页、项目、博客列表、文章或搜索页主动切换语言。

### 正确行为

- 有对应语言内容时进入同一逻辑页面的对应路由。
- 语言偏好立即保存，并影响后续中立入口。
- 界面语言、路由语言、文档标题和导航状态同步更新。

### 禁止状态

- 切换语言一律跳回目标语言首页。
- URL 已切换，但 Header 或页面文案仍使用旧语言。
- 只改变当前页面，不保存用户选择。

### 验收

1. 在每类主要路由切换中英文。
2. 检查目标路径仍属于同一逻辑内容。
3. 再访问中立入口，确认使用刚保存的语言。
4. 前进后退时确认两种语言状态与各自 URL 一致。
