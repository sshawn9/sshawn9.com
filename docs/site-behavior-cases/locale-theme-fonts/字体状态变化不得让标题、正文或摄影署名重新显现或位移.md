# 案例：字体状态变化不得让标题、正文或摄影署名重新显现或位移

### 场景

字体在页面首次显示前完成，或动态内容需要新的字体分片。

### 正确行为

- 字体就绪前对应文字表面不显示；就绪后只提交一次最终结果。
- 已经显示的标题、正文、导航和摄影署名持续可见，位置稳定。
- 动态内容在自己的提交边界等待，不重新隐藏已经稳定的页面内容。

### 禁止状态

- 已经显示的正文或署名再次消失并重现。
- 摄影署名、标题或列表因字体状态变化发生可见跳动。

### 验收

1. 在中文和英文页面分别延迟、阻断和缓存字体资源。
2. 观察标题、正文与摄影署名从首次显示到稳定的全过程。
3. 触发搜索等动态内容，确认只等待新内容且既有页面不闪动。
