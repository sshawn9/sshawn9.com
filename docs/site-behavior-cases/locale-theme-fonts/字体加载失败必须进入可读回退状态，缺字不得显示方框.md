# 案例：字体加载失败必须进入可读回退状态，缺字不得显示方框

### 场景

字体文件 404、超时、缓存损坏，或正文包含目标字体未覆盖的字符。

### 正确行为

- 字体控制状态在有限时间后进入 degraded，而不是永久 pending。
- 回退字体栈覆盖正文语言和常见符号。
- 页面布局可以合理变化，但内容必须完整可读、操作可用。

### 禁止状态

- 显示 tofu 方框、空白字符或不可见代码。
- 因一个字体失败隐藏整个页面。
- 重复请求失败字体并持续触发排版。

### 验收

1. 分别阻断标题、正文、代码和公式字体请求。
2. 检查就绪状态最终结束，页面仍能阅读和操作。
3. 注入缺字字符，确认回退链工作。
4. 检查控制台和网络没有无限重试。
