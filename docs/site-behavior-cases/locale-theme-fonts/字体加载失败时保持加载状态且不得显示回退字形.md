# 案例：字体加载失败时保持加载状态且不得显示回退字形

### 场景

当前内容需要的字体文件失败、缓存损坏或浏览器字体能力不可用。

### 正确行为

- 页面持续保持字体加载状态，背景和进度反馈仍可见。
- 标题、正文、导航、代码、公式和摄影署名均不显示回退字形。
- 客户端导航仍允许被后续导航取消，失败事务不得锁死当前旧页面。
- 同一事务不循环重试失败字体。

### 禁止状态

- 超时后切换到系统字体、Times New Roman 或其他降级字体。
- 一部分文字先出现，另一部分继续等待。
- 失败字体迟到后让已经显示的内容再次换字。

### 验收

1. 分别阻断标题、正文、中文、代码和公式字体。
2. 确认页面持续显示进度状态，所有文字表面保持不可见。
3. 在失败的客户端导航期间选择另一目标，确认旧事务被取消且新导航可继续。
