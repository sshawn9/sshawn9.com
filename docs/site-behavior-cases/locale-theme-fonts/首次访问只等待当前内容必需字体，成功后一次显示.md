# 案例：首次访问只等待当前内容必需字体，成功后一次显示

### 场景

用户首次打开站点，本地尚无当前页面需要的字体分片。

### 正确行为

- 壁纸或默认底色与细进度线保持可见，文字表面暂不显示。
- 只请求当前内容实际需要的标题、正文、代码、中文分片和公式字体。
- 所有必需字体成功后，页面以最终字形和最终几何一次显示。

### 禁止状态

- 先用系统字体显示内容，再替换为网站字体。
- 为简单页面等待未被当前内容使用的字体。
- 字体尚未就绪时提前结束进度状态或暴露部分文字。

### 验收

1. 清空字体缓存并分别打开中文、英文、代码和含公式页面。
2. 延迟字体请求，确认等待期间只有稳定背景与进度反馈。
3. 放行字体后逐帧检查，首个文字帧即为最终字体和最终布局。
