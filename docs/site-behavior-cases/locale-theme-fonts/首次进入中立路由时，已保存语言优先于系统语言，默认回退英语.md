# 案例：首次进入中立路由时，已保存语言优先于系统语言，默认回退英语

### 场景

用户首次或再次访问不含语言前缀的入口，浏览器具有系统语言，站点也可能保存过语言选择。

### 正确行为

- 已保存且仍受支持的语言优先于系统语言。
- 没有保存值时才参考系统语言；无法匹配时回退英语。
- 进入后 URL、HTML lang、界面文案和当前语言控件一致。

### 禁止状态

- 每次访问都用系统语言覆盖用户已保存选择。
- 先显示英语，再客户端跳到中文，或反向闪切。
- 弹出没有产品必要性的首次访问语言选择器。

### 验收

1. 分别设置已保存中文、已保存英文、无保存值与无效保存值。
2. 组合中文、英文和不支持的系统语言访问中立入口。
3. 从首个可见帧检查最终路由和文档语言。
4. 刷新后确认选择稳定且无二次重定向。
