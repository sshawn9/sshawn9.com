# 案例：主题默认跟随系统，用户选择跨刷新与站内导航保持

### 场景

用户尚未选择主题，或已经明确选择亮色/暗色，随后刷新、导航或重启浏览器。

### 正确行为

- 没有用户选择时跟随系统主题。
- 用户明确选择后，该选择优先并持久保存。
- 主题在首帧前恢复，站内导航期间保持同一状态。

### 禁止状态

- 每次刷新先显示系统主题，再切到保存主题。
- 站内导航把用户选择重置为自动。
- 主题存储损坏导致页面不可读或脚本中断。

### 验收

1. 覆盖无保存值、亮色保存值、暗色保存值和损坏值。
2. 在不同系统主题下冷访问、刷新和站内导航。
3. 逐帧检查首个背景与文字配色。
4. 重启浏览器后确认明确选择仍有效。
