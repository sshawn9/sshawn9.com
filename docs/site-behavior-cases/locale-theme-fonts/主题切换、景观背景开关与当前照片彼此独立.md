# 案例：主题切换、景观背景开关与当前照片彼此独立

### 场景

用户在亮暗主题、默认/景观背景和照片轮换之间任意组合操作。

### 正确行为

- 改变主题不能替换当前照片或重建照片队列。
- 开关景观背景不能改变主题偏好。
- 自动轮换只改变照片，不改变主题或景观总开关。

### 禁止状态

- 切换亮暗主题后随机换了一张照片。
- 关闭景观背景把主题重置。
- 重新开启景观背景生成与关闭前无关的新会话状态。

### 验收

1. 记录主题、景观开关、当前照片 ID 和队列。
2. 按不同顺序切换三类状态。
3. 检查每一步只改变其负责的状态。
4. 刷新和站内导航后复核相同不变量。
