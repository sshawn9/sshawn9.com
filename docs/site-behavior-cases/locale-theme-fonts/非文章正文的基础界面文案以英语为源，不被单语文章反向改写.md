# 案例：非文章正文的基础界面文案以英语为源，不被单语文章反向改写

### 场景

中文或英文文章存在语言回退，但页面仍包含导航、按钮、状态和辅助信息。

### 正确行为

- 组件和基础界面采用站点语言资源，英语为源语言。
- 正文实际语言只影响正文及与正文直接绑定的内容语言。
- 回退文章不得把导航、分页或操作文案切换成正文语言。

### 禁止状态

- 打开中文回退正文后，英文界面局部变成中文。
- 组件文案直接从文章 frontmatter 反推。
- 同一页面出现无法解释的混合界面语言。

### 验收

1. 在英文界面打开仅有中文正文的文章，反向再测一次。
2. 检查 Header、Sidebar、分页、按钮和状态信息的语言。
3. 检查正文 lang 与界面 lang 的边界。
4. 切换语言后确认组件资源正常更新。
