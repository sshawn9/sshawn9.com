# 案例：缺少目标语言时，只在当前版本内回退，并标明实际内容语言

### 场景

用户请求某语言的文章，但当前选定版本没有该语言正文。

### 正确行为

- 先确定当前可见版本，再在该版本内部选择可用语言。
- 回退正文使用其真实语言的 lang 属性。
- 站点界面仍使用请求语言，并清楚说明正文为何以另一语言显示。

### 禁止状态

- 为满足语言请求而静默显示旧版本翻译。
- 正文是中文却标记为英文。
- 缺翻译文章从另一语言的列表中消失。

### 验收

1. 构造最新版本缺少中文、缺少英文的文章。
2. 从两种语言列表、直接 URL 和语言切换进入。
3. 检查版本、正文语言、提示、canonical 与列表可见性。
4. 确认不会选择旧版本的同语言文件。
