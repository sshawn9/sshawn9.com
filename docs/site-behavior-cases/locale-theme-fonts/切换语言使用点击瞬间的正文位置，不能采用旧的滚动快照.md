# 案例：切换语言使用点击瞬间的正文位置，不能采用旧的滚动快照

### 场景

用户在长文章中多次滚动，停在新的阅读位置后立即切换语言。

### 正确行为

- 切换动作以点击瞬间的实际 scrollY 为基准，保留大致阅读进度。
- 旧的节流记录、历史状态或上一次点击位置不得覆盖当前值。
- 语言切换控件本身不得触发额外自滚动。

### 禁止状态

- 页面返回更早停留的章节。
- 切换前后先跳到顶部，再恢复到近似位置。
- 点击语言按钮时，因焦点或锚点逻辑先改变正文位置。

### 验收

1. 在长文中滚动到位置 A，继续滚动到位置 B 后立刻切换语言。
2. 记录点击瞬间与目标页稳定后的阅读进度。
3. 重复快速滚动与切换，确认不使用旧快照。
4. 检查切换全过程没有顶部闪帧或额外平滑滚动。
