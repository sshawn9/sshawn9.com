# 案例：首次访问可等待字体下载，但必须有明确且有限的就绪过程

### 场景

用户首次访问站点，本地没有任何目标字体缓存，网络速度可能较慢。

### 正确行为

- 网站可以在关键字体准备期间采用受控的等待或揭示效果。
- 等待范围、所需字体和完成条件必须与当前页面实际内容匹配。
- 成功和失败都有明确终点，不能无限隐藏正文。

### 禁止状态

- 为追求立即显示而先用错误字体排版，再明显换字。
- 等待所有站点可能使用的字体后才显示简单页面。
- 字体请求失败导致页面永久不可见。

### 验收

1. 清空字体缓存并模拟正常、慢速和失败网络。
2. 记录首个可见内容、字体请求和就绪/降级时刻。
3. 确认页面只等待实际需要的字体且有时间上限。
4. 失败时确认正文仍可阅读。
