# 案例：标题、英文正文、中文正文、代码与公式各自使用稳定字体角色

### 场景

页面同时包含中英文标题、正文、代码块、中文注释和数学公式。

### 正确行为

- 英文标题使用 Manrope，英文正文使用 Source Sans 3。
- 中文正文使用 Noto Sans SC，代码使用 JetBrains Mono 与中文等宽回退。
- 数学公式使用 KaTeX 自带字体，字体职责不因页面类型临时变化。

### 禁止状态

- 修复某篇文章时全站字体角色被无意替换。
- 中文代码回退到比例字体，破坏对齐。
- 公式字体被正文字体覆盖。

### 验收

1. 在中英文普通页、代码文章和数学文章读取计算字体。
2. 对比不同导航路径和硬刷新后的结果。
3. 检查中文代码、混合标点与公式基线。
4. 视觉确认字体选择仍符合既定阅读效果。
