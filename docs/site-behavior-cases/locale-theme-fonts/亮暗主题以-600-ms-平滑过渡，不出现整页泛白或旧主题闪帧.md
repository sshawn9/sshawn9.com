# 案例：亮暗主题以 600 ms 平滑过渡，不出现整页泛白或旧主题闪帧

### 场景

用户在任意页面主动切换亮暗主题，页面可能同时使用默认或景观背景。

### 正确行为

- 主题视觉在约 600 ms 内平滑完成，让眼睛有适应时间。
- 背景、文字、边界和控件作为一致视觉系统过渡。
- 过渡不创建额外白色页面层，也不先切背景后切文字。

### 禁止状态

- 暗色切亮色时整页先泛白，再进入正常亮色。
- 主题瞬间突变或过渡快到刺眼。
- 为修复主题动画而移除景观背景开关动画或页面切换动画。

### 验收

1. 在默认/景观背景的亮→暗与暗→亮四条路径录屏。
2. 逐帧检查亮度是否单调、是否出现中间白闪或旧色残留。
3. 验证实际持续时间与设计值相符。
4. 在 reduced-motion 下确认仍能清楚完成状态切换。
