# 案例：中英文内容长度不同不得造成控件碰撞、溢出或布局结构变化

### 场景

同一页面在中英文之间切换，标题、标签、按钮和目录文字长度不同。

### 正确行为

- 两种语言使用同一布局规则，根据容器空间自然换行或截断。
- 控件命中区域、层级关系和主要几何保持一致。
- 内容差异可以改变合理高度，但不能破坏结构或遮挡操作。

### 禁止状态

- 为某个中文或英文字符串单独硬编码位置。
- 标签、日期、按钮或目录彼此重叠。
- 语言切换导致 Sidebar、导航或图表使用另一套布局。

### 验收

1. 在两种语言下检查最长标题、标签、目录和按钮文案。
2. 覆盖移动端、桌面临界宽度和 Sidebar 调宽后的窄内容区。
3. 检查溢出、换行、截断与命中区域。
4. 切换语言逐帧观察是否发生结构跳变。
