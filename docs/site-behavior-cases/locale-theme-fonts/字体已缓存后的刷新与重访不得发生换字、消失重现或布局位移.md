# 案例：字体已缓存后的刷新与重访不得发生换字、消失重现或布局位移

### 场景

用户已完成一次访问，字体资源有效缓存，随后刷新或再次进入同一页面。

### 正确行为

- 首个可见帧直接采用目标字体及其最终几何。
- 正文、导航、目录、日期和署名持续可见。
- 页面不得再次制造首次访问式等待。

### 禁止状态

- 文字短暂消失后在原位重现。
- 先显示系统字体，再替换成网站字体。
- 页面最终没有 CLS，但用户仍看到一次透明度闪动。

### 验收

1. 先正常访问并确认字体进入缓存，再做多次温缓存刷新。
2. 逐帧采样文字可见性、字体族和关键元素边界。
3. 覆盖中文、英文、代码和含公式文章。
4. 任何换字、闪空或几何变化即失败。
