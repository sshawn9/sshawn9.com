# 案例：服务端完整输出可读页面，客户端只绑定交互而不重建可见结构

### 场景

用户直接访问普通页面，JavaScript 可能正常、延迟、失败或被禁用。

### 正确行为

- 导航、正文、文章信息、目录及基本列表由 HTML 完整提供。
- 客户端只为既有结构绑定筛选、当前章节、动画等增强能力。
- 水合前后主要节点身份、内容顺序和几何保持稳定。

### 禁止状态

- 服务端只输出空容器或骨架，等待客户端填充主要内容。
- 水合时先删除 SSR 内容，再创建外观相同的新结构。
- JavaScript 失败后页面永久空白或无法阅读。

### 验收

1. 禁用 JavaScript 访问首页、博客、文章和搜索页。
2. 检查核心内容、导航和链接可以阅读与使用。
3. 开启 JavaScript 并延迟 bundle，记录水合前后关键节点身份与几何。
4. 客户端接管导致结构重建或内容空窗即失败。
