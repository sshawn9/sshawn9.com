# 案例：慢速站内导航及时显示不占布局空间的进度反馈

### 场景

用户点击尚需网络请求的站内链接，请求明显慢于即时响应。

### 正确行为

- 确认存在真实等待后，导航栏边缘显示细的无确定进度反馈。
- 反馈覆盖在既有导航栏上，不增加 Header 高度。
- 主内容以可访问状态表达 busy，导航完成、失败或取消后反馈立即结束。

### 禁止状态

- 点击后长时间没有任何反馈，诱发重复点击。
- 进度线挤开页面并导致整体下移。
- 已经完成或被替代的导航仍保留进度状态。

### 验收

1. 将目标文档请求延迟到足以触发反馈。
2. 记录 Header 高度、正文顶部与进度线生命周期。
3. 确认只有真实慢请求显示反馈，快速缓存导航不产生明显闪动。
4. 验证成功、失败、取消和重复点击都能正确收尾。
