# 案例：系统浏览器指针刷新与站点控件生命周期回归分别判定

### 场景

系统 Chrome 中点击站内控件时，真实鼠标指针可能出现瞬时刷新；DOM 记录却显示控件始终存在且可交互。

### 正确行为

- 先验证站点是否保持节点、命中区域、cursor 样式和可用性，再单独判断浏览器或系统合成行为。
- 平台级指针脉冲必须由可复现实验支持，不能用猜测替代站点诊断。
- 已确认的平台边界不能驱动大量无效页面补丁，也不能掩盖真正的 DOM 回归。

### 禁止状态

- 仅凭 DOM 测试通过就声称真实指针没有闪烁。
- 未证明平台原因便把问题归咎于 Chrome、Safari 或操作系统。
- 为追逐不可控的系统指针刷新而破坏主题、壁纸或页面过渡。

### 验收

1. 同时采集节点身份、elementFromPoint、计算 cursor、导航事件和系统录屏。
2. 使用系统 Chrome 与至少一个对照环境重复相同操作。
3. 将网页层失败和系统 UI 现象分别记录。
4. 只有证据能隔离平台边界时，才接受“非站点代码问题”的结论。
