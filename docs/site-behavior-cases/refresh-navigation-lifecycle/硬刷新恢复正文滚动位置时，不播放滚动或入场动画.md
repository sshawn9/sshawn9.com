# 案例：硬刷新恢复正文滚动位置时，不播放滚动或入场动画

### 场景

用户已经滚动到页面中部或底部，刷新后网站需要恢复原来的阅读位置。

### 正确行为

- 保存的有效滚动位置应在页面暴露前恢复，用户直接看到原阅读区域。
- 恢复属于状态还原，不属于用户发起的滚动，因此不得平滑滚动。
- 已位于视口内的正文、图片和模块不得重新播放首次进入动画。

### 禁止状态

- 页面先显示顶部，再滚动到保存位置。
- 页面先跳到错误位置，之后二次校正。
- 恢复位置后，正文按从上到下的顺序重新淡入。

### 验收

1. 在普通长文和含交互图长文的中部、接近底部分别刷新。
2. 逐帧记录 scrollY 与主要元素可见状态。
3. 断言首个可见位置接近保存值，且没有 smooth scroll 或 reveal 动画。
4. 再用系统 Chrome 观察刷新过程，而不只读取最终 scrollY。
