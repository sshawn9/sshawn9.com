# 案例：快速连续导航时，迟到的水合只能接管最新页面

### 场景

客户端组件尚未完成水合时，用户已经从页面 A 快速导航到页面 B，甚至继续到页面 C。

### 正确行为

- 运行时必须以当前实际页面为准，丢弃来自旧页面的迟到上下文。
- 水合完成后只能绑定最新页面存在的节点和状态。
- 旧页面的标题、语言、导航选中项、监听器或恢复值不得覆盖当前页面。

### 禁止状态

- 页面已经位于 B 或 C，却短暂显示 A 的导航状态或文案。
- 旧页面水合后重新注册全局监听器并继续响应。
- 最终 URL 与可见页面一致，但全局控件仍引用旧页面。

### 验收

1. 人为延迟持久客户端组件水合。
2. 在延迟期间连续导航 A → B → C。
3. 水合完成后检查 URL、标题、语言、导航状态和事件监听只属于 C。
4. 重复操作并观察是否出现旧页面状态闪回。
