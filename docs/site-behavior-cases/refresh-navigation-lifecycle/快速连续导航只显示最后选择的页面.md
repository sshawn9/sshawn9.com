# 案例：快速连续导航只显示最后选择的页面

### 场景

用户在前一次页面切换尚未完成时继续选择新的目标页面。

### 正确行为

- 最终只显示最后一次选择对应的页面、标题、语言和导航状态。
- 较早请求即使随后完成，也不能再改变当前画面。
- 历史后退尚未完成、旧页面仍可操作时，用户在该页面的新操作作为最新意图，基于该页面状态处理；不能把它的筛选参数写到后退目标页面。
- 锚点跳转同样能取代未提交的导航，旧的局部更新队列不得随后覆盖新目标。

### 禁止状态

- 已进入最后目标后，旧页面内容或导航选中态短暂闪回。
- URL、标题、可见内容和 Header 状态分别属于不同页面。

### 验收

1. 在网络延迟下快速执行 A → B → C 导航。
2. 重复操作并确认过程中和最终状态始终以 C 为准。
3. 延迟后退目标响应，在仍显示的博客上点击标签，确认进入博客的新筛选状态。
4. 在局部操作尚未提交时激活“跳到主内容”，确认最终保留锚点，没有旧请求回写。
