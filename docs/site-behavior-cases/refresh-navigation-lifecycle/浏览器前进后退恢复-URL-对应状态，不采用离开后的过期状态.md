# 案例：浏览器前进后退恢复 URL 对应状态，不采用离开后的过期状态

### 场景

用户在筛选、分页、搜索、文章锚点和普通页面之间导航，然后使用浏览器前进或后退。

### 正确行为

- 页面内容、查询、选中项、主滚动与嵌套滚动共同恢复到目标历史项。
- URL 是可分享状态的事实来源；运行时缓存只能辅助恢复。
- 恢复过程不得先显示当前页面状态，再纠正为历史状态。

### 禁止状态

- URL 已回到旧查询，但结果仍是离开前的新查询。
- 正文恢复后，Sidebar 滚动或选中项仍来自另一历史项。
- 后退被错误实现为进入与历史无关的上一页面。

### 验收

1. 组合执行标签筛选、翻页、搜索和文章锚点跳转。
2. 多次前进、后退并记录每一历史项的 URL、内容与滚动。
3. 检查首帧与终态均对应目标历史项。
4. 刷新恢复后的历史项，确认结果仍可由 URL 独立重建。
