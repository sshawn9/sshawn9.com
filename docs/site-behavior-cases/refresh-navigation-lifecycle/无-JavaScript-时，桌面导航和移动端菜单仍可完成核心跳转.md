# 案例：无 JavaScript 时，桌面导航和移动端菜单仍可完成核心跳转

### 场景

JavaScript 被禁用、下载失败或尚未执行，用户需要访问站点主要页面。

### 正确行为

- 桌面导航保留真实链接，可直接打开所有主要页面。
- 移动端提供无需客户端框架即可使用的披露与链接结构。
- 当前页面和语言信息仍以 HTML 语义表达。

### 禁止状态

- 导航项目只有 click handler，没有 href。
- 移动端菜单按钮在无 JavaScript 时永远无法展开。
- 无脚本模式显示两套重叠导航或不可见链接。

### 验收

1. 禁用 JavaScript，在桌面与移动视口分别加载页面。
2. 使用键盘打开移动菜单并访问每个主要入口。
3. 检查链接地址、当前项语义和语言路由。
4. 恢复 JavaScript，确认增强不会复制导航内容树。
