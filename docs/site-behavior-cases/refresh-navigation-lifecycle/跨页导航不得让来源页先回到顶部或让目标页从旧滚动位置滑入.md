# 案例：跨页导航不得让来源页先回到顶部或让目标页从旧滚动位置滑入

### 场景

用户把当前页面滚到中下部，再点击链接进入另一个页面。

### 正确行为

- 来源页面在离场期间保持点击瞬间的滚动位置。
- 目标页面的目标滚动位置在其可见前完成放置。
- 链接带章节锚点时，目标章节在淡入前已位于目标位置；淡入过程中和完成后不再发生定位跳动。

### 禁止状态

- 来源页面先突然跳回顶部，再开始页面切换。
- 目标页面先沿用来源页面的滚动位置，再可见地滑到顶部。
- 页脚或页面底部短暂成为目标页面的首帧。

### 验收

1. 从博客、文章和项目页面的顶部、中部、底部分别进入其他页面。
2. 确认离场和入场过程中都没有可见的滚动插值或跳顶。
3. 覆盖带章节锚点的跨页链接，确认目标章节从透明阶段到完全显示始终保持同一位置。
