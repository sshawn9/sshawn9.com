# 案例：键盘导航后焦点进入主内容，并以当前语言宣布页面变化

### 场景

键盘用户通过主导航或站内链接进入另一页面。

### 正确行为

- 导航完成后，焦点移动到目标页面主要内容的合理入口。
- 页面变化通过当前界面语言向辅助技术宣布。
- 指针发起的导航不无条件抢走用户焦点。

### 禁止状态

- 键盘导航完成后焦点停留在已失效或已断开的旧链接。
- 中文界面使用英文播报，或反之。
- 每次鼠标点击都强制把焦点移到正文。

### 验收

1. 仅用键盘从主导航进入不同页面。
2. 检查 activeElement、主内容可聚焦入口与 live region 文案。
3. 分别在中英文界面验证播报语言。
4. 用鼠标重复同一路径，确认不会产生不必要的焦点跳转。
