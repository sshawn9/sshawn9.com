# 案例：页面级脚本在离场时释放、到场时只初始化一次

### 场景

用户反复进入和离开带目录、筛选器、图表或其他页面级增强的页面。

### 正确行为

- 页面级监听器、观察器、计时器与控制器在内容交换前释放。
- 新页面进入后，每项能力只存在一个有效实例。
- 站点级能力继续存活，但不得重复初始化。

### 禁止状态

- 返回同一页面后，一次操作触发两次或更多响应。
- 已离开的页面仍在执行 observer、timer 或异步回调。
- 通过全局布尔量压住重复初始化，却保留失效资源。

### 验收

1. 在博客、文章、搜索之间往返至少十次。
2. 统计关键监听器、观察器和控制器创建、释放次数。
3. 对筛选、目录、搜索和壁纸各执行一次操作，确认只响应一次。
4. 检查离场页面不再产生网络、定时或 DOM 写入。
