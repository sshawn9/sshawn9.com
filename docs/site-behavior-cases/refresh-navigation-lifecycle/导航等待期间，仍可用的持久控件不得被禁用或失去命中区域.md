# 案例：导航等待期间，仍可用的持久控件不得被禁用或失去命中区域

### 场景

用户点击持久导航链接后，请求仍在进行，鼠标没有移动，控件仍处于原位置。

### 正确行为

- 控件节点、尺寸、位置、命中区域和网页层面的可交互语义保持不变。
- 对同一目标的重复动作由请求逻辑合并，而不是替换或禁用控件。
- 与页面无关的主题、壁纸等持久操作继续可用。

### 禁止状态

- 加载期间用占位节点替换原链接。
- 临时设置 pointer-events: none 或移除 href，导致命中区域消失。
- 为防止重复请求而冻结整个 Header。

### 验收

1. 延迟站内导航请求，将指针停在触发链接上。
2. 连续采样节点身份、边界、href、pointer-events 与元素命中结果。
3. 重复点击同一目标，确认只产生一个有效导航请求。
4. 导航期间操作其他持久控件，确认仍然可用。
