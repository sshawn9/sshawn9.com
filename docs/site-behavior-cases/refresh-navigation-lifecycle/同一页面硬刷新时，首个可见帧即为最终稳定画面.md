# 案例：同一页面硬刷新时，首个可见帧即为最终稳定画面

### 场景

用户停留在已经稳定的页面和滚动位置，随后刷新同一地址。

### 正确行为

- 首个可见帧直接呈现正确内容、布局、主题和已保存的界面状态。
- 从首帧到页面完全可操作，每一帧都保持连续。
- 冷缓存缺少必需字体时可以先显示稳定背景和进度线；首个文字帧仍必须是最终画面。

### 禁止状态

- 先显示默认主题、默认布局或错误内容，再修正为最终状态。
- 必需字体已在浏览器缓存中，仍再次显示加载帧或隐藏文字。
- 最终截图正确，但过程中出现闪烁、跳动或内容重现。

### 验收

1. 在首页、博客、普通文章和含交互内容的文章分别连续刷新。
2. 覆盖首次访问、字体已缓存和字体失败场景；失败行为遵循字体资源契约。
3. 从首个可见帧观察到页面完全可操作，任一错误中间帧即失败。
