# 案例：站内导航只替换页面出口，站点外壳保持同一实例

### 场景

用户通过站内链接在首页、项目、博客、搜索和文章之间导航。

### 正确行为

- Header、主导航、主题控件、壁纸控件和壁纸图层属于持久外壳，导航前后保持同一 DOM 实例。
- 只有主内容与属于页面的页脚出口可以被替换。
- 持久外壳根据新页面上下文更新语言、当前项和可用操作，但不得卸载重建。

### 禁止状态

- 导航栏、壁纸或全局控件随正文一起销毁再创建。
- 相同背景在每次页面切换时重新淡入或重新请求。
- 为保留外壳而同时留下两份主内容或两套事件处理器。

### 验收

1. 导航前记录持久外壳关键节点引用和壁纸资源请求数。
2. 连续访问多个不同类型页面并执行前进、后退。
3. 断言外壳节点引用不变、主内容发生替换、背景未重复加载。
4. 检查导航后当前项、语言和全局操作仍对应目标页面。
