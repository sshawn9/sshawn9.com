# 案例：已取消的入场动画不得在字体或异步资源就绪后复活

### 场景

页面的 reveal 动画尚在等待字体或资源时，用户已经刷新、导航离开，或恢复到非顶部位置。

### 正确行为

- 页面离场、恢复滚动或明确取消后，旧 reveal 任务永久失效。
- 字体和资源迟到只能完成当前页面仍有效的任务。
- 返回页面时是否播放动画由新的导航场景重新判断。

### 禁止状态

- 离开页面后，字体完成事件让旧页面动画继续执行。
- 刷新恢复到正文中部后，下方内容重新逐段出现。
- 新页面沿用旧页面的 animation queue。

### 验收

1. 延迟字体加载，在 reveal 等待期间立即导航离开。
2. 等待字体和其他资源完成，确认旧页面没有动画或可见内容改写。
3. 在长文中部刷新，确认恢复后不重播 reveal。
4. 再正常进入新页面，确认其合法入场动画仍可工作。
