# 案例：站内页面切换保留既有动画，不退化为整页重载或突变

### 场景

用户通过站内链接切换页面，期间可能同时调整主题、背景或其他全局状态。

### 正确行为

- 页面内容遵循既定的两阶段节奏：旧内容单独淡出 180 ms，交换隐藏在全透明边界，新内容再单独淡入 180 ms。
- 目标文档在离场动画开始前已完成获取和必要准备；慢网络不提前把当前内容变透明。
- 持久导航栏的当前页语义在内容全透明的交换边界原子切换，不在旧内容退场期间提前变更。
- 普通跨页导航的目标滚动位置在目标画面暴露前完成；转场只播放既定透明度变化，不在新旧页面的滚动坐标之间插值位移。
- 修复首帧或持久外壳问题不能移除已有页面过渡。
- 页面过渡与主题、壁纸过渡分别管理，互不覆盖。

### 禁止状态

- 所有站内导航突然变成无过渡的瞬间替换。
- 从已滚动页面导航后，目标页的转场截图从页面下方或上方滑入目标位置。
- 旧页和新页同时半透明地叠在壁纸上，导致卡片重影、亮度变化或布局幽灵帧。
- 为避免闪烁，把站内导航退化为浏览器整页重载。
- 页面动画正常，但主题或壁纸过渡被一并取消。

### 验收

1. 记录修改前已确认的页面切换节奏。
2. 在长页面的顶部、中部和底部分别导航到不同页面类型，逐帧确认目标内容直接位于目标滚动位置。
3. 在亮暗主题、默认与景观背景下分别导航。
4. 逐帧确认旧、新内容不同时可见，两段各 180 ms 的透明度过渡完整；导航栏当前页状态只在中点切换，外壳不重建，主题和壁纸动画各自完整。
5. 在 reduced-motion 下确认非必要动画按偏好收敛。
