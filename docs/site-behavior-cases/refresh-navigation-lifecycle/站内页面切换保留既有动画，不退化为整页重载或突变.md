# 案例：站内页面切换保留既有动画，不退化为整页重载或突变

### 场景

用户通过站内链接切换页面，期间可能同时调整主题、背景或其他全局状态。

### 正确行为

- 页面内容遵循既定离场、交换与入场节奏。
- 修复首帧或持久外壳问题不能移除已有页面过渡。
- 页面过渡与主题、壁纸过渡分别管理，互不覆盖。

### 禁止状态

- 所有站内导航突然变成无过渡的瞬间替换。
- 为避免闪烁，把站内导航退化为浏览器整页重载。
- 页面动画正常，但主题或壁纸过渡被一并取消。

### 验收

1. 记录修改前已确认的页面切换节奏。
2. 在亮暗主题、默认与景观背景下分别导航。
3. 检查页面过渡仍存在，外壳不重建，主题和壁纸动画各自完整。
4. 在 reduced-motion 下确认非必要动画按偏好收敛。
