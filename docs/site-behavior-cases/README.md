# sshawn9.com 用户体验回退规范

本目录只记录用户能够直接看到或操作到的体验边界。源码、配置、数据模型、部署流程、缓存策略、测试方法和实现方案不在这里重复说明。

## 记录规则

- 一条可独立观察的故障使用一篇 Markdown，不把不同回退合成宽泛口号。
- 每篇只描述触发场景、正确结果、禁止出现的错误帧或错误状态，以及最小验收方式。
- 已经发生并修复过的回退继续保留；它们的价值是阻止重构和后续修改再次引入同一问题。
- 技术实现可以替换，但不得借此静默改变这里记录的用户结果。
- 普通功能若已能由页面和源码直接理解，且没有独立的时序、视觉或失败边界，就不在本目录立案。
- 最终截图正确不代表通过；只要过程中出现禁止状态，该案例即失败。
